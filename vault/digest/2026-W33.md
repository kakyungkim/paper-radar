## At a Glance

단백질 구조 생성 AI가 "진짜 새로운 폴드를 만드는가"라는 질문을 처음으로 정량적으로 검문한 논문이 이번 주 가장 큰 반향을 일으켰다. RetFold/DRR은 기존 TM-score 기반 신규성 평가의 허점을 도메인 검색률(DRR)로 드러내면서, 훈련 없는 검색 기반 베이스라인이 경쟁적 성능을 낼 수 있다는 불편한 사실을 드러냈다.

데이터 인프라 전선에서는 Argonne 국립연구소가 항암 약물반응 예측(DRP) 연구의 고질적 문제인 벤치마크 분절을 53,949개 화합물 · 5.5M 측정값 규모의 AI-ready 공개 데이터로 직접 공략했다. 상업 기업들의 데이터 해자가 공공 인프라에 의해 약해질 수 있다는 구조적 신호다.

전반적으로 이번 주 논문들은 완전히 새로운 알고리즘 발명보다 기존 도구의 조합·통합·평가 관행 비판에 무게가 실렸다. 분야 성숙 단계의 전형적인 패턴이지만, 이 비판들이 다음 세대 방법론의 출발점이 된다.

### 1. KAN과 Transformer로 단일세포 세포유형 주석을 다시 설계하다 (scKanFormer: A Transformer-KAN framework with biologically informed attention for cell type annotation in large-scale scRNA-seq data)

저자: Yuan L (1저자), Huang De-Shuang (교신) | 소속 기관 미확인

출처 · 2026-08-14 · peer-reviewed · [DOI: 10.1371/journal.pcbi.1014607](https://doi.org/10.1371/journal.pcbi.1014607) · [code](https://github.com/nathanyl/scKanFormer) (GitHub 확인, 내용 미확인)

**선택 이유** KAN을 단일세포 주석에 적용한 선례가 있었지만(scKAN, Genome Biology 2025), Transformer와 결합하면서 동시에 생물학적 경로(pathway) 마스크를 어텐션 레이어에 통합한 설계는 이번이 처음이다. 동료심사를 통과해 방법론 내적 타당성을 외부에서 확인받았다.

사회적 신호: PLOS Computational Biology 동료심사 게재

**Key Point** Transformer 인코더의 FFN(피드포워드 네트워크) 자리를 Kolmogorov-Arnold Networks(KAN)으로 교체하고, 경로 데이터베이스 기반 마스크 행렬을 어텐션에 주입해 경로 수준 표현을 강제한다. 9개 최신 방법 대비 세포유형 주석 정확도와 배치 효과(batch effect) 분리 성능 개선을 보고했다(초록 기준; 구체 수치와 비교 방법 이름 목록은 원문 확인 필요).

**💡 인사이트** KAN 단독 · 경로 마스크 단독 각각의 기여를 ablation 실험이 분리해서 보여주는가가 채택 전 핵심 점검 사항이다. 경로 데이터베이스 커버리지가 얇은 희귀 세포 유형에서 마스크가 오히려 정보를 제거할 수 있다는 역효과도 원문에서 다루는지 확인이 필요하다.

🔬 Method: KAN 기반 FFN 교체 + 경로 데이터베이스 마스크 행렬 어텐션 통합 설계; 9개 방법 대비 정확도·배치 강건성 벤치마크(데이터셋 목록 원문 확인 필요)

🩺 Clinical: 종양 미세환경(tumor microenvironment) 분석과 희귀 면역 세포 아형 동정의 정밀도를 높이는 상류(upstream) 도구; 임상 결정 도구로 전환까지 다단계가 남아 있음

🏭 Industry: 10x Genomics · QIAGEN(Parse Biosciences 인수) 등 단일세포 플랫폼의 분석 소프트웨어 경쟁과 직접 연결; CAR-T 세포 제품 조성 QC에 경로 수준 주석 정밀도가 중요해지는 방향

검증 수준: in silico (공개 scRNA-seq 데이터셋, peer-reviewed)

### 2. 항암 약물반응 예측의 데이터 인프라를 공공재로 만들다 (Large-scale AI-Ready Data for Anti-Cancer Drug Response Modeling)

저자: Vincent Lavelle (1저자), Rick Stevens (교신) | Argonne National Laboratory

출처 · 2026-08-11 · preprint(미동료심사) · [arXiv:2608.11444](https://arxiv.org/abs/2608.11444) · [code](https://github.com/JDACS4C-IMPROVE)

**선택 이유** 약물반응 예측(DRP) 모델들이 서로 다른 전처리·분할·평가 지표를 써서 논문 간 비교가 사실상 불가능하다는 문제를, Argonne 국립연구소가 53,949개 화합물 · 5.4M 측정값의 표준화 공개 데이터로 직접 공략했다. 커뮤니티 인프라 기여 측면에서 이번 주 신약AI 분야 논문 중 파급력이 가장 넓게 미칠 것으로 보인다.

사회적 신호: 없음

**Key Point** PharmacoDB를 중심으로 여러 소스를 통합해 53,949개 화합물 · 5,455,444개 약물반응 측정값을 IMPROVE 표준 스키마로 구성·공개한다. UNO 모델 기준 unseen-drug R²가 0.03에서 0.22로 향상됐고, unseen-cell-line R²는 0.60에서 0.58로 거의 변화가 없었다(원문 기준).

**💡 인사이트** unseen-drug R²의 개선은 신약 발굴 관점에서 의미 있지만, unseen-cell-line 성능이 거의 그대로라는 점은 데이터 규모 이외의 요인—오믹스 피처 설계, 모델 아키텍처—이 세포주 수준 예측의 실제 병목임을 드러낸다. scaffold split 방식으로 평가했는지가 수치 해석의 핵심으로, 원문 확인이 필요하다.

🔬 Method: IMPROVE 표준 스키마, PharmacoDB 기반 53,949 화합물 · 5.4M 측정값 통합, UNO 모델 기준 unseen-drug R² 0.03→0.22 / unseen-cell-line R² 0.60→0.58 평가(원문 기준)

🩺 Clinical: 정밀 종양학(precision oncology)에서 환자 유전체 기반 약물 선택 예측의 인프라 기반 구축; 세포주 데이터와 실제 환자 종양 간 간극(cell line-patient gap)은 별도 임상 검증이 필요함

🏭 Industry: 공공 표준화 벤치마크가 사실상의 업계 기준이 되면 Recursion, Tempus AI, Foundation Medicine 등의 DRP 모델이 외부 검증 압박을 받게 됨; IMPROVE로 빠르게 자체 검증·공개한 기업이 투명성 선점 이점을 가짐

검증 수준: in silico (암 세포주 기반, preprint)

### 3. 단백질 구조 생성 AI의 "신규성"을 정량적으로 검문하다 (Is Retrieval All You Need? Assessment and Emergence of Novelty in Protein Structure Generation)

저자: Tongyue Xu (1저자), Cheng Tan (교신) | Zhejiang University 외

출처 · 2026-08-11 · preprint(미동료심사) · [arXiv:2608.10598](https://arxiv.org/abs/2608.10598) · 코드 미공개 — 재현 불가

**선택 이유** 단백질 구조 생성 모델이 "신규 폴드를 만든다"는 주장의 측정 기준 자체를 도메인 검색률(DRR)로 정량적으로 검문하고, 훈련 없는 검색 기반 베이스라인이 경쟁적 성능을 냄을 보인 논문이다. 신약개발 R&D 관점에서 생성 모델 선택 기준 전체를 재검토하게 만든 이번 주 방법론 분야 핵심 논문이다.

사회적 신호: kiin.bio 뉴스레터 소개

**Key Point** "전체 체인 TM-score가 낮으면 신규 폴드"라는 기존 평가 관행이 도메인 수준 조합과 진짜 신규 폴드를 구별하지 못한다는 허점을 지적하고, CATH S40 기준 도메인 검색률(DRR, Domain Retrieval Rate)을 제안한다. 8개 확산·흐름 매칭 생성 모델을 DRR로 재평가하면 대부분 출력물에서 기존 도메인과 국소 정렬 가능한 구조가 발견됐다. 훈련 없는 RetFold는 CPU만으로 학습 기반 모델 대비 약 1/100 계산 비용으로 82개 CATH topology · 143개 superfamily에 걸쳐 경쟁적 다양성을 달성한다고 보고한다(검색 결과 기반; 원문 직접 확인 권장).

**💡 인사이트** RetFold가 학습 기반 모델과 경쟁한다는 결과는, 현재 확산·흐름 매칭 모델들이 주로 기존 구조의 더 나은 조합 작업을 하고 있을 가능성을 시사한다. "진짜 신규 폴드"의 정의와 측정 방식에 대한 분야 수준의 합의가 필요하다는 압박이 이 논문 한 편으로 구체화됐다.

🔬 Method: DRR(CATH S40 대비 국소 정렬 기반 도메인 신규성 지표) + RetFold(훈련 불필요, CATH 도메인 검색·조합 + 헬릭스 링커 최적화); 8개 확산·흐름 매칭 모델 재평가

🩺 Clinical: 신규 단백질 구조의 신규성 주장이 신약 파이프라인 진입 결정에 영향을 주므로, 허술한 평가 기준은 전임상 전략 오판으로 간접 연결될 수 있음

🏭 Industry: Generate Biomedicines, Xaira Therapeutics 등 신규 폴드 생성을 핵심 가치 제안으로 삼는 기업들의 주장이 DRR 기준으로 재검토 대상이 됨; 파마 파트너십·VC 평가 체계에 DRR 추가 검토 권장

검증 수준: in silico (CATH S40 데이터베이스 기반, preprint)

### 4. 코호트 규모 구조적 변이 검출을 Nextflow로 표준화하다 (SVPLEX: A Nextflow Pipeline for Cohort-level Structural Variant Calling)

저자: Jacob E. Munro (1저자), Melanie Bahlo (교신) | Walter and Eliza Hall Institute of Medical Research (WEHI), 호주

출처 · 2026-08-12 · preprint(미동료심사) · [arXiv:2608.11621](https://arxiv.org/abs/2608.11621) · [code](https://github.com/bahlolab/SVPLEX) (MIT 라이선스, 2026-08-13 최근 업데이트)

**선택 이유** WEHI가 실제 희귀질환 코호트 연구 환경에서 개발한 Nextflow 기반 SV 검출 파이프라인으로, 6개 검출기 통합 · 합의 필터링 · MIT 오픈소스 공개의 조합으로 이번 주 바이오인포 분야에서 즉시 활용 가능성이 가장 높다.

사회적 신호: 없음

**Key Point** 단편 읽기(short-read) WGS에서 6종의 구조적 변이(structural variant, SV) 검출기를 단일 Nextflow 워크플로로 통합하고, 삭제(deletion) · 중복(duplication) 콜에 읽기 깊이 변화 확인을 필수 필터로 추가해 위양성을 제거한다. 코호트 단위 합의 콜셋으로 기술적 아티팩트를 줄이며 로컬·HPC·클라우드 이식성이 보장된다. 구체 민감도·특이도 수치는 초록 수준에서 미명시로 원문 확인이 필요하다.

**💡 인사이트** 6개 검출기 통합은 계산 자원을 상당히 요구하지만, 합의 기반 필터링의 위양성 감소 효과는 경험적으로 잘 뒷받침된다. 장읽기(long-read) 전환 계획이 있는 연구실이라면 이 파이프라인의 유효 기간을 채택 전에 가늠해 두는 것이 합리적이다.

🔬 Method: 6종 SV 검출기 통합 + 합의 기반 필터링 + 읽기 깊이 변화 확인; Nextflow 기반 재현·확장성 워크플로; MIT 오픈소스

🩺 Clinical: 희귀 유전 질환 진단에서 SNP 기반 검사가 놓치는 SV 부담을 포착하는 핵심 단계; 임상 유전체 검사실 배포까지 CLIA/ISO 수준의 민감도·특이도 검증과 IVD 규제 경로가 남아 있음

🏭 Industry: GeneDx(NASDAQ: WGS) 등 희귀질환 유전체 진단 기업의 파이프라인 표준화 비용 절감에 기여; Illumina DRAGEN과 보완 또는 경쟁 관계

검증 수준: in silico (파이프라인 기능 검증, 외부 벤치마크 수치 미명시, preprint)

### 5. 리간드 결합 부위 유사도 검색을 잠재 공간으로 옮기다 (LEN-Seek: Fast and scalable ligand binding-site similarity search in the latent space of an SE(3)-invariant graph VAE)

저자: Kyunghwan Yeo (1저자), Juyong Lee (교신) | 소속 기관 미확인

출처 · 2026-08-14 · preprint(미동료심사) · [DOI: 10.64898/2026.08.14.744759](https://doi.org/10.64898/2026.08.14.744759) · 코드 미공개 — 재현 불가

**선택 이유** 리간드 결합 부위 유사도 검색이 신약 재창출(drug repurposing)과 표적 발굴(target identification)의 계산 병목인데, AlphaFold DB 규모(~2억 구조) 시대에 3D 구조 정렬 대신 잠재 벡터 검색으로 우회하는 방향이 실용적 수요를 직접 겨냥한다.

사회적 신호: 없음

**Key Point** SE(3)-불변(회전·이동 불변) 그래프 VAE로 결합 부위의 3D 형태와 화학 환경을 잠재 벡터로 인코딩하고, 잠재 공간 내 유클리드 거리로 유사도를 계산한다. 구조 정렬 대신 벡터 검색을 써서 수백만 개 결합 부위 대상 대규모 스크리닝이 가능하다고 주장하지만, 성능 수치 · 비교 베이스라인 · 코드 공개 여부 모두 bioRxiv 직접 접근 차단으로 이 분석 시점에서 확인하지 못했다.

**💡 인사이트** 잠재 공간 검색의 핵심 가정은 "기능적으로 유사한 결합 부위가 잠재 공간에서도 가깝게 위치한다"는 것이다. 이 가정이 알로스테릭 부위(allosteric site) 같은 비전형 결합 부위에서도 성립하는지는 downstream 태스크 검증 없이 판단하기 어렵다. 코드 공개 후 재평가 대상으로 플래그를 달아둔다.

🔬 Method: SE(3)-불변 그래프 VAE 기반 잠재 벡터 인코딩 + 유클리드 거리 유사도 검색; 성능 수치·비교 방법·데이터셋 규모 원문 확인 필요

🩺 Clinical: 신약 재창출과 교차 반응성(cross-reactivity) 예측의 계산 효율화 가능성; 생화학 결합 어세이·동물 모델 검증까지 여러 단계가 남아 있음

🏭 Industry: Schrödinger RBSS(2026-3 릴리스)와 직접 경쟁 방향; 제약사 CADD 팀의 초기 타깃-화합물 필터링 수요에 닿음; 코드 공개와 독립 성능 검증 후 실용화 경로 판단 가능

## Deep Dive

### RetFold와 DRR: "신규 단백질 폴드"의 기준을 다시 세우다

단백질 구조 생성 AI는 지난 몇 년 사이 RFdiffusion, FrameDiff, Genie 등 확산(diffusion) · 흐름 매칭(flow matching) 기반 모델들이 잇달아 등장하면서 "AI가 자연에 없는 새로운 단백질 구조를 설계할 수 있다"는 서사가 분야를 지배해 왔다. 이 주장의 근거로 흔히 쓰인 지표가 전체 체인 TM-score다. TM-score가 낮으면 자연 단백질과 유사도가 낮다, 즉 신규하다는 논리다.

arXiv:2608.10598이 건드리는 것은 이 논리의 빈틈이다. 전체 체인 TM-score가 낮더라도, 그 구조를 도메인 단위로 쪼개보면 각 도메인 하나하나는 이미 CATH 데이터베이스에 존재하는 것일 수 있다. 도메인들이 이전에 없던 방식으로 연결됐을 때 전체 체인 TM-score는 낮아지지만, 이것을 "신규 폴드"라고 부를 수 있는지는 전혀 다른 문제다. TM-score는 전체 구조를 한 번에 비교하므로, 도메인 수준의 재조합을 진짜 신규 폴드와 구별하지 못한다.

**DRR(Domain Retrieval Rate)** 은 이 허점을 메우는 지표다. 생성된 백본에서 각 부분을 CATH S40 데이터베이스의 기존 도메인과 국소 정렬(local alignment)로 비교해, 기존 도메인과 정렬 가능한 비율을 측정한다. DRR이 높으면 생성 모델의 출력물이 기존 도메인 조합으로 구성돼 있다는 의미다. 8개 확산·흐름 매칭 모델을 이 지표로 재평가하면, 대부분 모델의 출력물에서 CATH S40 내 기존 도메인과 국소 정렬 가능한 구조가 발견됐다(초록 기준).

**RetFold** 는 이 논문의 두 번째 기여다. 훈련이 전혀 필요 없는 베이스라인으로, CATH 도메인을 검색해 조합하고 도메인 간 연결을 helix-linker 형태 최적화로 다듬는다. GPU 없이 CPU만으로 실행되고, 학습 기반 모델 대비 약 1/100 계산 비용으로 82개 CATH topology · 143개 superfamily에 걸쳐 경쟁적 다양성을 달성한다고 보고한다. 평균 쌍별 qTM은 0.18이다(검색 결과 기반; 원문 직접 확인 권장).

이 결과가 불편한 이유는 RetFold 자체도 기존 도메인 조합이기 때문이다. 학습 기반 생성 모델들이 RetFold와 경쟁적 성능을 낸다면, 그 모델들도 근본적으로는 기존 구조의 더 나은 조합 작업을 하고 있다는 해석이 성립한다. "AI가 자연에 없는 구조를 만든다"는 주장은 적어도 DRR 기준으로는 대부분 모델에서 아직 검증되지 않은 것이다.

**관전 포인트** 는 세 가지다.

첫째, DRR의 "국소 정렬 허용 임계값" 설정이 결과에 크게 영향을 미칠 수 있다. 임계값이 느슨하면 DRR이 과도하게 높아진다. 이 설정 기준이 원문에 명시됐는지 확인이 필요하다.

둘째, CATH S40이 단백질 구조 공간 전체를 커버하지 않으므로 DRR이 낮다고 해서 반드시 "진짜 신규 도메인"을 의미하지는 않는다. CATH에 수록되지 않은 구조가 존재할 수 있고, 그 경우 낮은 DRR이 "신규"를 의미하는 건지 "CATH 미수록"을 의미하는 건지 구별이 어렵다.

셋째, 코드가 공개되지 않아 DRR 계산을 직접 재현할 수 없다. 이 지표를 실제 평가에 활용하려면 Foldseek 같은 구조 검색 도구를 조합해 직접 구현하거나 코드 공개를 기다려야 한다.

R&D 리더 관점에서 이 논문의 함의는 두 가지로 요약된다. 하나, 단백질 생성 AI 플랫폼을 평가하거나 파트너십을 고려할 때 TM-score만으로 신규성을 판단하는 것은 충분하지 않다. DRR을 포함한 도메인 수준 검색 지표가 내부 평가 체계에 추가돼야 한다. 둘, "훈련 없는 검색 기반 방법이 경쟁적 성능을 낸다"는 사실은 학습 기반 모델들이 실제로 어디서 차별 가치를 만드는지를 더 명확히 정의하라는 압박이기도 하다. 더 나은 도메인 조합인가, 더 빠른 설계인가, 아니면 진짜 신규 폴드 생성인가.

preprint 단계이므로 DRR 지표 정의와 RetFold 구현이 동료심사 후 변경될 가능성이 있다. 수치를 직접 인용하기보다 "DRR이라는 개념과 검색 기반 베이스라인이 등장했다"는 방법론적 맥락으로 우선 기록하고, 코드 공개와 동료심사를 기다리는 것이 적절하다.

## Threads to Follow

- **단백질 생성 AI 신규성 기준 재정립**: RetFold/DRR(arXiv:2608.10598)이 제기한 "진짜 신규 폴드의 정의"는 W32의 EpiBench(arXiv:2608.06022)가 "LLM이 에피토프를 안다는 것의 기준"을 물었던 것과 같은 흐름이다. 두 논문 모두 새 알고리즘 없이 기존 주장의 근거를 정량적으로 검문하는 방법론 비판 작업이다. 이 패턴이 연속으로 이어지고 있다.

- **약물반응 예측 데이터 인프라의 공공화**: IMPROVE 데이터(arXiv:2608.11444)는 W32 THBKG(arXiv:2608.05982)의 시간 인식 KG와 같은 축에 놓인다. 두 작업 모두 DRP·타깃 발굴 AI의 벤치마크 분절이라는 고질적 문제를 데이터 수준에서 직접 공략한다. IMPROVE 기반 unseen-drug R² 0.22라는 현재 상한을 다음 세대 모델들이 어떻게 뚫는지가 다음 체크포인트다.

- **단일세포 주석의 생물학 사전지식 통합 방향**: scKanFormer(PLOS CB)가 경로 마스크를 어텐션에 주입하는 설계를 동료심사로 공식화했다. W32에서 단일세포 파운데이션 모델의 스케일링 법칙(arXiv:2608.02961)이 "어떻게 훈련할 것인가"를 물었다면, scKanFormer는 "어떤 생물학 구조를 아키텍처에 심을 것인가"를 묻는다. 두 방향의 교차가 다음 세대 단일세포 AI 설계 공간을 만든다.

- **Short-read WGS 파이프라인의 현재 최선**: SVPLEX(arXiv:2608.11621)는 단편 읽기 기반 SV 검출 파이프라인의 현재 최선을 Nextflow로 정리한 작업이다. 장읽기(long-read) 시퀀싱이 가격 경쟁력을 갖춰가는 속도를 고려하면, Sniffles · PBSV 등 long-read SV 도구와의 병렬 벤치마크가 다음 관심사다.
