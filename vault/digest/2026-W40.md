### C1. 화학·단백질 언어 모델의 위계적 교차 어텐션을 통한 약물-표적 상호작용 예측 (Drug-Target Interaction Prediction via Hierarchical Sequential Cross-Attention over Chemical and Protein Language Models)

저자: 저자·소속 미확인

arXiv · 2026-09-28 · [preprint(미동료심사)] · [DOI](https://arxiv.org/abs/2609.34921) · 코드 미공개 — 재현 불가

**선택 이유** 화학 LM과 단백질 LM을 위계적 순차 교차 어텐션으로 융합한 DTI 예측 방법론으로, 신약개발 타깃 발굴 파이프라인 전단에 파운데이션 모델 표현을 이식하는 경로를 구체적으로 제시한다.

사회적 신호: spaceship/newDailyArxiv W40 약물 분야 목록 수록 (순위 미확인); HF Daily Papers 확인 불가

**Key Point** SMILES 기반 화학 LM과 단백질 서열 LM 두 인코더를 위계적 순차 교차 어텐션(hierarchical sequential cross-attention)으로 이어 분자 수준과 서열 수준에서 표현을 계층적으로 융합한다. 구체적 벤치마크 수치와 비교 베이스라인은 원문 직접 확인 필요.

**💡 인사이트** 두 모달리티를 계층적으로 교차시키는 구조는 개념적으로 타당하지만, 3D 결합 포켓 정보 없이 서열만으로 DTI를 예측하는 한계는 이 논문도 피하기 어렵다 — 코드와 외부 검증 없이는 기존 DTI 방법(ConPLex, DeepDTA 등) 대비 우위를 확인할 방법이 없다.

🔬 Method SMILES 화학 LM + 단백질 서열 LM 위계적 교차 어텐션 융합; 평가 데이터셋·성능 수치 미공개

🩺 Clinical 가상 스크리닝 초기 단계 보조 도구. in silico 성능이 실험 히트율로 이어지는 근거 없음

🏭 Industry 저분자 신약 타깃 발굴 단계; 중소 바이오텍 내부 스크리닝 파이프라인 통합 가능성; 외부 맥락: Insilico Medicine·BenevolentAI 등 기존 플레이어와 경쟁 공간

검증 수준: in silico

### C2. 진화 정보 기반 토크나이저로 효율적인 단백질 언어 모델 구축 — LEMON-ZEST (LEMON-ZEST: Evolution-Informed Tokenization for Efficient Protein Language Modeling)

저자: Team-LEMON (저자 명단 미확인, 익명 제출 이력 있음)

arXiv · 2026-09-29 · [검토필요: NeurIPS 2026 제출, 채택 미확인(웹검색 교차 불가 — 본문 확인 필요)] · [DOI](https://arxiv.org/abs/2609.37675) · [code](https://huggingface.co/Team-LEMON/lemon)

**선택 이유** 검토필요: NeurIPS 2026 채택 주장(미확인)과 HuggingFace 모델 공개를 동시에 달성한 이번 주 유일한 논문으로, 단백질 LM 토크나이징 문제에 진화 정보를 직접 주입하는 방법론을 즉시 재현·활용할 수 있다.

사회적 신호: 검토필요: NeurIPS 2026 제출 확인, 채택 미확인(웹검색 불가 — 본문 확인 필요); HuggingFace 모델 공개 확인

**Key Point** ZEST(Zoned Encoding of Sequence Traits) 토크나이저가 BLOSUM/PAM 치환 행렬 기반의 생화학적으로 치환 가능한 아미노산 n-gram 클러스터를 greedy max-match trie 알고리즘으로 32K 어휘로 구성한다. 24-레이어 트랜스포머(768-d, 헤드 12개, 203.72M 파라미터)가 이 어휘로 단백질 패밀리·폴드 유사도 검색 성능을 높인다.

**💡 인사이트** 기존 단백질 LM은 통계적 공출현 기반 어휘를 써왔지만, ZEST는 진화적 보존 패턴을 어휘 설계 자체에 반영한다. 생물학적 사전지식이 토큰 경계를 결정한다.

🔬 Method 32K ZEST 어휘 + 203.72M 파라미터 트랜스포머; 추정: SCOP/CATH 기반 패밀리·폴드 검색 벤치마크; 토크나이저 학습 코드·사전학습 데이터 공개 여부 미확인

🩺 Clinical 직접 임상 적용 없음(인프라 레이어). 항체 설계·타깃 발굴의 단백질 임베딩 백본으로 간접 기여 가능

🏭 Industry HuggingFace 공개 모델 → 중소 바이오텍의 단백질 서열 검색·클러스터링 파이프라인 즉시 적용 가능. 203M 파라미터 규모로 ESM-2보다 진입 비용이 낮다.

검증 수준: in silico (검토필요: NeurIPS 2026 동료심사 완료 미확인 — 본문 확인 필요)

### C3. 단백질 지향 진화를 위한 구조 인식 강화학습 (Structure-aware Reinforcement Learning for Protein Directed Evolution)

저자: 저자·소속 미확인

arXiv · 2026-09-30 · [preprint(미동료심사)] · [DOI](https://arxiv.org/abs/2609.39048) · 코드 미공개 — 재현 불가

**선택 이유** AlphaFold2 이후 저비용 구조 예측이 가능해진 환경을 활용해, RL 기반 서열 탐색에 3D 구조 피드백을 통합한 단백질 공학 방법론으로 신약 타깃 단백질 최적화 파이프라인에 직접 닿는다.

사회적 신호: spaceship/newDailyArxiv 단백질 분야 신착 목록 수록; HF Daily Papers 확인 불가

**Key Point** 단백질 서열 공간을 탐색하는 RL 프레임워크에 3D 구조 예측 모델의 출력을 보상 신호 또는 상태 표현으로 통합한다. 서열 공간만 탐색하던 기존 방법과 달리 구조적 실현 가능성을 탐색 단계에서 직접 제약한다고 주장한다. 평가 단백질 계열·베이스라인·구체 수치는 원문 확인 필요.

**💡 인사이트** 구조 오라클(추정: ESMFold/AlphaFold3)을 RL iteration마다 호출하는 계산 비용이 실용화의 첫 번째 병목이 될 것인데, 코드가 공개되기 전까지는 그 비용 구조조차 가늠하기 어렵다.

🔬 Method 구조 인식 RL 프레임워크; 추정: ESMFold/AlphaFold3 구조 오라클 연동; 코드·벤치마크 미공개

🩺 Clinical 항체·효소 최적화 후보 탐색 가속 목적. 계산 최적화 결과가 실험 검증·임상 기능으로 이어지는 근거 없음

🏭 Industry 항체 엔지니어링 CRO·효소 설계 기업의 라운드당 실험 비용 절감 가능성; 외부 맥락: Absci(ABSI) 등 구조 인식 단백질 설계 플레이어와 경쟁 공간

### C5. 전자 건강 기록에서 연속적 환자 궤적 학습 — EHRFlow (Learning Continuous Patient Trajectories from Electronic Health Records)

저자: 저자·소속 미확인 (GitHub: PKU-AICare/EHRFlow 레포 존재 확인 — 내용 미확인)

arXiv · 2026-09-28 · [preprint(미동료심사); ML4H 2026 Proceedings Track 제출] · [DOI](https://arxiv.org/abs/2609.36144) · 코드 미공개 (PKU-AICare/EHRFlow 레포 존재 — 내용 미확인)

**선택 이유** EHR 시계열 모델링에 multi-marginal flow matching을 처음 도입해 불규칙 관측 시점 문제를 수학적으로 정면 돌파하며, 이번 주 핵심 5편 중 실제 임상 데이터(100만 명+)를 사용한 유일한 후향 검증 논문이다.

사회적 신호: ML4H 2026 Proceedings Track 제출 확인; HF Daily Papers 확인 불가

**Key Point** 인코딩된 환자 과거 기록을 조건으로 다중-마진 플로우 매칭(multi-marginal flow matching)이 관측된 여러 시점의 경계 분포(marginals)를 동시에 만족하는 연속 확률 경로(probability path)를 학습한다. 임의 시점 예측과 불규칙 관측 처리를 단일 프레임워크로 다루며, 100만 명 이상 실제 임상 데이터셋에서 임상 코드 예측과 잠재 상태 복원 성능 개선을 주장한다(초록 기준, 검토필요: 기관·데이터 거버넌스 원문 확인 필요).

**💡 인사이트** 100만 명 이상 규모 후향 검증은 이번 주 핵심 5편 중 현실 세계와 가장 가깝지만, 서로게이트 지표(임상 코드 예측 정확도)가 실제 임상 결과 개선을 보장하지는 않는다 — 전향 검증과 설명 가능성 설계 없이 CDSS로 배포하는 것은 이르다.

🔬 Method Multi-marginal flow matching; 불규칙 EHR 시계열 연속 확률 경로 모델링; 임상 코드 예측·잠재 상태 복원 평가; 구체 베이스라인·수치 미공개

🩺 Clinical 후향적 (N=100만+, 단일 기관 추정). 전향 검증·임상 유용성 연구 없음. CDSS 배포 전 규제(FDA/CE-IVDR) 경로 필수

🏭 Industry 빅파마 RWE(실제 세계 증거)팀·병원 시스템의 고위험 환자 조기 식별 시나리오; 외부 맥락: Tempus AI(TMPS) 등 EHR 예측 플랫폼과 경쟁 공간

## Deep Dive

### LEMON-ZEST: 단백질 언어 모델 토크나이징의 구조적 전환

단백질 언어 모델(pLM) 연구의 오랜 전제 하나가 흔들렸다. ESM-2 계열을 포함한 기존 pLM은 아미노산 한 글자 토크나이징 또는 BPE(Byte Pair Encoding)를 써왔다. NLP에서 검증된 데이터 기반 어휘 구성 전략이지만, 단백질 서열에서는 맹점이 있다 — 진화적으로 기능이 동등한 아미노산 집합(예: BLOSUM 치환 허용 군)이 어휘 경계에서 무작위로 분절되거나 무의미한 조합으로 묶인다.

LEMON-ZEST는 이 문제에 정면으로 접근했다. ZEST(Zoned Encoding of Sequence Traits) 토크나이저는 BLOSUM/PAM 치환 행렬에서 정의된 생화학적 치환 허용 아미노산 n-gram 클러스터를 greedy max-match trie 알고리즘으로 32K 어휘로 구성한다. "진화 정보를 어휘 설계에 직접 주입"한다는 아이디어가 이 연구의 출발점이다. 모델이 학습 중에 패턴을 조정하기 전에, 생물학적 사전지식이 이미 토큰 경계를 결정한다.

아키텍처는 24-레이어 트랜스포머(768-d, 헤드 12개, 203.72M 파라미터)다. ESM-2 650M 대비 훨씬 작은 규모이면서도 단백질 패밀리·폴드 유사도 검색 성능을 높인다고 주장한다. NeurIPS 2026에 제출됐고(검토필요: 채택 미확인 — 웹검색 교차 불가, 본문 확인 필요), HuggingFace(Team-LEMON/lemon)에 모델을 공개했다.

**관전 포인트:**

ZEST 어휘 자체의 재현성이 첫 번째 관문이다. BLOSUM 치환 행렬 선택과 n-gram 클러스터링 파라미터가 어떻게 결정됐는지, 토크나이저 학습 코드가 별도로 공개됐는지가 추가 검증의 핵심이다. 두 번째는 ESM-2와의 공정한 ablation 여부 — 아키텍처와 학습 데이터를 고정한 상태에서 ZEST 어휘 사용 유무만 비교한 결과가 논문에 있는지 원문 확인이 필요하다. 어휘 설계 개선의 순수 기여를 분리하지 않으면 신규성 주장이 약해진다. 세 번째는 극단적 비전형 서열에서의 한계다 — 극단호성 미생물 단백질이나 비표준 아미노산이 포함된 서열에서 32K 고정 어휘가 충분한지는 미확인이다.

현 시점 가장 빠른 활용 경로: HuggingFace 공개 모델을 단백질 패밀리 분류·서열 검색 파이프라인에 즉시 적용하고 ESM-2와 직접 비교 실험을 진행하는 것이다.

### EHRFlow: 불규칙 EHR 시계열에 플로우 매칭을 처음 도입하다

EHR 기반 임상 ML에서 관측 시점의 불규칙성은 오랜 기술적 골칫거리였다. 환자는 정해진 간격이 아니라 임상 상태가 변할 때 측정되고, 기존 RNN·트랜스포머 기반 모델은 이 불규칙 시계열을 고정 간격으로 리샘플링하거나 마스킹해 처리했다. 정보 손실 없이 임의 시점 예측까지 지원하는 통일 프레임워크가 없었다.

EHRFlow는 flow matching을 이 문제에 적용했다. multi-marginal flow matching은 관측된 여러 시점의 경계 분포(marginals)를 동시에 만족하는 연속 확률 경로를 학습하고, 인코딩된 환자 과거 기록이 조건 신호가 되어 임의 미래 시점의 임상 상태 분포를 샘플링할 수 있다. 이론적으로 불규칙 관측 시간과 임의 시점 예측을 단일 프레임워크로 처리하는 구조다. 외부 맥락: EHR 시계열에 flow matching을 적용한 선행 연구(TFM, arXiv:2410.21154; IMMFM, arXiv:2510.03569)가 있으나, EHRFlow의 EHR 도메인 특화 차별점은 원문 확인 필요.

100만 명 이상 실제 임상 데이터셋에서 임상 코드 예측과 잠재 상태 복원 성능 개선을 주장한다(초록 기준). 임상 ML 논문 중 드문 규모다. 다만 검토필요: 기관 출처·데이터 거버넌스·기간·입원/외래 구분은 원문 직접 확인 전까지 불명이다.

**한계와 다음 단계:**

연속 경로 가정이 임상 현실과 어긋나는 경우가 있다. 패혈증 발현이나 급성 심근경색처럼 임상 상태가 불연속적으로 전환되는 사건에서 연속 확률 경로 모델이 얼마나 잘 작동하는지는 별도 검증이 필요하다. 악화 시 관측이 더 자주 일어나는 편향(informative missingness)을 multi-marginal 설계가 충분히 처리하는지도 원문에서 확인해야 할 사항이다. 단일 기관 후향 코호트 한계도 여전하다.

ML4H 2026 동료심사 결과가 이 논문의 다음 신뢰도 지표다. PKU-AICare/EHRFlow 레포의 코드 내용 공개 여부와 학습 데이터 접근 경로가 재현 및 외부 검증의 병목이다.

## 🔭 Wide Angle

**W1. CAGenMol-2: 마스크드 분자 추론으로 재정의한 약물 설계 (CAGenMol-2)** · [arXiv:2609.34301](https://arxiv.org/abs/2609.34301) · preprint(미동료심사) · 코드 미공개

하나의 분자 서열에서 마스킹-언마스킹을 반복해 다양한 화학적으로 유효한 분자를 생성하는 조건부 추론 패러다임을 제안한다. 추정: 전작 CAGenMol(ACL 2026 Findings)의 후속으로 추론 단계의 다양성 확장에 집중한 것으로 보인다. 코드·수치 미공개로 방법 세부 확인 불가. 분자 생성 다양성 주장의 실질 가치는 Insilico Medicine Chemistry42 등 기존 생성 분자 설계 플랫폼과 비교 실험이 나와야 드러날 것이다.

**W2. 전체 슬라이드 이미지를 동적 종양 미세환경 장(場)으로 모델링** · [arXiv:2609.34451](https://arxiv.org/abs/2609.34451) · 검토필요: NeurIPS 2026 제출(채택 미확인) · 코드 미공개

병리 전체 슬라이드 이미지(WSI)를 이산 패치 집합이 아닌 연속적 공간 장(continuous spatial field)으로 모델링해 종양 미세환경(TME)의 공간적 역학을 포착한다. 검토필요: NeurIPS 2026 채택이라고 기재됐으나 웹검색 교차 확인 불가 — 채택 사실 여부는 원문 직접 확인 필요. 면역항암제 바이오마커 개발에 직결되는 방향성으로, 외부 맥락: Paige AI·PathAI가 운영 중인 TME 분석 플랫폼과 경쟁·보완 관계다. 코드 공개 전까지 재현 불가.

**W3. AI 보조 유사분열상 계수로 복수 종양 유형에서 재현성·효율 향상** · [arXiv:2610.01813](https://arxiv.org/abs/2610.01813) · preprint(미동료심사) · 코드 미공개

이번 주 와이드 3편 중 임상 현장 접근성이 가장 높다. 유사분열상(mitotic figure) 계수는 유방암·연조직 육종 등 WHO 등급 기준에 포함된 일상 병리 업무로, AI 보조가 관찰자 간 변동성을 줄이면 직접 임상 이익이 있다. 복수 종양 유형 적용은 단일 적응증 제품 대비 규제 경로가 복잡하지만 시장 규모가 크다. 외부 맥락: Hamamatsu·Leica·Paige AI가 즉각 관심을 가질 수요자다. 미제공: 암종·병리의사 수·슬라이드 수 원문 확인 필요.
