▸ LEMON-ZEST: 단백질 언어 모델 토크나이징의 구조적 전환
단백질 언어 모델(pLM) 연구의 오랜 전제 하나가 흔들렸다. ESM-2 계열을 포함한 기존 pLM은 아미노산 한 글자 토크나이징 또는 BPE(Byte Pair Encoding)를 써왔다. NLP에서 검증된 데이터 기반 어휘 구성 전략이지만, 단백질 서열에서는 맹점이 있다 — 진화적으로 기능이 동등한 아미노산 집합(예: BLOSUM 치환 허용 군)이 어휘 경계에서 무작위로 분절되거나 무의미한
LEMON-ZEST는 이 문제에 정면으로 접근했다. ZEST(Zoned Encoding of Sequence Traits) 토크나이저는 BLOSUM/PAM 치환 행렬에서 정의된 생화학적 치환 허용 아미노산 n-gram 클러스터를 greedy max-match trie 알고리즘으로 32K 어휘로 구성한다. "진화 정보를 어휘 설계에 직접 주입"한다는 아이디어가 이 연구의 출발점이다. 모델이 학
아키텍처는 24-레이어 트랜스포머(768-d, 헤드 12개, 203.72M 파라미터)다. ESM-2 650M 대비 훨씬 작은 규모이면서도 단백질 패밀리·폴드 유사도 검색 성능을 높인다고 주장한다. NeurIPS 2026에 제출됐고(검토필요: 채택 미확인 — 웹검색 교차 불가, 본문 확인 필요), HuggingFace(Team-LEMON/lemon)에 모델을 공개했다.

▸ EHRFlow: 불규칙 EHR 시계열에 플로우 매칭을 처음 도입하다
EHR 기반 임상 ML에서 관측 시점의 불규칙성은 오랜 기술적 골칫거리였다. 환자는 정해진 간격이 아니라 임상 상태가 변할 때 측정되고, 기존 RNN·트랜스포머 기반 모델은 이 불규칙 시계열을 고정 간격으로 리샘플링하거나 마스킹해 처리했다. 정보 손실 없이 임의 시점 예측까지 지원하는 통일 프레임워크가 없었다.
EHRFlow는 flow matching을 이 문제에 적용했다. multi-marginal flow matching은 관측된 여러 시점의 경계 분포(marginals)를 동시에 만족하는 연속 확률 경로를 학습하고, 인코딩된 환자 과거 기록이 조건 신호가 되어 임의 미래 시점의 임상 상태 분포를 샘플링할 수 있다. 이론적으로 불규칙 관측 시간과 임의 시점 예측을 단일 프레임워크로 처리하는 구조
100만 명 이상 실제 임상 데이터셋에서 임상 코드 예측과 잠재 상태 복원 성능 개선을 주장한다(초록 기준). 임상 ML 논문 중 드문 규모다. 다만 검토필요: 기관 출처·데이터 거버넌스·기간·입원/외래 구분은 원문 직접 확인 전까지 불명이다.
