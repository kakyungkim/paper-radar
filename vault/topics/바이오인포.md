# 🗂 바이오인포 — 주제 지도(MOC)

## 핵심 흐름
(2026-W35 기준) W35 바이오인포는 장독취(long-read) RNA-seq의 확장성 문제 해결과 공간 전사체 파운데이션 모델의 교차 영역 적용이 핵심이다. Kouam 외(DOI:10.64898/2026.08.26.747213)의 SALRR은 인간 뇌 장독취 RNA-seq 데이터를 대규모로 처리하는 확장 가능 파이프라인으로, 이소폼(isoform) 수준 전사체 프로파일링에서 기존 처리 속도 한계를 넘는다. 뇌 전사체 장독취 연구(파킨슨병 등 신경질환)의 기반 도구로 활용 가치가 높으나, DOI 충돌 가능성이 있어 원문 확인이 필요하다. C1(GITIII-scale, arXiv:2608.26208)도 공간 전사체 분석 방법 측면에서 바이오인포 분야와 교차한다. W33의 아키텍처 혁신·파이프라인 표준화에서 W35는 장독취 확장성과 공간 전사체 분석 심화로 방향이 이동한다.

(이전) W33 기준 scKanFormer(Yuan 외, PLOS CB)의 KAN+Transformer 세포 유형 주석과 SVPLEX(Munro 외)의 코호트 수준 구조 변이(SV) 검출 파이프라인 표준화가 핵심이었다. 아키텍처 혁신과 변이 검출 인프라 재현성이 동시에 진전된 주차였다.
