# 🗂 바이오인포 — 주제 지도(MOC)

## 핵심 흐름
(2026-W33 기준) W33 바이오인포는 아키텍처 혁신과 파이프라인 표준화 두 방향이 선명하게 갈린다. scKanFormer(Yuan 외, DOI:10.1371/journal.pcbi.1014607)는 KAN(Kolmogorov-Arnold Network)과 Transformer를 결합하고 생물학적 사전 지식을 어텐션 구조에 주입해 대규모 단일세포 RNA-seq(scRNA-seq) 세포 유형 주석의 정확도와 해석 가능성을 동시에 높인다. SVPLEX(Munro 외, arXiv:2608.11621)는 Nextflow 기반 코호트 수준 구조 변이(SV, structural variant) 검출 파이프라인으로, 다양한 SV 검출기 앙상블과 코호트 통합 필터링을 표준화해 대규모 유전체 연구의 재현성을 높인다. W31의 에이전트 파이프라인 신뢰성 흐름에서 W33은 기반 아키텍처 개선과 변이 검출 인프라 표준화로 이동한다.

(이전) W31 기준 에이전트 파이프라인의 재현성과 신뢰성이 핵심 주제였다. SCTA(arXiv:2607.23821)는 scRNA-seq 표적 발굴 파이프라인의 재현성 결핍을 에이전트 전문화와 교차 실행 안정성 기준으로 처음 명시적으로 해결했다. 단일세포 클러스터링 벤치마크(arXiv:2607.25288, ISRSD 2026)는 Sobol 민감도 분석으로 딥러닝이 PCA보다 유의미하게 우위인 조건을 처음 정량화했다. FEV 프레임워크는 에이전트 바이오인포 시스템 109개를 신뢰성 3축으로 분류하는 공통 평가 언어를 제안했다.
