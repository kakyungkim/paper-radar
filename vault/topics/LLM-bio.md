# 🗂 LLM-bio — 주제 지도(MOC)

## 핵심 흐름
(2026-W32 기준) W32 LLM-bio는 생성·신호 추출·역량 평가 세 방향이 함께 전개된다. Sharipov 외(arXiv:2608.02961)의 자기회귀 단일세포 생성 트랜스포머는 세포 생성 영역에서 스케일링 법칙을 탐색하고, Lin 외(arXiv:2608.02688)는 세포 표현형에서 구조 보존형 분자 표현을 학습해 생물학적 신호를 약물 설계 공간과 연결한다. EpiBench(arXiv:2608.06022)는 에피토프 이해를 항체 설계에 특화된 LLM 역량 평가 축으로 제시한다. Datta 외(arXiv:2608.05329)는 frozen 유전체 LM의 표현을 레이어별로 분석해, 어떤 방식으로 표현을 꺼내 써야 유효한 신호를 얻는지를 진단한다. W31의 파운데이션 모델 심화에서 W32는 스케일링·신호 추출·진단이라는 실용적 단계로 이동한다.

(이전) W31 기준 CENO(Shanghai AI Lab)는 게놈 스케일 자기회귀 세계 모델로 DNA 이해·VEP·조절 서열 생성을 통합했고, EHR FM(Imperial College London)은 자기회귀 EHR 파운데이션 모델에 다중 임상 모달리티를 조건화하는 설계를 체계적으로 비교했다. FEV 프레임워크(arXiv:2607.27556)는 에이전트 바이오인포매틱스 109개 시스템을 신뢰성 3축으로 평가하는 기준을 제시했다. W31은 게놈·임상 영역으로의 파운데이션 모델 심화와 에이전트 신뢰성 평가가 동시에 진행된 주차였다.
