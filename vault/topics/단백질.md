## 2026-W41 핵심 흐름
W41 단백질 파트는 인과 특징 분리와 피트니스 공간 선형 구조화라는 두 방향이 공존한다. CausalBind(ICLR 2026 채택, arXiv:2610.07340)는 단백질-분자 교차-어텐션에서 결합에 인과적으로 관여하는 원자 개념만 희소 마스킹으로 분리하는 플러그인 접근이며, 가상 스크리닝 새 표적 일반화 병목에 직접 닿는다. Linear Fitness Subspace(EMNLP 2026 Findings, arXiv:2610.07607)는 단백질 언어 모델 표현 공간에서 피트니스가 선형 부분공간으로 포착된다는 가설 위에서 소수 실험 측정으로 지향 진화 탐색을 가능하게 하는 샘플 효율적 접근을 제안한다. 두 논문 모두 동료심사 완료(peer-reviewed)이나 코드 미공개다. W40의 토크나이징 전략 혁신과 구조 인식 RL에서 W41은 인과 특징 선별과 피트니스 공간 기하학이라는 새로운 방향이 추가된다.

# 🗂 단백질 — 주제 지도(MOC)

## 핵심 흐름
(2026-W40 기준) W40은 단백질 언어 모델의 토크나이징 전략 혁신(LEMON-ZEST)과 구조 인식 RL 기반 지향 진화(struct-rl-directed-evo)가 두 축이다. LEMON-ZEST는 아미노산 단위 토크나이징 한계를 생화학적으로 치환 가능한 n-gram 클러스터 기반 32K 어휘로 극복한 것이 핵심이다. 이는 기존 단백질 LM(ESM-2, ProtTrans 계열)이 단일 아미노산을 단위로 처리하던 방식에서 벗어나 언어 모델 표현의 생물학적 의미 단위를 재정의하는 시도다. struct-rl-directed-evo는 서열 공간 탐색에 구조적 선행 지식을 주입하는 방향이며, 신약 타깃 단백질 최적화 파이프라인과 직결된다.

## 타임라인
### 2026-W41 (2026-10-05~2026-10-11)
- [[causalbind-2026-W41]] — CausalBind: 단백질-분자 교차-어텐션+희소 마스킹으로 결합 인과 원자 개념 분리, 가상 스크리닝 새 표적 일반화, ICLR 2026 채택 ([arXiv](https://arxiv.org/abs/2610.07340))
  - 핵심: 플러그인 구조로 기존 파이프라인 유지하며 허위 상관 제거 단계 삽입; LIT-PCBA BEDROC·EF@1% 개선
  - 검증: in silico; 코드 미공개
- [[linear-fitness-subspace-2026-W41]] — Linear Fitness Subspace: PLM 표현 공간의 선형 피트니스 부분공간 가설 기반 샘플 효율적 지향 진화, EMNLP 2026 Findings ([arXiv](https://arxiv.org/abs/2610.07607))
  - 핵심: 소수 실험 측정으로 지향 진화 탐색 가능; 항체 affinity maturation 실험 비용 절감 가능성
  - 검증: 미확인 (추정 in silico + 소규모 in vitro; 초록 미확인); peer-reviewed

### 2026-W40 (2026-09-28~2026-10-04)
- [[lemon-zest-2026-W40]] — LEMON-ZEST: 진화 정보 기반 ZEST 토크나이저(32K 어휘)로 효율적 단백질 언어 모델 구축, NeurIPS 2026 채택, 모델 공개 ([arXiv](https://arxiv.org/abs/2609.37675))
  - 핵심: 생화학적 치환 가능 아미노산 n-gram 클러스터 기반 어휘 구성, 203M 파라미터 트랜스포머, 폴드 유사도 검색 성능 향상
  - 검증: in silico
- [[struct-rl-directed-evo-2026-W40]] — 단백질 지향 진화에 구조 인식 강화학습 적용 ([arXiv](https://arxiv.org/abs/2609.39048))
  - 핵심: RL 탐색 시 3차 구조 정보를 인코딩해 기능 향상 돌연변이 탐색 효율화, 서열-구조 공동 최적화
  - 검증: in silico
