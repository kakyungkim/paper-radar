## 2026-W40 핵심 흐름
W40 단백질 파트는 언어 모델 토크나이징 방식과 구조 제약 강화학습이라는 두 방향이 동시에 제출됐다. LEMON-ZEST(arXiv:2609.37675)는 진화적 보존 정보 기반 ZEST 토크나이저(32K 어휘, 아미노산 n-gram 생화학적 클러스터링)를 도입해 203M 파라미터 트랜스포머로 단백질 패밀리·폴드 유사도 검색 성능을 높이는 접근이다. NeurIPS 2026 채택 논문으로 HuggingFace에 모델 공개돼 재현 가능성이 높다는 점이 다른 논문과 차별화된다. struct-rl-directed-evo(arXiv:2609.39048)는 단백질 지향 진화(directed evolution)에 RL을 적용하면서 3차 구조 정보를 탐색 제약으로 통합한다. 두 방향 모두 in silico 단계이나, LEMON-ZEST의 NeurIPS 채택과 공개 모델은 즉시 활용 기준점으로 활용 가능하다.

# 🗂 단백질 — 주제 지도(MOC)

## 핵심 흐름
(2026-W40 기준) W40은 단백질 언어 모델의 토크나이징 전략 혁신(LEMON-ZEST)과 구조 인식 RL 기반 지향 진화(struct-rl-directed-evo)가 두 축이다. LEMON-ZEST는 아미노산 단위 토크나이징 한계를 생화학적으로 치환 가능한 n-gram 클러스터 기반 32K 어휘로 극복한 것이 핵심이다. 이는 기존 단백질 LM(ESM-2, ProtTrans 계열)이 단일 아미노산을 단위로 처리하던 방식에서 벗어나 언어 모델 표현의 생물학적 의미 단위를 재정의하는 시도다. struct-rl-directed-evo는 서열 공간 탐색에 구조적 선행 지식을 주입하는 방향이며, 신약 타깃 단백질 최적화 파이프라인과 직결된다.

## 타임라인

  - 핵심: 생화학적 치환 가능 아미노산 n-gram 클러스터 기반 어휘 구성, 203M 파라미터 트랜스포머, 폴드 유사도 검색 성능 향상
  - 검증: in silico
- [[struct-rl-directed-evo-2026-W40]] — 단백질 지향 진화에 구조 인식 강화학습 적용 ([arXiv](https://arxiv.org/abs/2609.39048))
  - 핵심: RL 탐색 시 3차 구조 정보를 인코딩해 기능 향상 돌연변이 탐색 효율화, 서열-구조 공동 최적화
  - 검증: in silico
