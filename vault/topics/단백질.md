## 2026-W43 핵심 흐름
W43 단백질 파트는 대규모 사전학습 전략 혁신과 다목적 최적화가 두 핵심이다. recAMPLIFY(arXiv:2610.26747)는 재귀적(recursive) 단백질 언어 모델의 대규모 사전학습 패러다임을 제시하며, 기존 단일 방향 자기회귀 PLM의 표현 한계를 재귀 구조로 극복하려는 시도다. ProtGlycanDock(arXiv:2610.26009)은 단백질-당 복합체 도킹 특화 영역에서 맞춤 데이터셋과 벤치마크를 구축해 구조 생물학의 빈 영역을 채운다. Multi-Objective Protein Optimization(arXiv:2610.28943)은 복수 목표를 동시 최적화하는 모듈형 확산 조향으로 단백질 공학 실용 파이프라인에 근접한다. W41의 인과 특징 분리·피트니스 공간 기하학에서 W43은 사전학습 규모 혁신·도킹 범위 확장·다목적 최적화로 전환된다.

# 🗂 단백질 — 주제 지도(MOC)

## 핵심 흐름
(2026-W40 기준) W40은 단백질 언어 모델의 토크나이징 전략 혁신(LEMON-ZEST)과 구조 인식 RL 기반 지향 진화(struct-rl-directed-evo)가 두 축이다. LEMON-ZEST는 아미노산 단위 토크나이징 한계를 생화학적으로 치환 가능한 n-gram 클러스터 기반 32K 어휘로 극복한 것이 핵심이다. 이는 기존 단백질 LM(ESM-2, ProtTrans 계열)이 단일 아미노산을 단위로 처리하던 방식에서 벗어나 언어 모델 표현의 생물학적 의미 단위를 재정의하는 시도다. struct-rl-directed-evo는 서열 공간 탐색에 구조적 선행 지식을 주입하는 방향이며, 신약 타깃 단백질 최적화 파이프라인과 직결된다.

## 타임라인
### 2026-W43 (2026-10-19~2026-10-25)
- [[recamplify-2026-W43]] — recAMPLIFY: 재귀적 단백질 언어 모델 대규모 사전학습, 기존 단일 방향 자기회귀 PLM 한계 극복 시도 ([arXiv](https://arxiv.org/abs/2610.26747))
  - 핵심: 재귀 구조로 장거리 의존성·계층적 서열 정보를 통합 사전학습; ESM/ProtTrans 계열 PLM 아키텍처 대안 제시
  - 검증: 추정 in silico (초록 미확인); preprint; 코드·라이선스 공개 여부 미확인
- [[protglycandock-2026-W43]] — ProtGlycanDock: 단백질-당 복합체 도킹 특화 데이터셋·벤치마크·모델 일괄 제시 ([arXiv](https://arxiv.org/abs/2610.26009))
  - 핵심: 소분자 도킹 특화 기존 도구의 당 처리 한계를 특화 학습으로 극복; 구조 기반 단백질 기능 연구 인프라 확장
  - 검증: in silico; peer-reviewed; 코드 공개 미확인
- [[multiobj-protein-diffusion-2026-W43]] — Multi-Objective Protein Optimization via Modular Diffusion Steering: 복수 목표 동시 최적화, 모듈형 확산 조향 ([arXiv](https://arxiv.org/abs/2610.28943))
  - 핵심: 치료 단백질 설계에서 친화도·안정성·특이성을 동시에 조향하는 모듈 구조; 단일 목표 최적화의 실용 한계 공략
  - 검증: 원문 미확인 (초록 재확인 권장); preprint; 코드 공개 미확인

### 2026-W41 (2026-10-05~2026-10-11)
- [[causalbind-2026-W41]] — CausalBind: 단백질-분자 교차-어텐션+희소 마스킹으로 결합 인과 원자 개념 분리, 가상 스크리닝 새 표적 일반화, ICLR 2026 채택 ([arXiv](https://arxiv.org/abs/2610.07340))

  - 검증: in silico; 코드 미공개
- [[linear-fitness-subspace-2026-W41]] — Linear Fitness Subspace: PLM 표현 공간의 선형 피트니스 부분공간 가설 기반 샘플 효율적 지향 진화, EMNLP 2026 Findings ([arXiv](https://arxiv.org/abs/2610.07607))
  - 핵심: 소수 실험 측정으로 지향 진화 탐색 가능; 항체 affinity maturation 실험 비용 절감 가능성
  - 검증: 미확인 (추정 in silico + 소규모 in vitro; 초록 미확인); peer-reviewed
