# 🗂 신약AI — 주제 지도(MOC)

## 핵심 흐름
(2026-W27 기준) Active-GRPO는 GRPO(Group Relative Policy Optimization) 강화학습을 LLM 기반 분자 최적화에 이식해 자기 개선 추론 루프를 신약 설계에 접목했다. MLP-GNN 가산 프레임워크는 수상 용해도(aqueous solubility) 예측에서 화학적·구조적 기여를 분리 정량화해 ADME 예측 해석 가능성을 높였다. W26의 타깃 발굴(유전 증거)·분자 생성(Molexar) 조합에서 W27은 분자 최적화 알고리즘(RL 기반)과 ADME 물성 예측(해석 가능 GNN)으로 포커스가 이동한다. 분자 설계 파이프라인 후반부 두 축이 같은 주에 나란히 진전됐다. 자율과학 AI 에이전트(DiscoPER)가 W27 와이드에 재등장해 W26 Robin에 이어 2주 연속 등장 중이다.

- **Active-GRPO: GRPO 기반 분자 최적화 자기 개선 추론(Liu 외)** — GRPO 강화학습으로 LLM 적응형 모방 학습과 자기 개선 추론을 분자 최적화에 적용. 코드 미공개. 미동료심사(preprint). 출처: [[digest/2026-W27]] | arXiv:2607.00531
- **MLP-GNN 수용해도 예측 프레임워크(Bhattacharya 외)** — 화학적(MLP) + 구조적(GNN) 기여를 분리하는 가산 프레임워크로 수상 용해도(aqueous solubility) 예측. ADME 해석 가능성 향상. 미동료심사(preprint). 출처: [[digest/2026-W27]] | arXiv:2607.02212
