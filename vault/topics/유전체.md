# 🗂 유전체 — 주제 지도(MOC)

## 핵심 흐름
(2026-W32 기준) W32 유전체는 단일세포 생성 모델의 스케일링과 기존 유전체 언어 모델의 표현 진단이 핵심이다. Sharipov 외(arXiv:2608.02961)는 자기회귀 트랜스포머를 단일세포 생성에 스케일업하며 세포 생성에서도 스케일링 법칙이 성립함을 실험적으로 검토한다. Datta 외(arXiv:2608.05329)는 사전학습된 유전체 언어 모델(genomic language model)의 표현이 항상 다운스트림 과제에 접근 가능하지는 않음을 보이며, 어떤 레이어·과제 조합에서 유용한 신호가 나오는지 진단한다. W31의 게놈 스케일 세계 모델(CENO) 등장에서, W32는 단일세포 생성의 스케일링과 기존 모델 표현 활용 진단이라는 실용적 방향으로 분화된다.

(이전) W31 기준 CENO(DOI:10.64898/2026.07.28.741284, Shanghai AI Lab)는 Mamba/Attention/MoE 하이브리드에 다중 종 MSA 사후 훈련을 더해 긴 DNA 서열 이해·VEP·조절 서열 생성을 단일 자기회귀 모델로 처리하며, 코드를 완전 공개했다. SCTA(arXiv:2607.23821)는 scRNA-seq 표적 발굴의 재현성 결핍을 에이전트 전문화로 해결했다. W31은 DNA 세계 모델이라는 새 개념이 등장한 주차였다.
