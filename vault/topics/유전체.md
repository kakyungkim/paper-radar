# 🗂 유전체 — 주제 지도(MOC)

## 핵심 흐름
(2026-W27 기준) Affinage(MIT)가 PubMed 전체 문헌에서 LLM으로 기계적 유전자 기능 주석(mechanistic gene annotation)을 자동 추출하는 파이프라인을 공개했다. 코드·API가 즉시 활용 가능한 몇 안 되는 논문으로, 유전체 기능 해석 워크플로우에 바로 통합 가능하다. Structured Gaussian Process는 고차원-소표본 오믹스 데이터의 불확실성 정량화를 다루며, 마이크로바이옴·전사체 등 데이터 빈곤 상황에 적용 범위가 넓다. W25-W26의 교란 반응 예측·희귀질환 변이 해석에 이어 W27에서는 문헌 지식의 자동 통합과 불확실성 인식 분류가 유전체 분석의 새 진입점으로 등장한다. 이번 주 코드 공개 논문은 Affinage 1편이다.
