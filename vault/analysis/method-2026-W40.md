### C1. Drug-Target Interaction via Hierarchical Sequential Cross-Attention
**원문**: Drug-Target Interaction Prediction via Hierarchical Sequential Cross-Attention over Chemical and Protein Language Models  
**출처**: arXiv:2609.34921 · 2026-09-28 · preprint, 미동료심사  
**링크**: https://arxiv.org/abs/2609.34921 | 코드: 미공개

**문제의식 선행**: 화학 LM(ChemBERTa 등 SMILES 기반)과 단백질 LM(ESM 계열)이 각각 독립적으로 발전했지만, 둘 사이의 **상호작용 정보를 어디서 어떻게 융합하느냐**가 DTI 예측 정확도의 병목이었다.

**무엇이 새로운가**  
단순 concatenation 또는 단층 cross-attention 대신 **위계적 순차(hierarchical sequential)** 교차 어텐션을 도입한다. 초록에 따르면 분자 수준과 단백질 서열 수준에서 표현을 계층적으로 융합한다 (초록 기준). 추정: "위계적"은 SMILES의 원자-서브구조-전체 분자 다중 스케일과 단백질의 잔기-도메인-전체 서열 다중 스케일을 대응시켜 교차 어텐션을 단계적으로 쌓는 구조일 가능성이 높다.

**핵심 가정**  
1. SMILES 표현이 약물 결합 특성을 충분히 포착한다 — 3D 형태 정보를 명시적으로 쓰지 않는 한, 유연한 분자(flexible ligand)나 토토머 처리에서 한계가 있다.  
2. 단백질 서열 LM 임베딩이 결합 포켓(binding pocket) 3D 구조를 대리(proxy) 표현한다 — 구조 기반 DTI 방법(예: AlphaFold 구조 사용)과 비교 시 서열-투-구조 간극이 가정에 내재한다.  
3. 교차 어텐션이 서열 상 관계 없는 위치 쌍에도 의미 있는 상호작용을 귀속할 수 있다 — 학습 데이터의 양·다양성 부족 시 과적합 위험.

**재현성**  
`미제공:` 코드 및 학습 데이터 미공개. 저자·소속 미확인 (초록 기준 정보 없음). 평가 데이터셋·베이스라인 비교 수치는 원문 직접 확인 전까지 알 수 없다.

**비교 대상 / 검증 수준**  
`미제공:` 구체 베이스라인·성능 수치 불명 (원문 확인 필요). 검증 수준: in silico. 외부 실험 검증 없음.

**강점**: 화학 LM + 단백질 LM 결합에서 단계적 어텐션 융합은 개념적으로 타당하다. 양 모달리티의 풍부한 pre-training 지식을 그대로 활용 가능.  
**한계**: 코드·수치 미공개로 실질적 검증 불가. 3D 구조 정보 부재. 서열 기반 DTI의 공통 약점인 신규 단백질 패밀리 일반화 문제가 해결됐는지 불명.

**내 연구 적용**  
타깃 발굴 초기 단계에서 가상 스크리닝 도구로 쓸 가능성이 있으나, 코드 공개 전까지 재현 불가. 유사한 cross-attention DTI 프레임워크(ConPLex, DTI-LM 등)와 비교 평가 후 채택 여부 결정 권장.

### C2. LEMON-ZEST: Evolution-Informed Tokenization for Protein Language Modeling
**원문**: LEMON-ZEST: Evolution-Informed Tokenization for Efficient Protein Language Modeling  
**출처**: arXiv:2609.37675 · 2026-09-29 · NeurIPS 2026 accepted, 동료심사 완료  
**링크**: https://arxiv.org/abs/2609.37675 | 모델: https://huggingface.co/Team-LEMON/lemon

**문제의식 선행**: 기존 단백질 LM(ESM-2 등)은 아미노산 단일 문자 토크나이징을 쓰거나 BPE 기반 토크나이저를 사용하는데, 이 방식은 **진화적으로 보존된 기능 단위(보존 모티프, 치환 허용 집합)를 무시**하고 통계적 공출현만으로 어휘를 구성한다.

**무엇이 새로운가**  
ZEST(Zoned Encoding of Sequence Traits) 토크나이저: BLOSUM/PAM 치환 행렬 등에서 정의된 **생화학적으로 치환 가능한 아미노산 n-gram 클러스터**를 기반으로 그리디 max-match trie 알고리즘으로 32K 어휘를 구성한다 (초록+모델 카드 기준, alphaneural.io 확인). 진화 정보를 토크나이징 단계에 직접 주입한다는 점에서 기존 BPE/SPM 방식과 근본적으로 다르다.

외부 맥락: 비슷한 방향의 선행 연구로 evoBPE(2024–2025, BPE+BLOSUM)가 있으나, LEMON-ZEST는 greedy max-match trie + 32K vocab + 24-layer 전체 LM 학습까지 통합한 완성형 파이프라인이다. 비교 분석은 원문 확인 필요.

**아키텍처**: 24-레이어 트랜스포머, 히든 768-d, 헤드 12개, 총 203.72M 파라미터 (raw 파일 수록 수치).

**핵심 가정**  
1. 진화적으로 보존된 아미노산 군이 기능적으로 등가 단위를 이루고, 이 경계가 토크나이징 경계로 적합하다 — 이 가정이 깨지면(예: 위치 특이적 치환 패턴이 강한 계열) ZEST 어휘가 부정확한 분절을 생성할 수 있다.  
2. 고정된 32K 어휘로 모든 단백질 패밀리를 균일하게 커버할 수 있다 — 극단적으로 비전형적인 서열(극단호성 미생물, 비표준 아미노산)에서 어휘 부족(out-of-vocab) 문제 발생 가능성.  
3. 토크나이저 개선만으로 다운스트림 검색·분류 성능이 향상된다 — 아키텍처·학습 데이터가 동일 조건으로 고정됐는지 ablation 확인 필요.

**재현성**  
HuggingFace 모델 허브에 공개 (https://huggingface.co/Team-LEMON/lemon). NeurIPS 2026 동료심사 통과로 이 주 논문 중 가장 높은 신뢰도. `미제공:` 토크나이저 학습 코드 및 사전 학습 데이터셋 공개 여부는 원문 확인 필요.

**비교 대상 / 검증 수준**  
`미제공:` 구체 벤치마크 수치 불명 (원문 확인 필요). 단백질 패밀리·폴드 유사도 검색(SCOP/CATH 기반으로 추정) 평가를 사용한다고 명시 (초록 기준). 검증: in silico.

**강점**: 생물학적 사전지식을 토크나이징에 직접 반영. NeurIPS 채택으로 방법론적 완성도 검증됨. 모델 즉시 사용 가능.  
**한계**: ZEST 어휘 구성 자체의 재현성(치환 행렬 선택·클러스터링 파라미터) 불명. 단백질 언어 모델 사전 학습 비용이 크므로 개인 재학습은 어렵다. 구조 기반 태스크(접힘 예측)에서의 성능 우위는 미확인.

**내 연구 적용**  
HuggingFace 공개 모델을 즉시 단백질 패밀리 분류·서열 검색 파이프라인에 사용 가능. 멀티오믹스 분석에서 단백질 임베딩 기반 특징 추출 백본으로 테스트 권장. ESM-2와 직접 비교 실험이 가장 중요한 다음 단계.

### C3. Structure-aware RL for Protein Directed Evolution
**원문**: Structure-aware Reinforcement Learning for Protein Directed Evolution  
**출처**: arXiv:2609.39048 · 2026-09-30 · preprint, 미동료심사  
**링크**: https://arxiv.org/abs/2609.39048 | 코드: 미공개

**문제의식 선행**: 기존 단백질 지향 진화 계산 방법은 서열 공간만을 탐색하거나 정적 구조 정보를 입력으로 쓰는데, 돌연변이에 따른 구조 변화를 **동적으로 피드백**하지 못한다는 병목이 있다.

**무엇이 새로운가**  
강화학습(RL) 기반 서열 탐색에 **단백질 3D 구조 예측 모델의 출력을 보상 신호(또는 상태 표현)로 통합**하는 구조 인식 프레임워크를 제안한다 (초록 기준). 추정: ESMFold 또는 AlphaFold3 기반 구조 예측을 RL 루프 내 보상 함수의 일부로 사용하는 구조일 가능성이 높다.

외부 맥락: 유사 방향의 2026년 논문으로 HADES(Hamiltonian dynamics + Bayesian optimization + 구조 피드백)와 RelaVDEP(GNN + RL + 피트니스 예측기)가 있다. C3와의 정확한 차별점은 원문 확인 필요.

**핵심 가정**  
1. 구조 예측 모델(구조 오라클)이 충분히 정확해 in silico 보상 신호로 쓸 수 있다 — 예측 오류가 누적되면 RL이 잘못된 방향으로 수렴(hallucinated fitness landscape).  
2. 서열→구조→기능의 인과 체인이 성립한다 — 기능이 구조로부터 단순하게 결정되지 않는 경우(IDR, allosteric 효과) 보상 설계가 부적절해진다.  
3. RL 탐색이 실험 가능한 서열 공간 내에서 유효 돌연변이를 생성한다 — 보상 해킹(reward hacking)으로 화학적 비현실 서열을 생성할 위험.

**재현성**  
`미제공:` 코드·데이터 미공개. 저자·소속 미확인. 구체 평가 단백질 계열·수치 불명.

**비교 대상 / 검증 수준**  
`미제공:` 베이스라인 비교·수치 확인 불가. 검증: in silico. 실험적 검증(wet-lab) 없음 (초록 기준).

**강점**: 구조 정보를 RL 루프에 통합하는 개념적 신규성. 서열 탐색 효율 개선 가능성.  
**한계**: 구조 오라클의 계산 비용이 크다 (RL iteration당 ESMFold 호출이면 step 비용 높음). 코드 미공개. 실험 검증 부재. 유사 연구 대비 차별점 불명확.

**내 연구 적용**  
신약 타깃 단백질 공학 파이프라인에서 보상 함수 설계 아이디어로 참고 가능. 코드 공개 및 외부 단백질 계열 검증 후 채택 검토 권장. 현재 단계에서는 HADES·RelaVDEP 등 코드 공개된 선행 방법과 비교 실험이 선행되어야 한다.

### C4. MoSPR: Histology-to-Gene Expression with Morpho-Spatial Macrostates
**원문**: MoSPR: Histology-to-Gene Expression Prediction with Morpho-Spatial Macrostates and Low-Rank Molecular Programs  
**출처**: arXiv:2609.34280 · 2026-09-28 · preprint, 미동료심사  
**링크**: https://arxiv.org/abs/2609.34280 | 코드: 미공개

**문제의식 선행**: 공간 전사체(spatial transcriptomics) 실험은 비용이 크고 동일 조직 절편에서의 반복이 어렵다. H&E 이미지는 모든 병리 파이프라인에 존재하는데, **H&E만으로 유전자 발현 공간 패턴을 추론**할 수 있다면 데이터 효율이 크게 높아진다.

**무엇이 새로운가**  
기존 패치별 회귀 방식(예: HisToGene, BLEEP) 대신 두 단계 이중 분해 구조를 제안한다: (1) H&E 이미지 패치를 형태-공간 거시 상태(morpho-spatial macrostates)로 클러스터링해 공간적 문맥을 포착하고, (2) 유전자 발현 행렬을 저-계수 분자 프로그램(low-rank molecular programs)으로 압축해 예측 타깃을 구조화한다 (초록 기준). 추정: 거시 상태는 공간 인접 정보를 반영한 클러스터(예: 세포 유형 맵), 분자 프로그램은 NMF 또는 유사한 저-계수 분해로 전사 패턴을 요약하는 구조일 가능성이 높다.

**핵심 가정**  
1. H&E 형태학적 특징이 유전자 발현을 충분히 결정론적으로 반영한다 — 동일 형태를 가진 세포가 전혀 다른 전사 상태를 가질 수 있다는 반례가 알려져 있다 (외부 맥락: 종양 내 전사 이질성 연구들).  
2. 저-계수 분해로 포착된 분자 프로그램이 생물학적으로 해석 가능하다 — 프로그램 수(rank)의 선택이 결과에 크게 영향.  
3. 학습 시 사용한 공간 전사체 데이터셋의 조직 유형이 예측 시와 일치한다 — 조직·암종 외삽 시 성능 저하 위험.

**재현성**  
`미제공:` 코드·학습 데이터셋 미공개. 저자·소속 미확인. 검증에 사용된 공간 전사체 플랫폼(10x Visium, Slide-seq 등) 불명.

**비교 대상 / 검증 수준**  
`미제공:` 구체 베이스라인·수치 불명 (원문 확인 필요). 검증: in silico (공간 전사체 데이터 대조).

**강점**: H&E만으로 유전자 발현 추론 — 비용·데이터 효율 측면의 잠재 가치가 크다. 이중 분해 구조가 해석 가능성(interpretability)에 기여할 수 있다.  
**한계**: 코드·데이터 미공개. 형태-전사 결정론 가정이 강하다. 조직 유형 일반화 검증 미확인. 예측 가능한 유전자 수(고발현 유전자 vs. 희귀 유전자)의 범위 불명.

**내 연구 적용**  
바이오인포 분석에서 기존 H&E 데이터를 공간 전사체 없이 활용하고 싶을 때 참고 가능. 코드 공개 시 유사 모델(HisToGene, SpaFoundation)과 성능 비교 실험 우선. 임상 적용 전에 외부 코호트 검증 필수 (현재 in silico 단계).

### C5. EHRFlow: Learning Continuous Patient Trajectories
**원문**: Learning Continuous Patient Trajectories from Electronic Health Records  
**출처**: arXiv:2609.36144 · 2026-09-28 · preprint; ML4H 2026 Proceedings Track 제출  
**링크**: https://arxiv.org/abs/2609.36144 | 코드: 미공개 (GitHub: PKU-AICare/EHRFlow 레포 존재 확인됨 — 내용 미확인)

**문제의식 선행**: EHR 기반 임상 ML 모델 대부분이 고정 시점 스냅샷 또는 규칙적 시계열을 가정한다. 실제 환자 기록은 불규칙 관측 시점을 가지며, 임의 미래 시점 예측이 필요하다. **연속 시간 역학을 명시적으로 모델링**하지 않으면 불규칙 시계열의 정보가 왜곡된다.

**무엇이 새로운가**  
EHR 시계열 모델링에 **multi-marginal flow matching** 프레임워크를 처음 적용한다 (초록 기준). 인코딩된 과거 기록을 조건 신호로 쓰고, 관측된 여러 시점의 경계 분포(marginals)를 동시에 만족하는 연속 확률 경로(probability path)를 학습한다. 이를 통해 임의 시점 예측과 불규칙 관측 시간 처리를 단일 프레임워크로 다룬다 (초록 기준). 규모: 100만+ 환자 실제 임상 데이터셋에서 검증 주장 (초록 기준).

외부 맥락: Flow matching의 임상 시계열 적용 선행 연구로 TFM(Trajectory Flow Matching, arXiv:2410.21154)과 IMMFM(arXiv:2510.03569)이 있다. EHRFlow가 이들 대비 EHR 도메인 특화 기여(임상 코드 처리, 다중 마진 설계)를 어떻게 차별화했는지는 원문 확인 필요.

**핵심 가정**  
1. 환자 임상 상태가 연속적 확률 경로로 근사 가능하다 — 급격한 임상 악화(sepsis 발현, 급성 이벤트)처럼 불연속적 전환이 강한 경우 연속 경로 가정이 깨진다.  
2. 관측 시점의 분포(marginals)가 궤적 전체를 충분히 제약한다 — 관측 시점이 편향적으로 선택된 경우(악화 시 더 자주 측정), 학습한 경로가 현실 역학을 왜곡할 수 있다.  
3. 단일 대규모 데이터셋에서 학습된 패턴이 다른 의료 시스템·인구 집단에도 일반화된다.

**재현성**  
`미제공:` 코드 공식 공개 여부 불명확 (GitHub 레포 PKU-AICare/EHRFlow 존재 확인, 내용 미확인). 학습 데이터(100만+ 환자 임상 데이터)는 비공개 추정. ML4H 2026 Proceedings Track 제출 상태.

**비교 대상 / 검증 수준**  
임상 코드 예측과 잠재 상태 복원 성능을 개선했다고 주장 (초록 기준). 구체 베이스라인·수치 불명. 검증: 후향적 (N=100만+, 단일 데이터셋 추정). 외부 기관 검증 미확인.

**강점**: EHR 시계열 불규칙성 문제를 수학적으로 엄밀하게 다루는 접근. 대규모 실제 데이터 검증이 이 주 논문 중 가장 현실적.  
**한계**: 코드·데이터 비공개로 재현 어려움. 단일 기관 후향 코호트 한계. 연속 경로 가정이 급성 이벤트 예측에 적합한지 불명. ML4H 미채택 시 방법론 신뢰도 불확실.

**내 연구 적용**  
임상 ML에서 불규칙 EHR 시계열을 다루는 방법론으로 참고 가치 있음. 코드 공개 및 ML4H 채택 여부 확인 후 추가 검토 권장. 질문: 국내 EMR 데이터 구조(한국 의료 코드 체계)에서도 동일 프레임워크 적용 가능한지 별도 검증 필요.

## 와이드 논문 방법 분석 (간략)

### W1. CAGenMol-2: One Sequence, Many Decodings
**출처**: arXiv:2609.34301 · 2026-09-28 · preprint | 코드: 미공개  
약물 설계를 **마스크드 분자 추론(masked molecular inference)**으로 재정의한다. 하나의 분자 서열에서 마스킹-언마스킹 과정을 반복해 다양한 화학적으로 유효한 분자를 생성하는 것이 핵심 아이디어. 추정: 전작 CAGenMol(조건부 확산 LM, ACL 2026 Findings 채택)의 후속으로, 추론 단계에서의 다양성 확대에 집중한 것으로 보인다. 코드·수치 미공개로 방법 세부 확인 불가.

### W2. WSI as Dynamic Tumor Microenvironment Fields
**출처**: arXiv:2609.34451 · 2026-09-28 · NeurIPS 2026 accepted | 코드: 미공개  
병리 전체 슬라이드 이미지(WSI)를 이산 패치 집합이 아닌 **연속적 공간 장(continuous field)**으로 모델링해 종양 미세환경(TME)의 공간적 역학을 포착한다. NeurIPS 2026 채택으로 방법론적 완성도 인정됨. 추정: neural field(NeRF 유사) 또는 연속 공간 보간 방식을 WSI에 적용했을 가능성. 코드·구체 수치 미공개.

### W3. AI-assisted Mitotic Counting across Tumour Types
**출처**: arXiv:2610.01813 · 2026-10-02 · preprint | 코드: 미공개  
다양한 종양 유형에서 AI 보조 유사분열상(mitotic figure) 계수의 재현성과 효율을 병리의사와 비교한 **임상 검증 연구**. 순수 방법론 제안보다는 기존 AI 계수 도구의 임상 적용 가능성 평가에 가깝다. 해석: 방법 렌즈보다 임상 렌즈 비중이 크므로 clinical-analyst 분석 참조 권장.

## 방법 총평

2026-W40은 **단백질 언어 모델 + 진화 정보 통합**과 **연속 확률 과정의 바이오의료 적용** 두 흐름이 겹쳐 나타난 주다. LEMON-ZEST는 토크나이징 단계에 생물학적 사전지식을 명시적으로 주입한 완성형 방법론으로, NeurIPS 채택과 HuggingFace 모델 공개로 이 주 재현 가능성이 가장 높은 논문이다. EHRFlow는 flow matching을 EHR 불규칙 시계열에 적용한 개념적 신규성이 있으나, 코드·외부 검증 부재로 현 시점 재현·활용이 어렵다. C3 (구조 인식 RL)와 C4 (MoSPR), C1 (DTI 교차 어텐션) 모두 in silico 단계이고 코드 미공개로, **이번 주 핵심 5편 중 즉시 활용 가능한 것은 LEMON-ZEST 1편**이라고 볼 수 있다. 와이드 단에서 W2 (Dynamic TME Fields)는 NeurIPS 채택으로 주목할 만하나, 코드 공개 전까지 방법 세부 확인이 불가하다. 전반적으로 이번 주는 코드 공개율이 낮아 방법론 재현에 제약이 크다.
