### 1. scVision: 공간 유전자 지도화 기반 단일세포 비전 파운데이션 모델
> 원문: arXiv:2607.14163 | 상태: preprint (미동료심사) | 검증 수준: in silico, 6개 보류 연구 zero-shot 평가

**닿는 모달리티**: 단일세포 전사체(scRNA-seq) 기반 세포유형 지도화, 바이오마커 발굴, 세포치료(cell therapy), 면역항암(I/O) 환자 층화(patient stratification)

**R&D 신호**
- 기존 scGPT·Geneformer·scFoundation 계열의 공통 약점 — 유전자 발현 크기(magnitude)를 토큰화 과정에서 버림 — 을 "유전자를 이미지 픽셀"로 표현하는 방식으로 직접 공략. 72M 인간 세포 사전학습 후 zero-shot에서 6개 독립 보류 연구 전원 SOTA 보고.
- 해석: R&D 총괄 시점에서 이 모델이 외부 코호트에서도 재현된다면, 대규모 scRNA-seq 아틀라스 기반 타깃 발굴에서 세포유형 주석 비용이 낮아지고, 기존 CLM(cell-language model) 파이프라인 일부를 대체할 유인이 생긴다.
- 질문: 유전자 수가 수만 개에 달하는 현실 스케일에서 optimal transport 기반 공간 배치의 재현 비용·안정성 확인 필요.

**경쟁 구도**
- 외부 맥락: 학계 선점자 — scGPT(Toronto), Geneformer(Broad), scFoundation(Westlake), CELLxGENE Discover(CZI). 모두 언어 모델 패러다임.
- 외부 맥락: 산업계 — Recursion(OmicsMap), Genentech AI 연구팀, BioMap(단백질+세포 파운데이션). Stanford 공저(James Zou 등)라는 점에서 스핀아웃 경로 가능성 있으나 미확인.
- 역사적 맥락: 단일세포 파운데이션 모델 경쟁은 2022~2023년 scBERT·Geneformer를 시작으로 가속됐으나, "유전자 크기를 버려야 토큰화가 된다"는 구조적 제약이 정확도 천장을 만들어 왔다. scVision은 이 제약을 우회하는 첫 파운데이션 모델 규모의 시도.

**상용화 거리**: 즉시~1년 (바이오인포 어노테이션 파이프라인으로 직접 도입) / 5년+ (세포치료·신약타깃 발굴에 직결)

**시나리오**: scVision이 재현된다면 대규모 환자 코호트 scRNA-seq 프로파일링에서 반응자(responder) 세포 서브셋을 zero-shot으로 정의하는 전략이 가능해진다. 특히 CAR-T 세포 품질 QC와 면역항암 환자 층화에서 가장 빠른 접점.

**수요 렌즈**: 1) 단일세포 아틀라스 보유 제약사 바이오마커팀 2) 세포치료 CRO(품질 검사 자동화) 3) CELLxGENE·10x Genomics 같은 아틀라스 플랫폼 운영자

### 2. Corgi: 컨텍스트 인식 서열-기능 모델 (Peer-reviewed)
> 원문: DOI:10.1038/s41467-026-75527-2 | 상태: peer-reviewed (Nature Communications) | 코드: github.com/ekinda/corgi

**닿는 모달리티**: 기능 변이(functional variant) 해석, 인핸서(enhancer) 설계, 유전자치료(gene therapy) 벡터 최적화, 에피게노믹스(epigenomics) imputation, 세포유형 특이적 유전자 발현 예측

**R&D 신호**
- 기존 Enformer·Borzoi의 핵심 병목 — 학습 시 본 세포유형에만 작동, 미지 세포유형(held-out cell type) 일반화 불가 — 을 trans-regulator 발현 벡터를 두 번째 입력으로 넣는 FiLM(feature-wise linear modulation) 방식으로 해결.
- Corgi+의 핵심 가치: RNA-seq 입력만으로 ATAC-seq·ChIP-seq 히스톤 트랙을 SOTA 수준으로 imputation. 에피게노믹스 실험 없이 규제 게놈 신호를 소급 추정할 수 있다.
- 해석: 임상시험 바이오마커 전략에서 기존에 수집된 bulk RNA-seq 데이터에 에피게놈 레이어를 소급 추가할 수 있다면, 레트로스펙티브 바이오마커 발굴의 해상도가 높아진다.

**경쟁 구도**
- 외부 맥락: 직접 경쟁 모델 — Enformer(DeepMind, 2021), Borzoi(2024), Flashzoi(2025 속도 개선), EPInformer(2026). 모두 세포유형 컨텍스트 고정.
- 외부 맥락: Corgi는 Max Planck Institute(비상업 학술기관) 산출물로 코드 공개. 직접 상업화보다는 제약사 내부 바이오인포 파이프라인 통합 경로가 현실적.
- 외부 맥락: 유전자치료 분야(BioMarin, uniQure, Spark Therapeutics)는 조직 특이적 인핸서 선택에 서열-기능 모델을 이미 탐색 중. Corgi의 세포유형 일반화 능력이 여기에 직접 닿음.

**상용화 거리**: 즉시~1년 (코드 공개, 파이프라인 통합 가능) / 3~5년 (신약개발 직접 의사결정 적용)

**시나리오**: Corgi+가 다양한 외부 코호트 RNA-seq에서 epigenomics imputation 성능을 유지한다면, RNA-seq 데이터만 있는 임상 샘플에서 에피게놈 기반 내성 메커니즘을 사후 분석하는 전략이 가능해진다. 이는 임상 2/3상 실패 후 분석(post-hoc)에서 비반응 환자의 에피게놈 특성을 소급 추정하는 데 활용 가능.

**수요 렌즈**: 1) 제약사 계산 생물학팀 (변이 해석, 타깃 발굴) 2) 유전자치료 회사 (조직 특이적 프로모터/인핸서 설계) 3) Epigenomics CRO (서비스 확장)

**econ-radar 교차**: 기존 ATAC-seq·ChIP-seq 서비스 CRO에게는 간접적 경쟁 압력 시나리오. 추정: imputation 도구가 성숙할수록 고비용 epigenomics 실험 일부가 계산으로 대체될 가능성.

### 3. LATTICE: 다중모달 공간 오믹스 통합 그래프 프레임워크
> 원문: arXiv:2607.14410 | 상태: preprint (미동료심사) | 벤치마크 수치 원문 미확인

**닿는 모달리티**: 공간 전사체(spatial transcriptomics)·공간 에피게노믹스 기반 종양 미세환경(TME, tumor microenvironment) 분석, 면역항암(I/O) 바이오마커 개발, 조직 도메인(tissue domain) 분류

**R&D 신호**
- Visium RNA·scMultiome RNA·scMultiome ATAC·spatial ATAC·spatial CUT&Tag 5가지 모달리티를 스팟 수준에서 통합. 현재 공간 오믹스 연구는 대부분 RNA 단독 혹은 RNA+ATAC 2중 모달리티에 그침.
- MD Anderson Cancer Center 협업 — 종양 샘플 접근성과 임상 데이터 연결 능력이 있어 향후 임상 적용 연구로 발전 가능한 위치.
- 해석: TME 분석에서 "면역 세포 위치 + 크로마틴 상태 + 히스톤 변형"을 동시에 보는 것은 지금까지 불가능했다. 면역항암 약물의 반응 예측 바이오마커를 에피게놈 레이어까지 확장하는 데 가장 직접적인 경로.

**경쟁 구도**
- 외부 맥락: 공간 도메인 검출 선행 도구 — STAGATE, SpatialDE, Banksy. 다중 오믹스 통합은 MOFA+·Seurat WNN이 선점했으나 공간 해상도 없음.
- 외부 맥락: 플랫폼 종속성 주목 — LATTICE는 10x Genomics Visium·Chromium 데이터 포맷에 맞춰 설계. 10x Genomics의 플랫폼 지배력이 지속될수록 이 분석 도구의 파급력도 유지됨.
- 외부 맥락: Parse Biosciences, Vizgen(MERFISH)이 대안 플랫폼으로 경쟁 중이라 장기적으로 플랫폼 중립 설계가 필요해질 수 있음.

**상용화 거리**: 3~5년 (바이오마커 개발 적용). 5가지 모달리티 동시 실험 자체가 연구 예산 기준 높아 현재 임상 연구 규모에서는 비현실적.

**시나리오**: 공간 오믹스 실험 비용이 하락하는 시점에 LATTICE 계열 통합 분석이 I/O 임상시험 반응 예측 바이오마커 발굴의 표준 파이프라인이 될 경로. BMS·머크·아스트라제네카 바이오마커팀의 기술 도입 대상.

**econ-radar 교차**: 10x Genomics(TXGN) — LATTICE가 상정하는 다중 모달리티 실험이 현실화될수록 장비·소모품 수요 직결. 추정: 플랫폼 수요는 공간 오믹스 방법론 성숙도에 달림.

**수요 렌즈**: 1) I/O 빅파마 바이오마커팀 2) 종양학 CRO (병리조직 기반 데이터 생성) 3) 공간 오믹스 플랫폼 회사 (10x Genomics)

### 4. Evo 2 프로브: 메타게노믹 생물안전 스크리닝
> 원문: arXiv:2607.14070 | 상태: preprint (미동료심사) | AMR 어텐션 프로브 ROC-AUC 0.977 (초록 기준)

**닿는 모달리티**: 메타게노믹스(metagenomics) 기반 감염병 감시·생물안전(biosecurity), 항생제 내성(AMR) 탐지, 감염증 CRO·규제기관, 감염증 신약 개발사(내성 모니터링)

**R&D 신호**
- Evo 2(Arc Institute/Stanford) 26번째 레이어 활성화를 동결(frozen)한 채 선형·어텐션 프로브만으로 AMR ROC-AUC 0.977 달성. 파인튜닝 없이 게놈 파운데이션 모델의 표현에 AMR 정보가 이미 인코딩되어 있음을 시사.
- 해석: 이 결과가 재현된다면 기존 CARD·ResFinder 같은 룰베이스 AMR 파이프라인에 Evo 2 임베딩을 가벼운 프로브 형태로 추가해 탐지 성능을 높이는 경로가 실용적. 신규 내성 변이(novel AMR variant)에 대한 일반화 여부가 핵심 미지수.
- 신약개발 연결: 감염증 신약(항생제) 개발사의 내성균 선발(screening)과 임상시험 환자 코호트의 내성 프로파일링 도구로 활용 가능.

**경쟁 구도**
- 외부 맥락: 기존 AMR 도구 — CARD, ResFinder, ARIBA, AMRFinderPlus(NCBI) — 모두 데이터베이스 매핑 방식. 파운데이션 모델 기반 접근은 새로운 계열.
- 외부 맥락: Evo 2 모델 자체는 Arc Institute(비영리)와 Together AI 공동 개발. 생물안전 응용은 DARPA·BARDA·WHO 같은 공공기관이 주된 수요처.
- 추정: AIxBio Hackathon 결과물이라 규모와 철저성이 제한적. 즉각적 상업화보다는 PoC 단계 — 추가 검증 선행 필요.

**상용화 거리**: 2~3년 (생물안전 스크리닝 공공 조달 경로) / 신약개발 직접 연결은 5년+

**시나리오**: 감염병 감시 기관이 메타게노믹 파이프라인에 Evo 2 프로브를 통합하면 AMR 조기 경보 정확도가 높아진다. 감염증 신약 개발사는 임상 코호트 내성 프로파일링에서 기존 시퀀스-데이터베이스 매핑의 노이즈를 줄이는 보완 도구로 검토할 수 있다.

**수요 렌즈**: 1) 생물안전 규제기관·공공보건 기관(CDC, ECDC, WHO) 2) 감염증 CRO 3) 항생제 신약 개발사 (내성 모니터링)

### 5. 방사선 반응 메커니즘의 인과 발견
> 원문: arXiv:2607.13994 | 상태: preprint (미동료심사) | 산업 함의 제한적

**닿는 모달리티**: 방사선요법(radiotherapy) 병용 신약, 방사선감작제(radiosensitizer) 타깃 발굴, 방사선 노출 바이오마커

**R&D 신호**
- 기존 방사선 반응 분석은 대부분 단변량 DEG(차등발현유전자) 분석 + 사전 정의된 경로(predefined pathway). 이 논문은 인과 발견(causal discovery) 알고리즘으로 방향성 있는 유전자 조절망을 복원하고, 알려진 방사선 반응 경로가 해당 네트워크에서 농축됨을 보인다.
- 해석: 방법론 자체는 타당하나 현 데이터 규모·세포 종류가 제한적으로 보임. 방사선감작제 타깃 발굴에 실질적으로 연결되려면 실험적 검증(perturbation 실험)과 환자 코호트 적용이 추가로 필요.

**경쟁 구도**
- 외부 맥락: 인과 발견 방법론 — NOTEARS, DAG-GNN, DECI 등. 생물학 네트워크 복원에 적용 사례 증가 중. 방사선 반응 특화 인과 분석은 희소.
- Rick Stevens(UChicago/Argonne) 공저라는 점에서 DOE 계산과학 인프라 배경 있으나 직접 상업화 경로 없음.

**상용화 거리**: 5년+ (기초 연구 단계)

**시나리오**: 인과 발견 네트워크가 새로운 방사선 반응 조절자를 정확히 예측하고 그 중 하나가 기존 소분자로 조절 가능한 타깃이라면 방사선감작제 병용 파이프라인에 연결될 수 있다. 현 단계에서는 R&D 신호보다 방법론적 가능성 시연에 가깝다.

**수요 렌즈**: 방사선종양학 연구자, 방사선요법 병용 개발사 — 직접 산업 수요는 현 단계에서 제한적

## 와이드 2편 — 산업 함의 요약

### W1. Inkling (Thinking Machines Lab, 975B MoE, Apache 2.0)
- 산업 함의 제한적(생물학 특화 아님). 그러나 975B 파라미터 오픈웨이트·Apache 2.0 라이선스라는 점에서 생물의학 도메인 파인튜닝 비용이 낮아진 것은 신약개발 AI 연구팀에게 장기적으로 유리.
