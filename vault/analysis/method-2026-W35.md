## C1: GITIII-scale — 팬-암 세포 상태-니치 상관관계 기반 TME 파운데이션 모델

**원문**: arXiv:2608.26208 · https://arxiv.org/abs/2608.26208 · **preprint (미동료심사)**
**저자**: Xiao Xiao, Jiashu He, Shiyang Zhang, Meiyi Mao (Yale·Penn·Michigan)
**코드/데이터**: https://github.com/lugia-xiao/GITIII_scale (사전학습 데이터·코드·모델 체크포인트 공개)

### 무엇이 새로운가

기존 공간 전사체(spatial transcriptomics) 파운데이션 모델은 세포 자체의 유전자 발현 패턴을 학습하는 데 집중했다. GITIII-scale은 여기서 한 걸음 나아가 세포가 주변 이웃 세포(niche)와 맺는 세포-세포 상호작용(cell-cell interaction, CCI)이 세포 상태를 어떻게 형성하는지를 명시적으로 모델링한다. "세포를 단어, 이웃 세포군을 문맥(context)"으로 취급하는 NLP 유사 비유가 핵심 설계 직관이다.

**문제의식**: 종양 미세환경(tumor microenvironment, TME)에서 단일 세포의 상태는 고립되어 결정되지 않는다. 주변 세포들과의 리간드-수용체 신호(ligand-receptor signaling)가 세포 상태를 규정하는데, 기존 파운데이션 모델은 이 공간적 맥락 정보를 충분히 포착하지 못했다.

### 모델·아키텍처

세 수준의 계층 구조:
1. **CCI 해석 레이어**: 단일 레이어 그래프 트랜스포머 (feed-forward network 없음). 수용 세포(receiver cell)의 각 유전자가 주변 발신 세포(sender cell)에 의해 어떻게 영향받는지를 분해 가능한 방식으로 표현한다. 해석 가능성(interpretability)이 이 레이어의 설계 목표다.
2. **니치 임베딩 레이어**: 그래프 트랜스포머로 세포 이웃(neighborhood) 전체의 임베딩을 생성한다.
3. **팬-암 사전학습**: 암종에 걸쳐 공통된 세포 상태-니치 상관 패턴을 학습하도록 설계됐다.

선행 연구 GITIII(Nature Machine Intelligence, 2025 — 원문 인용 기반)를 팬-암 스케일로 확장한 것이 GITIII-scale이다.

### 데이터

훈련 데이터: 조직 매칭(specimen-matched) scRNA-seq + 영상 기반 공간 전사체(imaging-based spatial transcriptomics) 팬-암 데이터베이스. 구체적인 암종 수·샘플 수는 초록에서 확인되지 않는다.

미제공: 훈련에 포함된 암종 목록, 각 암종의 샘플 수, 공간 전사체 플랫폼(MERFISH·Xenium 등)의 구성 비율. 원문(방법 섹션) 직접 확인 필요.

### 베이스라인 및 평가

평가 기준: 훈련 시 미노출(unseen) 암종에서의 니치 연관 세포 상태 변화 포착 정확도. "기존 공간 전사체 파운데이션 모델 대비 우수"라고 초록은 명시하지만, 비교 대상 모델명·구체적 수치는 초록에서 확인되지 않는다.

검토필요: 어떤 파운데이션 모델(예: HEST-1k 기반 모델, scGPT, GeneFormer 등)을 베이스라인으로 삼았는지 방법 섹션에서 확인 필요.

검증 수준: **in silico** — 팬-암 벤치마크 (훈련 외 암종 포함). 외부 코호트·전향적 검증 없음.

### 재현성

- 코드·모델 체크포인트·사전학습 데이터: https://github.com/lugia-xiao/GITIII_scale (공개 확인)
- PyPI 패키지(`gitiii`)도 존재하는 것으로 검색됨 — 배포 의지가 있다.
- 추정: 사전학습 데이터 규모가 크고 영상 기반 공간 전사체 필요 — 완전한 재현에는 높은 컴퓨팅·데이터 접근 비용이 따를 것으로 예상.

### 강점

- 코드·체크포인트 공개: 방법론 논문 중 재현 가능성이 가장 높은 수준.
- CCI를 해석 가능한 방식으로 분해 — 리간드-수용체 경로까지 역추적 가능하다는 점이 약물 표적 발굴에 직접 연결된다.
- 팬-암 훈련으로 특정 암종 데이터가 적어도 TME 특성을 표현할 수 있다는 점이 희귀암 연구에 강점.

### 한계

- 평가가 in silico에 그침. 도출된 CCI 해석이 실제 기능적 의미를 갖는지 실험적 검증이 없다.
- 베이스라인 세부와 정량 수치가 초록에서 불명확 — 방법 섹션 확인 전까지 성능 우위의 크기를 단정하기 어렵다.
- 핵심 가정: 공간 전사체에서 측정된 세포 위치가 실제 기능적 상호작용을 반영한다고 가정. 다중세포층·3D 조직 구조에서 2D 공간 좌표 기반 이웃 정의가 과연 타당한지는 플랫폼 종속적이다.
- 영상 기반 공간 전사체 한정 — Visium HD나 시퀀싱 기반 플랫폼으로의 일반화 여부는 별도 검증 필요.

### 내 연구에 쓸 수 있나

TME 분석이나 CCI 기반 약물 표적 발굴에 관심이 있다면 코드가 공개된 만큼 바로 테스트해볼 수 있다. scRNA-seq + 공간 전사체 매칭 데이터를 보유한 연구에서는 파인튜닝 없이 임베딩을 추출해 클러스터링·다운스트림 분류에 쓸 수 있을 것이다. 다만 TME 임베딩의 임상적 예측력(예: 치료 반응)은 별도 검증이 필요하다.

## C2: RNA Yield DNN — IVT 수율 예측을 위한 대규모 스크리닝+CNN 파이프라인

**원문**: arXiv:2608.23722 · https://arxiv.org/abs/2608.23722 · **preprint (미동료심사)**
**저자**: Dinghai Zheng, Justin Hong, Jun Wang, Adrien Villain, Mickaël Costallat, Fernando Ulloa Montoya, Vikram Agarwal
**코드/데이터**: 미공개 (원문·검색 결과 모두 언급 없음)

추정: 저자 소속 미기재 (scout raw 기준). Vikram Agarwal은 생물정보 분야에서 활동하며, 저자 구성과 연구 내용상 제약·바이오테크 산업 연구진으로 추정되나 공식 소속 확인 필요.

### 무엇이 새로운가

mRNA 치료제 제조의 핵심 병목은 시험관 전사(in vitro transcription, IVT) 반응에서 얼마나 많은 RNA가 생산되느냐다. 서열에 따라 수율이 크게 달라지지만 이를 사전 예측하는 계산 도구는 부재했다. 이 논문은 10^5개 올리고뉴클레오타이드 무작위 라이브러리를 NGS로 대규모 측정한 뒤 CNN 기반 모델로 수율을 예측하는 파이프라인을 구축한다.

**기존 한계 → 이번 해결**: 기존 IVT 수율 최적화는 소규모 실험 기반 경험칙에 의존했다. 이 연구는 10^5 규모의 병렬 스크리닝 데이터를 딥러닝과 결합해 새로운 서열 설계를 실험 전 사전 순위화(pre-experimental prioritization)한다.

### 모델·아키텍처

- 모델 유형: CNN(합성곱 신경망) 기반 딥러닝 모델
- 입력: 올리고뉴클레오타이드 서열
- 출력: IVT RNA 생산량(수율) 예측값
- 세부 아키텍처(레이어 수·하이퍼파라미터): 미제공. 초록 수준 정보.

### 데이터

- 훈련 데이터: 10^5개 무작위 올리고뉴클레오타이드 서열 라이브러리
- 측정 방법: NGS(Illumina 시퀀싱)로 DNA·RNA 존재비(abundance)를 병렬 정량
- 데이터 공개 여부: 미제공. 특허·영업 비밀 가능성 있음.

### 베이스라인 및 평가

- 평가 지표: 보류(held-out) 테스트 세트에서 예측-실측 Pearson 상관계수 **0.94** (초록 기반)
- 베이스라인 모델: 미제공. 어떤 비교군(서열 특성 기반 회귀·기존 통계 모델 등)과 비교했는지 초록에서 확인 불가.
- 검증 수준: **in silico** — 단일 held-out 테스트 세트. 독립 실험 재검증 없음.

검토필요: Pearson 0.94는 높은 수치지만, 무작위 올리고뉴클레오타이드 라이브러리에서 훈련했을 때 실제 치료제 설계에 쓰이는 mRNA 서열(5'UTR, 코딩 서열 등)로 어떻게 일반화되는지 확인 필요.

### 재현성

- 코드: 미공개 (검색·원문 모두 언급 없음) — 재현 어렵다.
- 데이터: 미공개 — 산업 연구진 구성상 기업 독점 가능성 있음.
- 추정: 이 방법론(대규모 라이브러리 + NGS 측정 + CNN)은 재현 가능하나, 동일 데이터 없이는 모델 자체를 재현하기 어렵다.

### 강점

- 실제 제조 공정(IVT 수율)을 직접 타깃으로 삼아 산업 실용성이 명확하다.
- 10^5 규모 무작위 라이브러리로 서열 공간을 넓게 커버한 훈련 설계가 일반화에 유리하다.
- Pearson 0.94는 사전 필터링 도구로 충분히 활용 가능한 수준의 예측력을 시사한다(단, 단일 held-out 세트 기준임을 유념).

### 한계

- 코드·데이터 미공개 — 외부 재현·감사 불가.
- 베이스라인 비교 없음: 딥러닝 모델의 성능 우위를 어떤 대조군 대비 보였는지 초록에서 불명확.
- 일반화 범위 불명확: 무작위 올리고뉴클레오타이드에서 학습한 모델이 구조화된 mRNA 서열(캡·5'UTR·코딩 영역·폴리A 테일)에서도 같은 예측력을 갖는지 검증이 없다.
- 핵심 가정: 서열이 IVT 수율의 주된 결정 인자라는 전제. 실제 IVT 반응은 온도·마그네슘 농도·효소 배치 등 비서열 인자에도 민감하다.

### 내 연구에 쓸 수 있나

mRNA 서열 설계 또는 합성생물학 파이프라인을 운영한다면, 이 방법론(대규모 NGS 기반 스크리닝 + CNN 예측)은 자체 구현 가능한 프레임워크다. 코드가 없으므로 유사 아키텍처(예: 5'UTR 번역 효율 예측에 쓰인 선행 CNN 모델)를 레퍼런스 삼아 구현하는 방향이 현실적이다. Pearson 0.94 수치는 사전 순위화 필터로는 충분하지만, 최적화 루프(예측 → 실험 → 재훈련)까지 구성할 때 데이터 누수(data leakage) 가능성을 별도 점검해야 한다.

## C3: Perturb-seq HSPC — 조혈줄기세포 기능 규명을 위한 기능유전체 스크린

**원문**: bioRxiv 10.64898/2026.08.27.747499 · **preprint (미동료심사)**
**저자**: Joseph S Bowness, Aina Bernal Martinez, Jan Barinka, Jonas Schulte-Schrepping, Simon Renders, Alexander Waclawiczek, Aino-Maija Leppa, Andreas Trumpp, Simon Raffel, Simon Haas, Lars Velten (Centre for Genomic Regulation, Barcelona; 독일·핀란드 기관 포함)
**코드/데이터**: 미확인 (bioRxiv 직접 접근 불가 환경)

### 무엇이 새로운가

Perturb-seq(CRISPR 교란 + 단일세포 RNA-seq 동시 판독)을 인간 조혈줄기·전구세포(hematopoietic stem and progenitor cell, HSPC)에 적용해 단일 유전자 교란이 복수의 공동 조절 유전자 프로그램(co-regulated gene programs)에 어떻게 파급되는지 단일세포 해상도로 규명한다.

**문제의식**: 단일 유전자 녹아웃이 전사체에 미치는 영향은 단순하지 않다. 하나의 유전자가 여러 독립적 전사 프로그램에 동시에 영향을 줄 수 있으며, HSPC처럼 이질적인 세포군에서는 이 복잡성이 더 크다. 이 논문은 유전자 교란 → 다중 프로그램 변화 경로를 체계적으로 지도화한다.

### 모델·아키텍처

방법론적 핵심은 실험 설계다:
1. **Perturb-seq 스크린**: 인간 HSPC에 CRISPR 교란을 도입하고 단일세포 전사체를 동시 판독.
2. **유전자 프로그램 추출**: 단일세포 데이터에서 공동 발현(co-expression) 기반 유전자 프로그램을 비음수 행렬 분해(NMF) 계열 방법 등으로 추출(세부 방법은 원문 확인 필요).
3. **교란-프로그램 연결**: 각 유전자 교란이 어떤 프로그램에 영향을 주는지 매핑.

미제공: 스크리닝한 유전자 수, 세포 수, 구체적 계산 파이프라인. bioRxiv 직접 접근 불가로 방법 섹션 확인 불가.

### 데이터

- 실험계: 인간 HSPC (ex vivo)
- 측정: Perturb-seq (CRISPR + scRNA-seq)
- 세부 샘플 수·유전자 패널: 원문 확인 필요.
- 데이터 공개 여부: 미확인.

### 베이스라인 및 평가

- 검증 수준: **ex vivo** (인간 HSPC 실험) + 단일세포 전사체 분석. In vivo 기능 검증은 초록 수준에서 확인되지 않는다.
- 비교 방법론: Perturb-seq 결과 해석에 어떤 계산 방법을 사용했는지, 기존 HSPC Perturb-seq 연구 대비 어떤 점이 개선됐는지 원문 확인 필요.

미제공: 구체적 정량 수치. raw data에서 접근 불가.

### 재현성

- 코드: 미확인.
- Velten 연구실은 CRG Barcelona 소속으로 데이터·코드 공개 전통이 있으나(외부 맥락: 이전 발표 논문 기준), 이번 논문에서의 공개 여부는 별도 확인 필요.
- Lars Velten: CRG 그룹 리더, 조혈·단일세포 분야 주요 연구자.

### 강점

- 인간 HSPC에서 직접 수행한 기능유전체 스크린 — 마우스 대리 모델이 아닌 인간 세포 수준의 데이터.
- 공동 조절 프로그램 개념은 단일 유전자 표적 접근보다 복잡한 혈액 질환 병인을 이해하는 데 더 적합한 단위를 제공한다.
- Lars Velten·Simon Haas 등 분야 내 검증된 그룹의 컨소시엄 연구.

### 한계

- 세부 수치·방법 미확인 (접근 불가 환경). 현재 초록 수준 평가만 가능.
- Ex vivo HSPC는 이식(engraftment) 환경이 아님 — 골수 니치 환경이 결여된 상태에서의 유전자 프로그램이 생체 내에서도 동일하게 작동하는지는 별도 검증 필요.
- 핵심 가정: 교란 효과가 세포 유형에 걸쳐 일관된다는 가정 — HSPC는 매우 이질적이며 하위 세포 유형별로 교란 반응이 다를 수 있다.

### 내 연구에 쓸 수 있나

유전체 기능 스크린 또는 조혈계 단일세포 분석을 수행한다면, 공동 조절 프로그램 단위로 교란 효과를 분석하는 접근이 참고할 만하다. 계산 파이프라인이 공개될 경우, 다른 세포 유형·조직의 Perturb-seq 데이터에 동일 분석 틀을 적용할 수 있는지 테스트해볼 가치가 있다. 현재는 원문 접근 후 방법 섹션 확인이 선행 조건이다.

## C4: SALRR — 인간 뇌 장독취 RNA-seq 대규모 분석 파이프라인

**원문**: bioRxiv 10.64898/2026.08.26.747213 · **preprint (미동료심사)**
**저자**: Cedric Kouam, Jackson Mingle, Pilar Alvarez Jerez, Allison Evans, Abraham Moller, Mina Ryten, Fritz Sedlazeck, Luigi Ferrucci 등 (다기관 컨소시엄)
**코드/데이터**: 미확인 (원문 접근 불가)
**주의**: 동일 DOI에 대해 웹검색에서 두 논문(SALRR / MOSurvivor-CpG)이 혼재하는 결과가 포착됐음. DOI 확정은 원문 직접 확인 필요. 이하 분석은 SALRR을 주 귀속 논문으로 전제한다.

### 무엇이 새로운가

장독취(long-read) RNA-seq은 단독취(short-read) 대비 이소폼(isoform) 전장 서열을 직접 포착한다는 강점이 있지만, 데이터 규모가 커질수록 분석 계산 비용이 급증한다. SALRR은 이 확장성 문제를 해결하는 파이프라인을 개발하고 인간 뇌 전사체 전면 이소폼 프로파일링에 적용했다.

**기존 한계 → 이번 해결**: 기존 장독취 분석 도구(예: FLAIR, Bambu, IsoSeq3)는 단일 샘플·소규모 데이터셋에 최적화되어 있어 뇌 연구에서 요구되는 대규모 다샘플 분석에 병목이 발생한다. SALRR은 이 병목을 파이프라인 수준에서 해소하려는 시도다.

### 모델·아키텍처

SALRR은 새로운 딥러닝 알고리즘보다 **확장 가능한 계산 파이프라인** 논문에 가깝다. 세부 구성 요소(사용된 정렬 도구, 이소폼 병합 전략, 병렬화 방식)는 원문 접근 없이 확인 불가. 저자 중 Fritz Sedlazeck(장독취 시퀀싱 분야 주요 연구자)이 포함된 점은 방법론적 신뢰도의 맥락 정보다.

미제공: 파이프라인 구체 단계, 기존 도구 대비 속도·정확도 벤치마크 수치, 코드 공개 여부.

### 데이터

- 대상: 인간 뇌 장독취 RNA-seq 데이터 (PacBio / Oxford Nanopore — 플랫폼 미확인)
- 규모: 원문 확인 필요.

### 베이스라인 및 평가

검증 수준: **in silico** — 대규모 시퀀싱 데이터 분석. 기존 파이프라인과의 속도·이소폼 포착률 비교 여부는 원문 확인 필요.

미제공: 구체적 벤치마크 수치(처리 속도, 이소폼 수, 알려진 이소폼 회수율 등).

### 재현성

코드 공개 여부 미확인. 파이프라인 논문 특성상 공개 가능성이 높지만, 현재 확인 불가.

### 강점

- 장독취 RNA-seq 대규모 분석의 실용적 병목을 직접 타깃한다.
- Fritz Sedlazeck·Luigi Ferrucci 등 분야 내 주요 연구자 참여.
- 뇌 전사체 이소폼 지도는 신경퇴행성 질환(파킨슨병·ALS 등)의 RNA 처리(splicing) 이상 연구에 기반 데이터로 활용 가능하다.

### 한계

- 현재 초록 수준 이상 정보가 없어 방법 평가가 매우 제한적이다.
- DOI 충돌 가능성: 동일 DOI 두 논문이 검색됨 — 원문 확인 전까지 이 논문의 정보를 다른 자료로 신뢰하기 어렵다.
- 파이프라인 논문의 공통 한계: 재현 가능성은 구현 환경(GPU·메모리·OS)에 민감하며, 컨테이너화(Docker·Singularity) 제공 여부에 따라 실용성이 크게 달라진다.
- 핵심 가정: 장독취 시퀀싱 오류율을 충분히 교정했다는 전제 — 특히 Nanopore 데이터에서 이소폼 경계 정밀도가 플랫폼 및 교정 방법에 따라 달라진다.

### 내 연구에 쓸 수 있나

뇌 또는 신경계 장독취 RNA-seq 분석을 계획한다면, 코드가 공개될 경우 SALRR의 확장성 검증 결과가 파이프라인 선택에 직접 참고가 된다. 그러나 현재 단계에서 원문 확인 없이 적용 결정을 내리기는 어렵다. DOI 충돌 문제가 먼저 해소되어야 한다.

## C5: Mol-JEPA — 분자 다중 모달리티 JEPA 기반 사전학습

**원문**: arXiv:2608.22642 · https://arxiv.org/abs/2608.22642 · **preprint (미동료심사)**
**저자**: Florian Rottach, Sebastian Schieferdecker (Tübingen·Boehringer Ingelheim), William Rudman (UT Austin), Randall Balestriero (Brown), Carsten Eickhoff (Tübingen)
**코드/데이터**: https://github.com/Boehringer-Ingelheim/mol-jepa (공개 확인, HuggingFace 통합 포함)

### 무엇이 새로운가

분자 표현 학습(molecular representation learning)에서 다중 모달리티(구조·세포 표현형·결합 친화도·ADMET·양자화학 시뮬레이션 등)를 통합하려는 시도는 있었지만, 대부분 대조 학습(contrastive learning) 방식을 써왔다. 대조 학습은 두 가지 문제가 있다: (1) 모달리티 붕괴(modality collapse) — 한 모달리티만 지배적으로 학습, (2) 화학적으로 부자연스러운 증강(augmentation) — 임의 원자 교란이 화학 의미를 파괴한다.

Mol-JEPA는 LeCun이 제안한 JEPA(Joint Embedding Predictive Architecture) 프레임워크를 분자 도메인에 이식해 이 두 문제를 우회한다.

**메커니즘 핵심 가정**:
JEPA의 핵심 직관은 잠재 공간(latent space) 내에서 마스킹된 모달리티를 예측하도록 학습하는 것이다. 이미지 픽셀이나 토큰을 직접 재구성하는 대신 표현 공간에서 예측을 수행하므로, 화학적으로 무의미한 저수준 노이즈를 암기할 유인이 없다. **"14개 모달리티 중 일부를 마스킹하고 나머지로부터 마스킹된 모달리티의 표현을 예측"** — 이것이 모달리티 마스킹(modality masking)의 핵심이다.

### 모델·아키텍처

- 14개 모달리티를 각각 인코딩: 분자 그래프(2D 구조), 세포 표현형 이미지, 결합 친화도, ADMET 프로파일, 양자화학 특성 등.
- 각 모달리티 인코더 → 공유 잠재 공간으로 투영.
- 모달리티 마스킹: 훈련 시 일부 모달리티를 마스킹하고, 컨텍스트 모달리티로부터 마스킹된 모달리티의 잠재 표현을 예측하는 예측 네트워크(predictor)를 학습.
- 모달리티별 세부 인코더 종류(GNN·Transformer 등): 원문 확인 필요.

### 데이터

- 훈련 데이터: 약 500만 개 분자 (diverse drug-like chemical space)
- 14개 모달리티 포함 — 단, 모든 분자에 모든 모달리티가 있지는 않을 것이며 희소(sparse) 멀티모달 설계일 가능성이 있다. (추정: 원문 확인 필요)
- 데이터셋 자체도 HuggingFace를 통해 공개.

### 베이스라인 및 평가

평가 벤치마크:
- **OpenADMET** (ExpansionRx 및 PXR 챌린지)
- **ASAP-Polaris** (COVID 표적 결합 + ADMET)
- **Biogen ADME** 데이터셋

성능 요약 (초록 기반):
- 데이터 희소 설정(low-data regime)에서 기존 베이스라인(GNN·기술자 기반 모델) 대비 낮은 MAE 달성.
- 특히 ASAP/Polaris·Biogen ADME 같은 소규모 고품질 데이터셋에서 강한 성능.

검토필요: 구체적 MAE 수치·개선 폭은 초록에서 확인되지 않음. 원문 결과 테이블 확인 필요.

검증 수준: **in silico** — 공개 벤치마크 평가. 실험적 활성 재검증 없음.

### 재현성

- 코드: https://github.com/Boehringer-Ingelheim/mol-jepa (Boehringer Ingelheim 공식 GitHub)
- HuggingFace 모델·데이터 통합 포함 — 재현·파인튜닝 장벽이 낮다.
- Boehringer Ingelheim 제약사의 공식 참여로 코드 품질·유지관리에 대한 기대치가 높다.

### 강점

- JEPA를 분자 도메인에 적용한 첫 체계적 시도(초록 기준 — 선행 연구 존재 여부는 방법 섹션 확인 필요).
- 모달리티 마스킹이 대조 학습의 구조적 한계(모달리티 붕괴·부자연스러운 증강)를 원천적으로 우회한다는 설계 논리가 명확하다.
- 14개 모달리티 통합 + 500만 분자 규모는 단일 모달(구조 그래프만) 사전학습보다 풍부한 화학 맥락을 제공한다.
- 코드·데이터 모두 공개, 제약 기업 참여로 산업 실용성 검증이 동반됐다.

### 한계

- 14개 모달리티 전부를 동시에 보유한 분자는 드물다 — 희소 모달리티 설계에서 어떻게 결측을 처리하는지, 이것이 학습 안정성에 미치는 영향은 원문 확인 필요.
- 평가가 벤치마크 in silico에 그침 — 예측한 ADMET 프로파일이 실제 실험값과 어떻게 대응되는지 검증 없음.
- 핵심 가정: 14개 모달리티가 상호 보완적 화학 정보를 담고 있다는 전제 — 일부 모달리티가 중복 정보를 담고 있다면 예측 네트워크 학습이 수렴하지 않을 수 있다.
- 데이터 누수(leakage) 가능성: OpenADMET·Polaris 챌린지 데이터가 사전학습 500만 분자 세트와 겹칠 경우 성능이 과대평가된다. 원문에서 decontamination 처리 여부 확인 필요.

### 내 연구에 쓸 수 있나

신약 후보 물질의 ADMET 예측이나 결합 친화도 스크리닝에 관심이 있다면, Mol-JEPA의 사전학습 임베딩을 기반으로 소규모 실험 데이터(수십~수백 개 측정값)에 파인튜닝하는 전이학습 전략이 가장 즉각적인 활용 경로다. 코드가 공개되어 있고 HuggingFace 통합이 있어 진입 장벽이 낮다. 다만 자체 데이터가 사전학습 세트와 겹치는지 먼저 점검해야 한다.

## 와이드 논문 방법 메모

### W1: BixBench3 — AI 에이전트 생물정보학 연구 수준 능력 평가

**원문**: arXiv:2608.25286 · https://arxiv.org/abs/2608.25286 · **preprint (미동료심사)**
**저자**: Edison Scientific / FutureHouse 팀
**코드/데이터**: https://github.com/EdisonScientific/BixBench3 · https://huggingface.co/datasets/EdisonScientific/BixBench3 (공개)

벤치마크의 설계가 방법론적으로 흥미롭다. 기존 bioinformatics 벤치마크는 단일 질문-답변 형식이었지만 BixBench3는 실제 출판 논문 20편의 원시 데이터를 주고 "연구 목적 + 방법 가이드"를 제시한 뒤, 에이전트가 전체 분석 파이프라인을 실행해 138개 아티팩트(결과물)를 생성해야 한다. 평가 방식: 결정론적(deterministic) 자동 채점기. 최고 점수는 GPT 5.6 Sol 0.48 / 최저 Gemini 3.1 Flash Lite 0.00 (arXiv:2608.25286 초록 기반). 흥미로운 성능 패턴: 원시 데이터가 클수록(>100 GB) 점수 하락(0.10 vs. 소규모 0.36), 순차 단계가 많을수록 성능 저하. 평균 시도당 6.8시간·102M 토큰·$43 비용이 소요됐다. 현재 모든 프론티어 LLM이 인간 연구자 수준의 계산생물학 분석 자동화에 아직 도달하지 못했음을 구체적 수치로 드러낸다는 점에서 방법론적 과대기대를 교정하는 역할을 한다.

### W2: Evolution Strategies vs. GRPO — LLM 사후 훈련에서의 추론 커버리지 비교

**원문**: arXiv:2608.27351 · https://arxiv.org/abs/2608.27351 · **preprint (미동료심사)**
**저자**: Yunpeng Ba, Zhi Zheng, Yue Xie 외 다수
**코드/데이터**: 미확인

GRPO(Group Relative Policy Optimization)는 현재 LLM 추론 능력 강화에 가장 많이 쓰이는 사후 훈련 기법이다. 이 논문은 진화전략(Evolution Strategies, ES) — 집단 기반·기울기 없는(gradient-free) 방법으로 가중치 공간에서 무작위 섭동(perturbation) 후 최적화 — 이 GRPO보다 **추론 커버리지(reasoning coverage)**를 넓게 달성한다고 주장한다. 추론 커버리지는 pass@k 같은 지표로 측정되며, 단일 최선 답변 정확도(pass@1)와 구분된다. 관련 선행 연구 arXiv:2604.01499도 ES vs. GRPO 비교를 다뤘으며 이 논문과 맥락을 공유한다. 바이오의학 LLM 파인튜닝(단백질·게놈·임상 도메인) 관점에서는, 소규모 도메인 특화 데이터셋에서 ES가 더 다양한 추론 경로를 탐색한다면 희귀 생물학적 패턴 발견에 유리할 수 있다. 단, 코드 공개 여부 미확인으로 직접 적용 전 방법 세부 확인 필요.

## 종합: 이번 주 방법론 흐름

이번 주 다섯 핵심 논문은 공통적으로 **파운데이션 모델 또는 대규모 데이터 기반 학습**을 생물학 실용 문제에 연결하려는 흐름을 보인다. C1(GITIII-scale)·C5(Mol-JEPA)는 각각 TME 해석과 분자 ADMET 예측에 특화된 파운데이션 모델을 제시하며, 두 논문 모두 코드를 공개했다는 점에서 재현 가능성 측면에서 이번 주 가장 주목할 논문들이다. C2(RNA Yield DNN)는 산업 적용에 특화된 실용 파이프라인이지만 코드·데이터 미공개로 외부 검증이 닫혀 있다. C3·C4는 각각 Perturb-seq과 장독취 시퀀싱이라는 실험·데이터 생성 방법론을 앞세우며, 계산보다 실험 설계와 분석 파이프라인의 신규성이 핵심이다. 한 가지 방법론적 주의 신호: C5 Mol-JEPA에서 사전학습 세트와 벤치마크 데이터의 겹침 여부, C2에서 학습·테스트 서열의 유사도 기반 누수 가능성이 모두 미검증 상태다. 다음 단계로 두 논문의 원문 방법 섹션에서 데이터 분리(split) 전략을 확인하는 것이 우선이다.
