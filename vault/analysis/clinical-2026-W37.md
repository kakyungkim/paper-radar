## C1. ProteinTalks — 교란 프로테오믹스 기반 가상세포 모델

**출처**: Nature · 2026년 9월 · peer-reviewed
**DOI**: https://doi.org/10.1038/s41586-026-11001-9
**저자**: Rui Sun (제1저자), Liujia Qian, Yongge Li 외 | Westlake University / Westlake Omics Inc. / DP Technology Co., Ltd.

### 임상 질문

유방암 세포에서 FDA 승인 항암제 63종의 동적 단백질 반응을 측정해 신경 ODE 기반 가상세포 모델(ProteinTalks)을 구축하면, 개별 약물 효능·2제 병용 시너지·약물 내성 관련 단백질을 예측할 수 있는가. 항암 병용요법 선택과 내성 기전 탐색이라는 미충족 임상 수요에 접근하려는 시도다.

### 검증 수준 (in silico)

`(in silico, 유방암 세포주)`

학습 및 검증 모두 유방암 세포주(cell line) 기반의 교란 프로테오믹스 데이터다. 원문 raw 파일이 명시한 바: 투여 전·6h·24h·48h 4개 시점에 걸쳐 3,800만 건의 단백질 발현량 측정값, 63종 FDA 승인 항암제, 59종 2제 병용 조건. 환자 종양 조직 데이터를 사용했다는 서술은 raw 파일에 없다.

해석: 세포주는 실제 종양 미세환경(tumor microenvironment), 개인 간 유전 변이, 약동학/약력학(PK/PD) 복잡성을 반영하지 않는다. "63종 FDA 항암제를 다뤘다"는 사실이 임상 검증을 의미하지 않는다.

### 임상 적용까지의 거리

매우 멀다. 아래 단계가 모두 선행되어야 한다.

1. 환자 유래 세포(PDC)·오가노이드 수준 검증 (ex vivo)
2. 다양한 암종으로 일반화 실험 (유방암 단일 세포주 → 여러 암종)
3. 동물 모델 약효 검증 (in vivo)
4. 환자 코호트 전향 예측 연구
5. 임상 의사결정 지원 도구로의 통합 및 규제 승인

추정: Nature 게재 수준의 연구라면 보충자료에 추가 세포주 검증이 있을 수 있으나, raw 파일에는 미명시 — 원문 보충자료 직접 확인 필요.

### 수요자 관점 (수요 렌즈)

- **주된 수요자: 신약개발 연구자·제약사 R&D 조직.** 병용 스크리닝 비용을 줄이는 계산 필터로 쓸 수 있다.
- **임상의**: 지금 단계에서 처방 선택에 활용 불가. 세포주 예측이 특정 환자에게 직접 연결되지 않는다.
- **환자**: 직접 영향 없음. 중장기적으로 병용요법 후보 발굴 속도가 빨라질 가능성 (추정).
- **지불자**: 관련 없음. 임상시험 전 단계.

### 위험·한계

- **세포주 편향**: 세포주 데이터는 복잡한 종양 생물학을 과단순화한다. 예측이 환자 반응으로 전환되지 않을 가능성.
- **단일 암종**: 유방암 세포주만 학습 — 다른 암종 일반화 근거 미확인 (raw 파일 기준).
- **코드·데이터 공개 미확인**: raw 파일에 "본 논문 전용 링크 미확인"으로 기술. 재현 검증 어려움.
- **이해상충 검토필요**: 저자 소속에 Westlake Omics Inc. (상업 기관)가 포함. 상업적 이해관계가 결과 해석에 영향을 미쳤는지 COI 섹션 확인 권장.
- **과대해석 경계**: "운용 가능한(operational) 가상세포 모델"이라는 표현이 임상 운용 가능성을 시사하지 않는다. 여기서 "운용 가능"은 계산적 추론 가능성을 의미한다.

**기존 한계→이번 해결**: 기존 약물 병용 스크리닝은 실험 비용·시간 때문에 전수 탐색이 불가능하다. 이 연구는 동적 단백질 시계열 데이터로 학습한 Neural ODE 모델이 고비용 병용 실험을 계산으로 사전 필터링할 수 있다고 주장한다 — 단, 세포주 수준에 한정된다.

## C2. ProMeta — PROTAC 분해 활성의 소수샷 예측

**출처**: arXiv · 2026-09-09 · **preprint(미동료심사)**
**DOI/링크**: https://arxiv.org/abs/2609.09891
**저자**: Yuansheng Liu (제1저자), Yufei Ye, Tao Tang, Jiawei Luo, Wen Tao, Xiao Luo | 소속 미확인 (초록 기준)

### 임상 질문

PROTAC(단백질 분해 유도 이중기능 분자)의 분해 활성이 특정 E3 리가제(CRBN, VHL 등)에 집중된 학습 데이터 때문에 다른 E3 리가제 조건으로 일반화하지 못하는 문제를, 메타러닝 기반 그래프 신경망(ProMeta)으로 해결할 수 있는가. 비교적 탐색이 덜 된 E3 리가제를 활용한 PROTAC 설계 — 즉 '언드러거블(undruggable)' 표적 공략 — 이 실현 가능성을 계산 수준에서 타진한다.

### 검증 수준 (in silico)

`(in silico, 미동료심사)`

원문 raw 파일 기준: 분자 그래프 인코딩과 단백질 서열 임베딩을 결합한 계산 예측 연구다. 구체적 성능 수치(소수샷 조건·교차-리가제 일반화 정량 지표)는 초록에 미명시 — 논문 본문 직접 확인 필요.

미제공: 세포 내 분해 활성 실험(DC50, Dmax) 검증 여부, 동물 모델 사용 여부. raw 파일에 해당 정보 없음.

### 임상 적용까지의 거리

매우 멀다.

1. 계산 예측 → 실험 합성·세포 분해 활성 확인 (wet lab 검증)
2. 선택적 분해 확인, 오프타깃(off-target) 단백질 영향 평가
3. 약동학(PK), 세포 투과성, 안정성 최적화
4. 동물 약효·독성 연구
5. IND 신청 및 임상 진입

해석: PROTAC 계열 신약 자체가 아직 임상 초기 단계인 경우가 많고, E3 리가제 다양화라는 목표는 장기 과제다. 이 계산 도구가 가속을 도울 수 있어도, 현재로서는 신약 탐색 필터 이상이 아니다.

### 수요자 관점 (수요 렌즈)

- **주된 수요자: 표적 단백질 분해(TPD, Targeted Protein Degradation) 분야 제약·바이오텍 연구팀.** E3 리가제 포트폴리오 확장을 탐색하는 연구자에게 CRBN/VHL 편향을 벗어난 계산 가이드를 제공할 수 있다.
- **임상의·환자**: 직접 관련 없음. 신약개발 파이프라인의 초기 탐색 단계.
- **지불자**: 직접 관련 없음.

### 위험·한계

- **미동료심사**: 수치·방법 모두 동료 심사 전. 성능 수치 미명시로 독립 평가 불가.
- **데이터 편향 → 새 편향 가능성**: CRBN/VHL 데이터 편향을 메타러닝으로 해결하려 하지만, 메타러닝 학습셋 자체가 어떤 E3 리가제 분포를 갖는지 미확인.
- **소수샷 조건 실제성**: 소수샷(few-shot) 성능이 실제 실험 설계에서 유효한 예측으로 이어지는지 wet lab 검증 없이는 불분명.
- 미제공: 코드·데이터 공개 여부 미확인.

## C3. Biology-in-the-loop — CRISPR 스크린 순차 실험 설계

**출처**: arXiv · 2026-09-10 · **preprint(미동료심사)**
**DOI/링크**: https://arxiv.org/abs/2609.11877
**저자**: Carl Edwards (제1저자), Edward De Brouwer, Xiner Li, Namkyeong Lee, Ehsan Hajiramezanali, Anne Biton, Sara Mostafavi, Gabriele Scalia (교신) | Genentech 및 공동 기관
**코드**: https://github.com/Genentech/AssayBench

### 임상 질문

기능 유전체학(functional genomics)에서 CRISPR 스크린의 실험 예산이 제한될 때, 어떤 유전자를 먼저 테스트해야 히트(hit)를 효율적으로 발굴할 수 있는가. 신약 타깃 발굴 속도와 비용을 동시에 개선하려는 문제다.

임상 직접성은 낮다. 이 연구는 치료제를 다루는 것이 아니라, 치료 타깃 후보를 찾는 실험 설계 방법론을 다룬다.

### 검증 수준 (in silico / 공개 데이터 재분석)

`(in silico, 1,389개 공개 CRISPR 스크린 데이터 기반, 미동료심사)`

raw 파일 명시 수치: 1,389개 공개 CRISPR 스크린, 5개 표현형 카테고리로 구성한 벤치마크(AssayBench-Loop). 성능 수치: 후보 라이브러리의 5% 스크리닝 후 히트의 27.7% 회수, 랜덤 선택 대비 5.67배 enrichment (초록 기준).

해석: 이 수치는 기존 공개 스크린 데이터에서의 시뮬레이션 결과이지, 실제 신규 생물학적 맥락에서의 전향 실험 검증이 아니다. "5.67배 enrichment"는 벤치마크 설계와 데이터 분할 방식에 크게 달라질 수 있다.

### 임상 적용까지의 거리

간접적이고 멀다. 이 방법은 타깃 발굴의 실험 효율화 도구이지, 그 자체로 임상 개입이 아니다.

1. 이 방법으로 발굴된 타깃 → 독립적인 기능 검증 (wet lab)
2. 선별 타깃의 질환 관련성 전향 확인
3. 동물 모델에서 타깃 검증
4. 신약 개발 파이프라인 진입

해석: 타깃 발굴에서 임상까지는 통상 10년 이상이 소요된다. 실험 설계 효율화가 그 경로를 앞당길 수 있지만, 현재 수치로 임상 영향을 정량화하는 것은 시기상조다.

### 수요자 관점 (수요 렌즈)

- **주된 수요자: 기능 유전체학 연구팀 및 타깃 발굴 부서 (Genentech 등 대형 제약사 내부, 학술 기관).** 실험 예산 제약 아래 CRISPR 스크린을 운영하는 연구자에게 실용적 스크린 설계 도구가 된다.
- **임상의·환자**: 현재 단계에서 직접 관련 없음.
- **지불자**: 신약 탐색 비용 절감에 장기적 간접 영향 가능 (추정).

### 위험·한계

- **미동료심사**: 벤치마크 설계·수치 모두 동료 심사 전.
- **공개 데이터 기반 벤치마크**: 훈련·평가 모두 공개 스크린 데이터. 신규 생물학적 문맥에서의 전향 실험 성능은 미검증.
- **Genentech 내부 생물학 사전 의존 가능성**: LLM 파생 생물학 사전을 활용하는데, 이것이 특정 기관 데이터·관점에 편향될 가능성.
- **데이터 누수 가능성 질문**: 사전학습에 사용된 1,389개 스크린 중 벤치마크 평가 스크린과 중첩이 있는지 불분명 — raw 파일 미명시, 원문 확인 필요.
- **코드 공개**: https://github.com/Genentech/AssayBench (raw 파일 명시). 재현 시도 가능.

## C4. CARDEA — 관상동맥 조영술 AI 해석

**출처**: arXiv · 2026-09-07 · **preprint(미동료심사)**
**DOI/링크**: https://arxiv.org/abs/2609.06931
**저자**: Jia-Jen Lee (제1저자), Shih-Yen Hou, Kee Koon Ng, Wei-Chun Wang, Shih-Sheng Chang (교신) | 소속 미확인 (초록 기준)

### 임상 질문

관상동맥 조영술(CAG, Coronary Angiography) 판독에서 관찰자 간 변동성(inter-observer variability)을 줄이고, AI가 진단 근거를 공간적으로 명시할 수 있는가. 두 가지 구체적 과제: 우관동맥 우세도(right coronary dominance) 분류와 병변 복잡도 평가. 심장내과 현장에서 관찰자 간 불일치는 실제 임상 문제이며, 설명 가능한(explainable) AI가 검증·감사(audit)를 가능하게 한다는 것이 이 연구의 전제다.

### 검증 수준 — 이번 주 5편 중 임상 관련성이 가장 높은 논문

`(in silico / 공개 데이터셋, 미동료심사)`

raw 파일 명시: 공개 데이터셋으로만 훈련. 2개 연구 수준 진단 과제 평가. 검증 데이터셋 규모·성능 수치는 초록에 미명시 — 원문 본문 직접 확인 필요.

해석: "공개 데이터셋으로만 훈련"이라는 표현이 임상적 강점(독점 데이터 의존성 없음)이기도 하지만, 동시에 실제 다기관 임상 환경에서 다양한 장비·프로토콜로 수집된 데이터에 대한 일반화를 보장하지 않는다.

미제공: 외부 기관 데이터 검증 여부, 전문가 판독과의 일치도(agreement) 정량 수치. 이 두 가지는 임상 채택 가능성 판단에 필수다.

### 임상 적용까지의 거리

중간에서 멀다. 진단 AI 중 임상 적용 가능성이 상대적으로 가까운 범주이나, 여전히 여러 단계가 필요하다.

1. 다기관·다국가 외부 코호트 검증 (장비·프로토콜 다양성 반영)
2. 전문 심장내과의 판독과의 일치도·우월성 연구
3. 공간 근거(chain-of-box) 표시의 임상 유용성 연구 — 의사의 의사결정에 실제로 도움이 되는가
4. CE 마크(유럽) 또는 FDA 510(k)/De Novo 인허가
5. 전자의무기록(EMR)·카테터실(cath lab) 워크플로 통합

추정: 비슷한 심장 AI 제품(e.g., 심전도·에코카디오그래피 AI)이 규제 승인을 받는 데 통상 2~5년이 걸렸다. 임상 근거 구축 기간을 포함하면 실제 사용까지 더 길 수 있다.

### 수요자 관점 (수요 렌즈)

- **주된 수요자: 심장내과 임상의 및 카테터실 운영 병원.** 관상동맥 조영술 판독에서 일관된 기준을 원하는 의사, 두 번째 의견(second opinion)을 원하는 소규모 병원이 실수요층이다.
- **환자**: 진단 일관성 향상으로 치료 결정의 정확도가 높아진다면 이점 가능 (추정). 단, 현재 단계에서 환자 결과(outcome) 개선을 보인 데이터는 없다.
- **검사실·영상의학 기사**: 키프레임 자동 선택 기능이 판독 전 처리 부담을 줄일 수 있다.
- **지불자**: 판독 효율화로 비용 절감 가능성 있으나, 검증 없이 구체적 수치 제시 불가.

### 위험·한계

- **미동료심사**: 핵심 성능 수치 미공개 상태에서 임상 함의 판단 어려움.
- **소속 미확인 검토필요**: 저자 소속이 raw 파일에 "미확인 (초록 기준)"으로 기재. 임상 환경 접근성 및 데이터 출처 파악 불가.
- **단일 기관 데이터 가능성**: 공개 데이터셋 사용이라고 하지만 어떤 데이터셋인지 미명시. 단일 기관 데이터였다면 일반화 문제.
- **임상 채택의 설명 가능성 요건**: Chain-of-Box(CoB) 공간 근거가 임상의에게 실제로 유용한지(cognitive burden 증가 vs. 감소) 별도 사용자 경험 연구 필요.
- **두 가지 과제의 임상 중요도 차이**: 우관동맥 우세도 분류와 병변 복잡도 평가 중 후자(복잡도 평가, 예: SYNTAX score 관련)가 임상 의사결정에 더 직접적이다. 이 둘을 동등하게 취급하는 것이 적절한지 질문.

**기존 한계→이번 해결**: CAG 판독에서 관찰자 간 변동성은 오랜 임상 문제다. CARDEA는 공개 데이터만으로 훈련하면서 공간 근거를 노출하는 RLVR 학습 방식을 결합해, 블랙박스 AI가 아닌 감사 가능한(auditable) 시스템을 지향한다는 점이 임상 신뢰 확보에 이론적 장점이 있다 — 단, 실제 임상 환경에서의 검증은 미완이다.

## C5. CIDER — 질환 유전자 조절 네트워크 차등 변화 탐지

**출처**: bioRxiv · 2026-09-08 · **preprint(미동료심사)**
**DOI**: https://doi.org/10.64898/2026.09.08.750185
**저자**: Wooseok J Jung (제1저자), Mingyue Ding, Shu Liao, Zolboo Erdenebaatar, Michael Brent (교신) | 추정: Washington University in St. Louis (Brent 연구팀 기준; raw 파일에 "소속 직접 확인 필요" 표기)

### 임상 질문

두 조건(질환 대 정상, 또는 약물 처리 대 미처리) 사이에서 유전자 조절 네트워크(GRN, Gene Regulatory Network)의 어느 연결이 달라지는지 탐지하면, 표현형 전환을 일으키는 핵심 조절 변화를 파악할 수 있는가. 질환 메커니즘 이해 및 신약 타깃 발굴의 기초 도구로서의 문제 설정이다.

### 검증 수준 (in silico)

`(in silico, 미동료심사)`

raw 파일 기준: "두 생물학적 조건 사이에서 GRN 연결이 달라지는지 탐지"하는 계산 방법. 구체적 수치(사용 데이터셋 규모·성능 정량지표)는 raw 파일에 "미확인 — 초록 상세 내용 직접 확인 필요"로 명시되어 있다.

미제공: 어떤 질환 데이터에 적용했는지, 탐지된 GRN 변화가 wet lab 실험으로 검증됐는지, 코드·데이터 공개 여부. 이 모든 사항이 raw 파일에 미명시.

### 임상 적용까지의 거리

가장 멀다. 이 연구는 기초 연구 방법론이며, 임상 적용 경로는 다음과 같이 길다.

1. 이 방법으로 탐지된 차등 GRN 변화 → 실험적 검증 (ChIP-seq, ATAC-seq, perturbation 실험)
2. 핵심 조절자(master regulator)가 타깃 가능성이 있는지 평가
3. 타깃 검증 → 신약 개발 파이프라인
4. 전임상·임상 단계

해석: GRN 추론 자체가 불확실성이 높은 분야다(전사인자-유전자 연결은 맥락 의존적이고 노이즈가 많다). CIDER가 이 불확실성 위에 차등 변화 탐지라는 추가 레이어를 올린다. 각 단계의 불확실성이 곱해진다.

### 수요자 관점 (수요 렌즈)

- **주된 수요자: 전산 생물학·시스템 생물학 연구자.** 멀티오믹스 데이터로 질환 조절 네트워크를 분석하는 연구 그룹.
- **임상의**: 현재 단계에서 직접 사용 불가. 기초 과학 도구.
- **환자**: 간접적. 이 방법이 발굴하는 메커니즘 지식이 먼 미래 치료 타깃으로 이어질 수 있다 (추정).
- **지불자**: 관련 없음.

### 위험·한계

- **미동료심사, 핵심 수치 미공개**: 성능·적용 데이터 모두 초록 기준으로 불명확. 독립 평가 불가.
- **GRN 추론 자체의 불확실성**: GRN 추론은 데이터, 알고리즘, 생물학적 맥락에 따라 결과가 크게 달라지는 것으로 알려진 분야다. 외부 맥락: 다수의 GRN 추론 방법 비교 연구(e.g., BEELINE 벤치마크)에서 방법 간 일치도가 낮음이 보고된 바 있다.
- **소속 추정**: raw 파일이 Brent 연구팀 기준으로 Washington University in St. Louis를 "추정"으로 기재. 직접 확인 필요.
- **코드·데이터 공개 미확인**: raw 파일에 "미확인"으로 명시.
- **임상 관련성 연결의 간접성**: 표현형 전환과 연관된 GRN 변화를 탐지하는 것과 그것이 치료 가능한 타깃인지는 별개 질문이다.

이번 주 5편 중 **C4 CARDEA**가 임상 관련성이 가장 높다. 심장내과 진단 워크플로에 직접 닿는 과제를 다루고, 설명 가능성 설계를 갖추었다. 그러나 성능 수치 미공개, 외부 검증 미확인, 소속 미확인이라는 세 가지 제약이 현 시점에서 임상 함의 판단을 제한한다.

**C1 ProteinTalks**는 Nature 게재로 검증 권위가 높지만, 임상 적용 거리 면에서는 세포주 in silico 수준을 벗어나지 않는다. "63종 FDA 항암제"라는 수식이 임상 검증 완료처럼 오해될 수 있어 주의가 필요하다.

**C2, C3, C5**는 모두 신약 탐색 파이프라인의 상류(upstream)에 위치한 계산 도구로, 직접적 임상 함의보다 연구 인프라적 의미가 크다.
