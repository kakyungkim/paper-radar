## C1. CausalBind — 가상 스크리닝에 인과 추론을 얹다

**논문**: Causal Modeling and Learning for Protein-Molecule Virtual Screening  
**출처**: arXiv · 2026-10-05 · ICLR 2026 채택 (peer-reviewed 전환)  
**DOI**: https://arxiv.org/abs/2610.07340  
**코드/데이터**: 미제공: 공개 여부 확인 불가

### 임상적 질문

신약 개발 초기 단계에서 수십만~수천만 개 화합물 라이브러리를 실제 실험 없이 추려내는 가상 스크리닝(virtual screening)의 핵심 약점은 "새로운 표적 단백질에서 성능이 급격히 떨어진다"는 일반화 실패다. 이 논문은 그 원인을 결합과 무관한 허위 상관(spurious correlation)에서 찾고, 인과적으로 결합에 관여하는 원자 개념만 분리·정렬하는 방식으로 기존 대조 학습 기반 방법의 한계를 돌파하려 한다.

임상 미충족 수요와의 연결: 현재 신약 후보 발굴 단계에서 스크리닝 명중률(hit rate)은 통상 0.01~0.1% 수준이며, 새 표적일수록 더 낮다(외부 맥락: 업계 통상 수치 — 본문 인용 아님). 허위 상관 제거로 새 표적에서의 농축도(enrichment)를 올린다면 실험 비용과 시간을 실질적으로 줄일 수 있다.

### 검증 수준

**(in silico)** LIT-PCBA 벤치마크 기반 평가. LIT-PCBA는 실험적 활성 데이터를 포함한 현실적 벤치마크이나, 계산 평가 지표(BEDROC, EF@1%)에 그치며 실험적 검증(wet lab) 결과는 확인되지 않는다. 구체 수치는 원문 직접 확인 필요; 초록 요약에서 "LIT-PCBA 최대 향상" 언급만 확인됨.

검토필요: ICLR 2026과 NeurIPS 2026 Oral 두 학회 채택 표기가 raw 파일에 공존 — 출처 불일치, 원문 재확인 요망.

### 임상 적용까지의 거리

in silico 스크리닝 도구 → 히트 검증(wet lab) → 리드 최적화 → 전임상 → 임상 1상. 현재 위치는 맨 앞 단계다. 이 도구 자체가 진료나 환자에게 직접 닿는 것이 아니라, 신약 후보 발굴 파이프라인의 효율을 높이는 인프라 레이어다.

추가로 필요한 것: ① 실제 실험 검증(생화학·세포 활성 측정)으로 명중률 향상 확인, ② 여러 표적 클래스에 걸친 외부 재현성 검증, ③ 기존 도킹 소프트웨어·ML 스크리닝 파이프라인과의 통합 가능성.

### 수요자 관점

- **환자**: 직접 관계 없음 — 혜택이 있다면 수년 후 더 빠른 후보 발굴을 통해 간접적으로.
- **임상의**: 직접 관계 없음.
- **신약 R&D 연구자**: 가장 직접적 수요자. 새 표적(특히 희귀질환·항생제 내성 등 전례 없는 타깃)에서 스크리닝 효율이 올라가면 프로젝트 조기 실패를 줄일 수 있다.
- **제약사·바이오텍**: 스크리닝 외주 비용, 히트 확인 비용 절감 가능성. 모듈 플러그인 형태라면 기존 파이프라인 통합 비용 낮음.

### 위험 / 과대해석 주의점

- 벤치마크 성능 개선이 실제 실험 히트율 개선을 보장하지 않는다. LIT-PCBA 같은 공개 데이터셋에서의 과적합 가능성은 항상 존재.
- "인과적 정렬"이라는 용어가 철학적으로 엄밀한 인과 추론(Pearl의 do-calculus 등)과 다를 수 있음 — 실제로는 희소 어텐션 기반 특징 선택에 가까울 가능성(추정: 제목·초록 수준 근거).
- 코드 미공개 상태에서 재현 어려움.
- 적용 한계: 결합 포켓 구조가 알려진 단백질에 주로 적합. 막단백질·내재적 무질서 단백질(intrinsically disordered protein) 등에서의 성능은 미확인.

## C2. 선형 피트니스 부분공간 — 소수 데이터로 단백질을 진화시키다

**논문**: Linear Fitness Subspace in Protein Language Models Enables Sample-Efficient Directed Evolution  
**출처**: arXiv · 2026-10-06 · EMNLP 2026 Findings 채택  
**DOI**: https://arxiv.org/abs/2610.07607  
**코드/데이터**: 미제공: 공개 여부 확인 불가  
**주의**: 초록 미확인 — 이하 분석은 제목·게재처 기반 추론이며 `추정:` prefix 적용

### 임상적 질문

추정: 치료용 단백질(항체, 효소 대체 치료제, 사이토카인 유도체 등) 공학에서 가장 큰 병목 중 하나는 실험 가능한 변이체 수가 단백질 서열 공간에 비해 극히 적다는 것이다. 이 논문은 단백질 언어 모델(PLM) 내부 표현에서 피트니스(활성·안정성 등 목표 특성)가 선형 부분공간으로 포착된다는 가설 위에서, 소수 실험 측정값만으로 효율적 지향 진화를 가능하게 하는 방법을 제안하는 것으로 보인다.

임상 미충족 수요와의 연결: 희귀질환용 효소 대체 치료제, 고활성·저면역원성 항체, 내열성 단백질 의약 설계에서 실험 데이터가 희소한 상황은 표준적 문제다.

### 검증 수준

추정: (in silico + 소규모 in vitro) 방법론 논문의 표준적 검증 패턴은 공개 단백질 피트니스 데이터셋(ProteinGym 등)에서의 성능 비교와 선택적 실험 검증이다. 그러나 실제 검증 수준은 원문 확인 전 단정 불가.

### 임상 적용까지의 거리

선형 부분공간 가설이 성립한다면 → 실험 설계 효율화 → 최적화 단백질 후보 생성 → 세포 기반·동물 실험 → 임상. 현재 위치는 방법론 제안 단계이며, 실제 치료 단백질에 적용한 전임상 결과가 없으면 임상과의 거리는 크다.

추가로 필요한 것: ① 치료용 단백질 시나리오(항체 친화도 성숙, 효소 안정화)에서의 실험 재현, ② PLM 선형 가설의 일반화 범위(어떤 단백질 패밀리에서 성립하는가), ③ 코드 공개 및 외부 재현.

### 수요자 관점

- **단백질 공학 연구자·제약사 R&D**: 직접 수요자. 고가의 실험 반복 사이클을 줄일 수 있다면 단기 비용 절감 효과 기대.
- **환자**: 직접 관계 없음 — 치료 단백질의 품질 향상이라는 간접 경로만 존재.

### 위험 / 과대해석 주의점

- "선형 부분공간" 가설은 단순한 적합성 지형(fitness landscape)에서는 성립할 수 있으나, 다목적 최적화(활성+안정성+용해도 동시 최적화)에서는 비선형성이 지배적일 수 있다(해석: 일반적 단백질 공학 지식 기반, 본문 미확인).
- EMNLP 채택은 NLP 방법론 기여를 인정한 것이며, 생물학적 타당성은 별도 전문 심사가 필요.
- 초록 미확인 — 모든 해석은 제목 수준이며, 실제 주장과 다를 수 있음.

## C3. 알츠하이머 역인과 AI — 상류 병목 유전자를 찾아라

**논문**: Entropy-Guided Reverse-Causal AI to Identify Upstream Bottleneck Genes for Alzheimer's Drug Discovery  
**출처**: arXiv · 2026-10-06 · preprint(미동료심사)  
**DOI**: https://arxiv.org/abs/2610.08736  
**코드/데이터**: 미제공: 공개 여부 확인 불가  
**주의**: 초록 미확인 — 이하 분석은 제목·관련 선행연구 기반 추론이며 `추정:` / `해석:` prefix 적용

### 임상적 질문

알츠하이머병(AD)은 전 세계 5,000만 명 이상이 영향을 받는 신경퇴행성 질환으로, 현재 승인된 치료제 중 병인을 수정하는 약물의 효과는 제한적이다(외부 맥락: lecanemab/donanemab 2023–2024 승인 후에도 임상적 효과 크기가 작다는 비판 지속 — 본문 인용 아님). 핵심 미충족 수요는 "APOE4, APP, PSEN1/2 외에 어떤 유전자·경로가 치료 가능한 상류 병목(druggable upstream bottleneck)인가"다.

추정: 이 논문은 유전체·전사체 데이터에서 엔트로피 기반 역인과 추론으로 하류 증상이 아닌 상류 조절자(upstream regulator)를 역추적하는 접근을 취하는 것으로 보인다. 관련 선행연구(arXiv 2502.03938, AAAI 2025)가 유사 방향의 역방향 추적 기법을 AD에 적용한 사례가 있다.

### 검증 수준

추정: (in silico) 공개 AD 유전체·전사체 데이터셋(ROSMAP, ADNI 등)에서의 계산 분석일 가능성이 높다. 발굴된 유전자가 실제 치료 가능성을 갖는지는 세포·동물 실험 없이는 확인 불가.

### 임상 적용까지의 거리

in silico 타깃 발굴 → 기능 검증(세포 녹아웃/과발현 실험) → 동물 모델 검증 → 독성 평가 → 임상 1상. 이 논문이 타깃 발굴 가설을 제시한다면, 임상까지는 최소 10–15년의 통상적 신약 개발 주기가 남아있다(해석: 업계 통상 기간, 본문 미인용).

추가로 필요한 것: ① 발굴된 유전자의 세포·동물 실험 기능 검증, ② 다른 AD 데이터셋에서의 재현성, ③ 이미 진행 중인 임상시험과의 타깃 겹침 여부 확인.

### 수요자 관점

- **AD 신약 R&D 연구자**: 직접 수요자. 새로운 타깃 가설을 값싸게 생성할 수 있다면 R&D 포트폴리오 확장에 도움.
- **환자·보호자**: 직접 관계 없음 — 타깃 발굴은 치료 개발 파이프라인의 매우 초기 단계.
- **임상의**: 아직 관계 없음.

### 위험 / 과대해석 주의점

- AD 분야는 in silico 타깃 발굴 → 임상 실패의 역사가 길다. 수십 년간 아밀로이드·타우 이외 타깃 후보가 다수 발굴됐으나 임상에서 좌절됐다(외부 맥락: 2000년대 이후 AD 임상 3상 실패율 약 99% — 본문 미인용).
- "역인과(reverse-causal)" 방법이 실제 인과를 포착하는지, 강한 상관관계를 역방향으로 추적하는 데 그치는지는 원문 확인 없이 판단 불가.
- 프리프린트(미동료심사): 동료 심사 전까지 방법론적 타당성 유보.
- 초록 미확인 — 모든 해석은 제목·관련 선행연구 수준.

## C4. TDP-43 RNA 바이오마커 — 드문 스플라이싱으로 ALS/FTD를 본다

**논문**: Fine-tuning genomic models on rare splicing events identifies a novel biomarker of TDP-43 pathology  
**출처**: bioRxiv · 2026-10-07 · preprint(미동료심사)  
**DOI**: https://doi.org/10.64898/2026.10.07.757366  
**코드/데이터**: 미제공: 공개 여부 확인 불가  
**주의**: 초록 미확인 — 이하 분석은 제목·TDP-43 관련 외부 맥락 기반 추론이며 `추정:` / `외부 맥락:` prefix 적용

### 임상적 질문

이 논문이 임상적으로 가장 직접 닿는 대상은 **ALS(근위축성 측삭경화증)과 FTD(전두측두엽치매)**다. 두 질환 모두 질환 수정 치료제가 없거나 제한적이고, 생전 확진이 어려운 것이 임상 미충족 수요다.

외부 맥락: TDP-43(TARDBP 유전자 산물)은 ALS 환자의 ~97%, FTD 환자의 ~45%에서 핵에서 세포질로 이탈해 응집물을 형성한다. 그러나 생전 혈액·CSF에서 TDP-43 병리를 신뢰성 있게 감지하는 바이오마커는 아직 확립되지 않았다(외부 맥락: 2025년 기준 진단 바이오마커 개발 현황, 본문 미인용).

추정: 이 논문은 유전체 파운데이션 모델을 TDP-43 결합·기능 상실 시 발생하는 드문 스플라이싱 이벤트(cryptic exon inclusion 등)에 파인튜닝해, RNA 수준에서 TDP-43 병리의 신호를 포착하는 바이오마커를 발굴하는 것으로 보인다. Cryptic exon 기반 TDP-43 바이오마커는 최근 주목받는 방향이다(외부 맥락: STMN2·UNC13A cryptic exon 연구 — Bhatt et al., 2023 등).

### 검증 수준

추정: (in silico + 후향, 코호트 미확인) 사후부검 뇌 조직 RNA-seq 데이터 또는 ALS 코호트 데이터를 사용한 계산 분석일 가능성이 높다. 혈액 또는 CSF 기반 임상 바이오마커로의 전환 여부는 미확인.

### 임상 적용까지의 거리

계산 바이오마커 발굴 → 독립 코호트 검증 → 혈액/CSF 기반 검사법 개발 → 임상 유용성 전향 연구 → 진단 기준 통합. ALS·FTD의 임상시험 선별(trial enrichment) 도구로 쓰이려면 최소 전향적 바이오마커 검증 연구가 필요하다.

추가로 필요한 것: ① 독립 ALS/FTD 코호트에서의 바이오마커 재현성 검증, ② 접근 가능한 생체 시료(혈액·CSF·소변) 기반 검사법 개발, ③ 다른 신경퇴행 질환(파킨슨병, 알츠하이머 등)과의 특이도 확인.

### 수요자 관점

- **ALS/FTD 환자**: 잠재적으로 가장 큰 수혜자. 조기·정확 진단, 임상시험 선별 개선, 치료 반응 모니터링 가능성.
- **신경과 임상의**: 진단 바이오마커가 확립된다면 임상 판단에 직접 사용 가능.
- **임상시험 설계자**: TDP-43 병리 확인 바이오마커는 균질한 환자군 선별에 결정적 — ALS/FTD 임상시험의 고질적 문제인 환자 이질성을 줄일 수 있다.
- **검사실·체외진단 기업**: RNA 바이오마커 검사 플랫폼 개발 기회.

### 위험 / 과대해석 주의점

- "드문(rare)" 스플라이싱 이벤트는 정의상 신호가 약해 기술적 노이즈와 구분이 어렵다. 서열 깊이(sequencing depth) 요건이 까다로울 수 있다.
- 파운데이션 모델 파인튜닝 결과는 학습 데이터 특성에 민감하다 — 사용된 데이터셋이 특정 ALS 아형·인종에 편향돼 있다면 일반화 제한.
- bioRxiv 프리프린트(미동료심사): 방법론과 수치 해석 유보.
- 초록 미확인 — 실제 바이오마커 유형(RNA 직접 측정 vs. 혈장 단백질 대리 지표 등)은 원문 확인 필요.

## C5. 마우스-인간 신경 역학 정렬 — 동물 실험에서 임상 약효를 읽다

**논문**: Cross-species representation learning aligns mouse and human neural dynamics and tracks clinical drug efficacy  
**출처**: arXiv · 2026-10-08 · preprint(미동료심사)  
**DOI**: https://arxiv.org/abs/2610.11222  
**코드/데이터**: 미제공: 공개 여부 확인 불가  
**주의**: 초록 미확인 — 이하 분석은 제목 기반 추론이며 `추정:` / `해석:` prefix 적용

### 임상적 질문

추정: 이 논문은 전임상-임상 번역 실패(translational failure)라는 신약 개발의 핵심 난제를 직접 겨냥한다. 특히 **중추신경계(CNS) 약물**은 전임상에서 유효성을 보인 후 임상에서 실패하는 비율이 가장 높은 분야 중 하나다(외부 맥락: CNS 임상 실패율 약 91% — 본문 미인용).

마우스와 인간의 신경 활동 패턴을 동일 표현 공간으로 정렬한다면, 동물 전임상 데이터로부터 인간 임상 약효를 예측하는 다리를 놓을 수 있다. 제목의 "tracks clinical drug efficacy"가 핵심 주장으로, 이미 알려진 약물의 임상 결과를 신경 표현 정렬로 소급 추적했을 가능성이 있다(추정).

### 검증 수준

추정: 검증 방향은 두 가지 시나리오가 가능하다: (a) 공개 전기생리·신경영상 데이터셋에서의 교차 종 정렬 검증 (in silico), (b) 특정 약물의 신경 시그니처를 마우스→인간으로 전이 예측하는 후향 검증. 실제 수준은 원문 확인 전 불확정.

### 임상 적용까지의 거리

마우스-인간 정렬 도구 → 전임상 약물 패널에서 임상 결과 예측 정확도 검증 → 신규 화합물 전향 예측 → 신약 개발 의사결정 도구화. 현재 단계에서 임상 의사결정(어떤 환자에게 어떤 약을)에 쓰이기까지는 수 단계가 남아있다.

추가로 필요한 것: ① 신규 약물(학습 중 미포함)에서의 예측 타당성 전향 검증, ② 이 모델로 선별된 후보 약물의 임상시험 결과 추적, ③ 적용 가능한 신경계 질환·측정 방식의 범위 확인.

### 수요자 관점

- **CNS 신약 R&D 연구자**: 핵심 수요자. 비싼 영장류 실험을 대체하거나 의사결정 우선순위화에 쓸 수 있다면 파이프라인 효율화 가능성.
- **임상시험 설계자**: 환자 계층화(바이오마커 기반 선별)에 활용될 수 있다면 CNS 임상시험 설계 혁신 가능성(추정).
- **환자**: 전임상 실패 예측 개선 → 더 유망한 후보만 임상으로 진입 → 장기적 환자 노출 리스크 감소.

### 위험 / 과대해석 주의점

- 종간(cross-species) 표현 정렬의 가장 큰 위험은 표면적 상관(예: 마취 상태·측정 조건 차이)이 생물학적 신호처럼 보이는 것이다.
- "임상 약효 추적"이 소급(retrospective) 추적이라면 과거 데이터에 대한 사후 적합에 불과할 수 있다. 전향 예측력이 없으면 신약 개발 적용 가치 제한.
- CNS 질환 이외(종양·대사·면역) 적용 가능성은 별도 검증 필요.
- 프리프린트(미동료심사); 초록 미확인.

## W1. 트랜스포머 < 6개 공변량 — 임상 예측 모델의 반례

**논문**: No Transformer Beats Six Covariates: Long-Horizon Prediction of Depressive Symptoms from Childhood Essays  
**저자**: Daniel Kua, Emrul Hasan, John-Jose Nunez, Frances Chen  
**출처**: arXiv · 2026-10-06 · preprint(미동료심사)  
**DOI**: https://arxiv.org/abs/2610.07764  
**초록 확인**: 제3자 집계(opentrain.ai) 기반 — 원문 직접 확인 권장

### 임상적 질문

정신건강 예측 임상 연구의 오래된 질문: "임상 구조 데이터(사회경제 변수, 병력, 가족력 등)와 비구조 자연어 데이터(환자 서술, 에세이) 중 어느 쪽이 장기 예후 예측에 더 유용한가?" 이 연구는 영국 NCDS(National Child Development Study) 코호트를 활용해 11세 에세이 텍스트로 23세 우울 증상을 예측하는 실험을 수행한다.

임상 미충족 수요: 소아청소년기 정신건강 이상 조기 발견. 생애 초기 개입이 예후에 미치는 영향이 크다는 근거 축적에도 불구하고, 실용적인 초기 선별 도구가 부족하다.

### 검증 수준

**(후향, NCDS 코호트)** NCDS는 1958년 출생 코호트를 추적한 전국 종단 연구로, 11세(1969년)와 23세(1981년) 시점 데이터를 사용한다. 이는 실제 전향 코호트 데이터의 후향 분석이다.

강점: 표본이 국가 대표성 있는 종단 데이터. 약 12년의 추적 기간.  
약점: 1950–1970년대 데이터로 현대 사회경제적 환경·디지털 텍스트 맥락과 차이가 클 수 있다. 11세 에세이의 성격이 현대 소셜미디어 글쓰기나 임상 기록과 다름.

### 핵심 발견과 임상 함의

초록 기반: 파인튜닝 트랜스포머 7종 + 제로샷 LLM 4종 전부가 6개 구조화 공변량(아동기 SES, 성별 등으로 추정)을 사용한 로지스틱 회귀에 미치지 못한다.

해석: 이 결과는 임상 예측 모델 설계에 두 가지 함의를 갖는다.

1. **복잡한 NLP 모델이 항상 더 좋지 않다** — 특히 비전문적 텍스트(에세이)와 타깃(우울 증상) 사이의 도메인 거리가 클 때. 모델 복잡성이 곧 예측력이 아니다.
2. **공변량 선택이 모델 선택보다 중요할 수 있다** — 어떤 변수를 넣느냐가 어떤 아키텍처를 쓰느냐보다 결과에 더 크게 영향을 미치는 상황이 존재한다.

이 결과를 현재 임상 EHR 기반 예측 모델 연구에 그대로 적용하는 것은 과대해석이다 — 코호트 특성(1950년대 출생, 에세이 텍스트, 12년 장기 예측)이 현대 단기 임상 예측과 다르다.

### 임상 적용까지의 거리

학술적 결론(반례 제시) → 현대 임상 텍스트(입원 노트·상담 기록)와 단기 예측에서의 재현 → 임상 선별 도구 통합. 이 논문이 직접 임상 도구를 제공하는 것은 아니다. 기여는 "과잉 복잡성 경계"라는 방법론적 교훈에 있다.

### 수요자 관점

- **임상 ML 연구자**: 핵심 수요자. "텍스트 모델을 쓰기 전에 구조화 공변량을 먼저 최대화했는가"를 재점검하게 하는 반례.
- **정신건강 임상의**: 직접 도구로서의 관련성은 낮지만, 현재 EHR 텍스트 마이닝 도구에 대한 과도한 기대를 조율하는 데 유용한 근거.
- **보건 정책 연구자**: 소아기 사회경제 변수가 성인 정신건강을 예측한다는 근거 — 구조적 개입(빈곤 감소, 교육 지원)의 정당성에 닿는다.

### 위험 / 과대해석 주의점

- **시대 편향**: NCDS 코호트는 1958년생으로 현재 진료 맥락과 거리가 멀다. 현대 임상 텍스트·환자군에서 같은 결과가 나온다는 보장 없음.
- **공변량 내용 미상**: 6개 공변량이 무엇인지 원문 확인 전에는 결론의 의미를 정확히 해석하기 어렵다. 일부 공변량이 결과와 강한 인과 관계가 있다면 비교 자체가 불공정한 설정일 수 있다.
- **부정 결과의 일반화**: "11세 에세이 + 12년 예측"이라는 특수 설정의 결과를 일반 임상 NLP 모델의 한계로 일반화하면 과잉 해석.
- 제3자 집계(opentrain.ai) 기반 초록 요약 — 원문과 차이가 있을 수 있음.

## W2. CircuitATLAS — 회로 질환 타깃 발굴 지식 그래프

**논문**: CircuitATLAS: Agentic reasoning over a systems neuroscience knowledge graph for target discovery in circuitopathies  
**출처**: arXiv · 2026-10-07 · preprint(미동료심사)  
**DOI**: https://arxiv.org/abs/2610.09643  
**코드/데이터**: 미제공: 공개 여부 확인 불가  
**주의**: 초록 미확인 — 이하 분석은 제목 기반 추론이며 `추정:` prefix 적용

### 임상적 질문

추정: 우울증, 조현병, 파킨슨병, 강박장애 등 뇌 회로 이상에서 비롯되는 질환군("circuitopathies")은 단일 유전자나 단일 단백질 타깃으로는 설명되지 않는 복잡성을 가진다. 기존 신약 개발이 단일 분자 타깃에 집중한 결과, 많은 CNS 임상 실패로 이어졌다는 비판이 있다(외부 맥락: CNS 임상 실패율 관련 일반 지식). 이 논문은 시스템 수준의 뇌 회로 지식 그래프 위에서 LLM 에이전트가 추론해 더 맥락적인 타깃을 발굴하는 접근을 시도하는 것으로 보인다.

### 검증 수준

추정: (in silico) 지식 그래프 구축 + LLM 에이전트 추론 결과를 문헌 기반 타깃과 비교하는 방식일 가능성이 높다. 생물학적 실험 검증 단계는 포함되지 않을 가능성이 크다.

### 임상 적용까지의 거리

지식 그래프 기반 타깃 제안 → 세포·동물 실험 검증 → 신약 개발 파이프라인 진입 → 임상. 와이드 논문으로서 직접 임상 관련성은 낮고, 신약 타깃 발굴 방법론 차원의 기여다.

### 수요자 관점

- **신경과학 신약 R&D 연구자**: 기존 타깃 정보를 시스템 수준으로 재해석하는 가설 생성 도구로서 관심 가능.
- **임상의·환자**: 직접 관계 없음 — 매우 초기 단계.

### 위험 / 과대해석 주의점

- LLM 에이전트 추론의 신뢰성은 지식 그래프 품질과 LLM 환각(hallucination) 빈도에 직결된다. "새로운 타깃 발굴"이라는 주장은 독립 생물학적 검증 없이는 가설 수준.
- "Circuitopathy"라는 용어의 범위가 불분명 — 어떤 질환을 포함하는지에 따라 임상 관련성이 크게 달라진다.
- 초록 미확인, 프리프린트(미동료심사).

## 이번 주 임상 렌즈 총평

이번 주 5편 핵심 논문 모두 **in silico 또는 계산 수준의 검증**에 머물러 있으며, 직접적인 환자 데이터 기반 전향·다기관 검증을 거친 논문은 없다. 임상 파급력 순위를 매기자면:

1. **C4 (TDP-43 바이오마커)** — ALS/FTD의 생전 진단 바이오마커 미충족 수요와 가장 직접 닿는다. 발굴 바이오마커가 독립 코호트에서 재현된다면 진단·임상시험 선별에 빠른 경로가 열릴 수 있다.
2. **W1 (트랜스포머 < 공변량)** — 임상 예측 모델 연구 커뮤니티에 즉각적인 방법론 교훈을 제공하는 음성 결과(negative result). 과잉 복잡성 경계라는 메시지가 실질적.
3. **C5 (마우스-인간 신경 정렬)** — 전임상-임상 번역 문제에 정면 도전. 전향 예측 데이터가 있다면 CNS 신약 개발 의사결정 도구로 실질적 가치.
4. **C3 (알츠하이머 타깃 발굴)** — 임상 파급력은 크지만 발굴-검증-임상 사이클이 길어 단기 임상 함의 제한.
5. **C1 (CausalBind)**, **C2 (선형 피트니스 부분공간)** — 신약 개발 초기 인프라 레이어. 임상과의 거리가 가장 멀다.

**공통 주의점**: 초록 미확인 논문(C2–C5, W2)의 분석은 제목 기반 추론이므로, 실제 원문 검토 후 재평가 권장.
