## C1. recAMPLIFY: 재귀적 단백질 언어 모델 대규모 사전훈련

**출처**: arXiv:2610.26747 · preprint(미동료심사) · 2026-10-19
**저자**: Saurav Jha, Qianli Liao, Robert Vernon, Sarath Chandar, Quentin Fournier (Mila / McGill University)
**코드·체크포인트**: https://huggingface.co/chandar-lab/recamplify (11개 체크포인트, 훈련·평가 코드 포함)
**정보 신뢰도**: arXiv 초록, WebSearch 스니펫, NVIDIA BioNeMo 문서(AMPLIFY 선행 작업 확인) 기반.

### 문제의식 선행

단백질 언어 모델(pLM) 성능이 파라미터 수에 비례해 높아진다는 통념 아래 ESM-2(15B) 같은 대형 모델이 주류가 됐다. 하지만 학습·추론 비용이 연구소 규모의 접근성을 제한하고, 계산 예산 대비 실질 이득이 파라미터 증가분을 정당화하는지 검증이 부족했다. 동일 계산 비용으로 더 많은 추론 연산을 쓸 수 있다면 어떤가 — recAMPLIFY는 이 물음에서 출발한다.

### 핵심 방법론적 기여

**무엇이 새로운가**: 기존 AMPLIFY(Chandar Lab, bioRxiv 2024)가 단순 마스크드 pLM이었다면, recAMPLIFY는 **재귀적 사전훈련(recursive pretraining)**을 마스크드 단백질 언어 모델에 처음 적용한다. 핵심은 두 가지다.

1. **가중치 공유 Transformer 코어(weight-tied Transformer core)**: 동일 파라미터 집합이 잔기(residue) 수준 은닉 상태를 조절 가능한 사이클 수만큼 반복 정제한다. 추론 시 사이클을 늘리면 새로운 파라미터 없이 연산량만 증가시킬 수 있다 — "테스트 타임 컴퓨팅 확장"의 단백질 언어 모델 구현이다.

2. **Gated Mixture Recurrence (GMR)**: 각 재귀 단계에서 방문한 은닉 상태들을 확률 가중 혼합으로 디코딩하여 "기대 레이어 깊이(expected layer depth)"를 줄인다. 그래디언트 흐름이 더 짧아져 학습이 안정된다.

**선행 연구 대비 차별점**: 재귀적 계층 공유는 자연어 처리(Universal Transformer, 2018)에서 제안됐으나 단백질 언어 모델에 대규모 적용 및 벤치마크는 이번이 처음이다(외부 맥락: NLP 선행 작업 기반 판단).

### 메커니즘 핵심 가정

이 방법이 성립하려면: (a) 단백질 서열의 언어적 구조가 반복적 은닉 상태 정제로 더 잘 포착될 만큼 계층적이어야 하고, (b) 가중치 공유로 인한 파라미터 절감이 다양한 서열 길이·계통군에서 일반화 손실 없이 이루어져야 한다. 만약 단백질 서열 공간이 층마다 다른 특화된 표현을 필수로 요구한다면 가중치 공유가 병목이 된다.

### 재현 가능성

- **코드·체크포인트**: HuggingFace chandar-lab/recamplify에 11개 모델 체크포인트와 훈련·평가 코드 공개. `trust_remote_code=True` 로드 필요 (주의: 신뢰할 수 없는 코드 실행 위험이 있으므로 환경 격리 권장).
- **훈련 데이터**: AMPLIFY 선행 작업 기준 UR100P 데이터셋, 2T 토큰 — 데이터셋 출처 공개되어 있어 재현 가능성 높음.
- **베이스라인 공정성**: AMPLIFY-350M과 동일한 2T 토큰, 동일 데이터로 훈련했다는 점이 토큰 수 등가 비교를 가능하게 한다. 단, 훈련 GPU 시간·하드웨어 동일성은 원문 직접 확인 필요.
- 검토필요: "CASP 접촉 회수율 개선", "4개 지도학습 태스크 중 3개 향상", "fold 정확도 +22.5%"의 구체적 지표 정의(어떤 CASP 버전, 어떤 fold 분류기)는 arXiv 원문 방법·결과 섹션 직접 확인 필요. 현재 수치 출처는 papers.cool 스니펫.
- **데이터 누수 위험**: CASP 접촉 평가는 흔히 테스트 단백질 계열이 훈련셋에 유사 서열로 포함될 위험이 있다. 저자들이 서열 동일성 기준 컷오프(예: 30% 이하)를 적용했는지 원문 확인 권장.

### 강점 / 한계

**강점**
- 파라미터 56% 절감(155M vs. 350M)으로 동등 이상 성능 — 소규모 연구 환경의 실용적 대안.
- 추론 시 사이클 수 조정으로 연산/성능 트레이드오프를 유연하게 조율 가능.
- 코드·체크포인트 즉시 공개 — 실제 파이프라인 통합 문턱이 낮음.

**한계**
- fold 정확도 +22.5%의 기준치가 AMPLIFY-350M 대비인지 다른 모델 대비인지 원문 확인 필요.
- 재귀 사이클을 늘릴수록 추론 지연(latency)이 선형 증가 — 실시간 응용(예: 대규모 라이브러리 스크리닝)에서 병목 가능.
- 현재 평가가 CASP 접촉·fold·지도학습 태스크 4개에 한정 — 단백질-단백질 상호작용, 기능 예측, 표현 전이 등 더 넓은 벤치마크 검증이 부재.
- GMR이 모든 태스크에서 항상 유리하지 않다고 보고됨(4개 중 3개만 개선) — 태스크 의존성 있음.

### 검증 수준

in silico 전용. 계산 벤치마크(CASP 접촉, fold 정확도, 지도학습 태스크 4개). 외부 실험·생물학적 검증 없음. preprint(미동료심사).

### 내 연구 활용 가능성

파라미터 효율 단백질 표현 학습이 필요한 파이프라인(기능 예측, 변이 효과 예측, 단백질 임베딩 기반 QSAR)에 AMPLIFY-350M 대체재로 시험해볼 만하다. 체크포인트가 공개되어 있어 프리트레인된 표현을 다운스트림 태스크에 파인튜닝하는 비용이 낮다. 단, 추론 사이클 수와 latency 트레이드오프를 내 태스크 규모에서 먼저 측정해볼 것을 권장.

## C2. ProtGlycanDock: 단백질-당질 도킹 데이터셋·벤치마크·모델

**출처**: arXiv:2610.26009 · preprint(미동료심사) · 2026-10-19 · NeurIPS 2026 accepted poster #139712
**저자**: 미확인 (NeurIPS 2026 포스터 확인 — 저자명 원문 접근 불가)
**코드·데이터**: 미확인
**정보 신뢰도**: NeurIPS 2026 포스터 초록 및 WebSearch 스니펫 기반. arXiv 원문 직접 접근 불가.

### 문제의식 선행

단백질-당질 상호작용(protein-glycan interaction)은 바이러스 감염, 항체 당질화(glycosylation), 수용체 인식 등 핵심 생물학 과정을 지배한다. 그러나 당질 분자의 높은 구조적 유연성(flexible glycosidic bonds)과 당질 데이터의 희소성 탓에 도킹 분야에서 맞춤형 데이터셋·벤치마크·모델이 사실상 부재했다.

### 핵심 방법론적 기여

**기존 한계 → 이번 해결**: 기존 단백질-리간드 도킹 도구(AutoDock, Rosetta GlycanDock 등)는 소분자 위주 설계이거나 당질 특화 평가가 없었다. ProtGlycanDock은 (1) 단백질 일반화(protein generalization: 훈련 때 없던 단백질 표적), (2) 당질 일반화(glycan generalization: 훈련 때 없던 당질 구조) 두 가지 어려운 설정의 벤치마크를 처음 체계화했다.

**모델 기여**: 기존 분자 구조 예측 모델(AlphaFold 3 포함 8개)을 평가한 뒤, 두 가지 미세조정 기법을 제안했다: (a) 당질 위상적 특징(glycan topological features) 입력 추가, (b) 당질 에너지 손실(glycan energy loss) 결합. 이 둘의 조합이 AF3를 상회하는 새로운 SOTA를 달성했다고 보고한다.

### 메커니즘 핵심 가정

당질 위상적 특징 추가가 유효하려면: 기존 모델이 당질의 분지형(branched) 그래프 구조를 선형 SMILES 표현에서 충분히 학습하지 못해 위상 정보가 독립적 신호 가치를 가져야 한다. 에너지 손실이 유효하려면: 당질-단백질 계면에서의 물리적 에너지가 도킹 포즈 품질의 주요 결정 인자여야 한다.

### 재현 가능성

- **코드·데이터**: 미확인. NeurIPS 2026 포스터 페이지에서 링크 확인 필요.
- **베이스라인 공정성**: 8개 모델 공개 구현을 사용했다면 비교는 공정하나, 각 모델의 동일 조건 훈련 여부 확인 필요.
- 미제공: 데이터셋 크기(PDB 복합체 수), 각 일반화 설정의 훈련/테스트 분할 방식, 평가 지표(RMSD 컷오프 기준) 등은 원문 확인 전까지 미확인.

### 강점 / 한계

**강점**
- 당질 도킹 분야 최초 체계적 벤치마크 — 이후 방법론 비교의 기준선 제공.
- 두 가지 일반화 설정(단백질·당질)이 실제 응용에서의 어려움을 현실적으로 포착.
- AF3 수준에서 출발해 미세조정만으로 SOTA를 넘겼다는 점은 실용적 업그레이드 경로 제시.

**한계**
- 저자·소속 미확인 — 연구 그룹 신뢰성·이해상충 여부 판단 불가.
- 코드·데이터 미확인 — 재현 가능성 현재 불명.
- 당질 구조 다양성이 실제 PDB 분포를 대표하는지(희귀 당질 구조 포함 여부) 원문 확인 필요.
- AF3를 미세조정의 기반으로 쓰는 경우 AF3 라이선스 조건(비상업적 연구 제한) 준수 여부 확인 필요.

### 검증 수준

in silico. PDB 구조 기반 도킹 재현 평가(리독킹). 실험적 검증(ITC·SPR 등) 없음. preprint(미동료심사) · NeurIPS 2026 포스터(동료심사 통과).

### 내 연구 활용 가능성

항체 당질화 변이체의 Fc 수용체 결합 모델링, 당질 리간드 기반 표적 발굴 시 이 벤치마크를 기준선으로 삼을 수 있다. 코드·데이터 공개 여부 확인 후 실제 파이프라인 통합 검토 권장. 당질 다양성이 낮은 내부 데이터셋에서의 성능은 별도 평가 필요.

## C3. SelectBench: SBDD 생성 모델의 선택성 평가

**출처**: arXiv:2610.24124 · preprint(미동료심사) · 2026-10-16 · NeurIPS 2026 accepted poster #138964
**저자**: University of Toronto · Université de Montréal (2차 출처 Pebblous 블로그 기반 — 저자명 개인 확인 필요)
**코드·데이터**: 미확인
**정보 신뢰도**: NeurIPS 2026 포스터 초록, Pebblous 블로그 2차 요약, WebSearch 스니펫 기반. arXiv 원문 직접 확인 불가.

### 문제의식 선행

SBDD(구조 기반 신약 설계) 생성 모델이 목표 단백질 결합력(affinity) 최적화에 집중한 나머지, 오프타깃 단백질 결합 — 즉 독성·부작용의 직접 원인 — 을 체계적으로 평가한 연구가 없었다. 선택성(selectivity)은 실제 약물 개발에서 결합력만큼 중요하지만 ML 벤치마크에서 비어 있던 축이다.

### 핵심 방법론적 기여

**기존 한계 → 이번 해결**: 기존 SBDD 평가(CrossDocked2020 Vina 점수 등)는 목표 단백질에서의 결합력 순위에만 집중했다. SelectBench는 선택성을 세 가지 평가 설정으로 분해한다.

1. **문헌 케이스 스터디**: 선택성이 주요 이슈였던 실제 약물 개발 사례 재현.
2. **제약업계 안전 스크리닝 패널(85개 오프타깃 구조)**: 실제 안전성 검사에 쓰이는 표준 오프타깃 패널. 이 설정이 방법론적으로 핵심이다 — 실제 임상 개발 파이프라인의 계산적 대리물.
3. **대규모 구조 쌍(CrossDocked2020 기반, 9,900쌍)**: 광범위한 통계적 평가. 단, Pebblous 블로그 한국어판에 따르면 계산 비용으로 인해 easy 쌍 9,834개 중 100개만 평가했고, medium·hard 쌍은 전량 평가. 검토필요: 이 서브샘플링이 결과 편향을 유발할 수 있음.

**주요 발견**: 9개 SBDD 모델 평가 결과 — 선택성 학습 모델도 오프타깃 판별이 미미하고, 추론 시 유도(inference-time guidance)도 제한적 개선에 그쳤다.

### 메커니즘 핵심 가정

현재 SBDD 생성 모델이 선택성을 달성하려면: 구조적으로 유사한 오프타깃 단백질 결합 포켓과 목표 결합 포켓을 구분할 만한 기하 특이성을 학습 표현이 포착해야 한다. 이 논문이 시사하는 바는 현재 모델들이 이 능력을 갖추지 못했다는 것이다.

### 재현 가능성

- **코드·데이터**: 미확인. NeurIPS 2026 포스터 페이지 확인 필요.
- **베이스라인 공정성**: 9개 모델 공개 구현 사용은 재현 가능성 높음. 단, 각 모델의 훈련 데이터가 CrossDocked2020과 겹칠 경우 테스트셋 오염 위험 존재.
- **Easy 쌍 서브샘플링**: 전체 easy 쌍의 ~1%만 평가한 점은 결론의 일반화 한계. 검토필요: 서브샘플링이 무작위인지, 특정 단백질 계열에 편중됐는지 원문 확인 필요.

### 강점 / 한계

**강점**
- SBDD 분야에서 선택성 평가 부재라는 구조적 맹점을 정면으로 짚은 최초 체계적 벤치마크.
- 산업계 실제 안전 패널(85개 오프타깃) 포함 — 실용적 타당성 높음.
- 모든 주요 SBDD 생성 모델을 동일 조건에서 비교한 공정한 설계.

**한계**
- Easy 쌍 서브샘플링(1%)으로 통계적 대표성 약화.
- 코드·데이터 미확인 — 재현 및 후속 연구 접근성 불명.
- 선택성 실패의 원인 분석(모델 아키텍처? 훈련 데이터? 목적함수?)이 현재 평가에서 충분히 분리됐는지 원문 확인 필요.
- "선택성 학습 모델"의 구체적 학습 전략이 무엇인지 원문 확인 필요(어떤 손실 함수·데이터 증강 사용).

### 검증 수준

in silico. 구조 기반 평가(도킹 스코어·가상 스크리닝 메트릭). 실험적 선택성 측정(Ki 비율, 세포 독성) 없음. preprint(미동료심사) · NeurIPS 2026 포스터(동료심사 통과).

### 내 연구 활용 가능성

신약AI 생성 모델의 선택성 실패율을 정량화하는 프레임으로 직접 활용 가능하다. 85개 오프타깃 안전 패널은 in silico 다중오프타깃 스크리닝의 표준 기준선으로 채택할 만하다. SBDD 파이프라인 평가 시 결합 친화도 단독 지표에서 선택성 지표로 확장할 때 이 벤치마크 설계를 참고할 것을 권장한다.

## C4. LG-Bench: 생명과학 LLM 그래프 구조 벤치마크

**출처**: arXiv:2610.26787 · preprint(미동료심사) · 2026-10-19 · NeurIPS 2026 accepted poster #139764
**저자**: Lu Sun, Xiangyi Zhang, Guangtao Zhai 외 (2차 출처 book.st-hakky AI 요약 기반 — 저자명 원문 확인 권장)
**코드·데이터**: 미확인
**정보 신뢰도**: NeurIPS 2026 포스터 초록, book.st-hakky 2차 요약, WebSearch 스니펫 기반. arXiv 원문 직접 접근 불가.

### 문제의식 선행

현행 생명과학 LLM 벤치마크(MedQA, MMLU-Medical 등)는 각 문항을 독립 이진 질문으로 취급하므로, 모델이 연관된 개념들을 일관되게 이해하는지 — "단순 암기인가, 개념 관계를 파악했는가" — 를 평가하지 못한다.

### 핵심 방법론적 기여

**기존 한계 → 이번 해결**: 독립 MCQ 배터리의 한계를 넘어, 질문들을 의미 관계 그래프(semantic relationship graph)로 연결한 벤치마크 구조를 도입했다.

1. **그래프 구성**: 의학·생물학·화학 3개 도메인에 걸친 10,000개 이상 4지선다 문항을 양방향 매칭(bidirectional matching)과 의미적 유사도(semantic similarity)로 엣지를 부여해 그래프 노드로 연결.

2. **Global Coherence Score (GCS)**: 의미적으로 연관된 이웃 질문들 내에서 모델 응답의 일관성을 측정. 단순 정확도가 아닌, "올바른 이유로 맞혔는가"를 간접 측정.

3. **Knowledge Balance Score (KBS)**: 오답이 그래프 내 특정 개념 영역에 집중됐는지 시각화 — LLM의 개념적 맹점(blind spot) 지도 생성.

검토필요: 2차 요약(book.st-hakky)에서 GCS를 "Global Consistency Score"로 표기하는 불일치 있음. NeurIPS 포스터 초록의 명칭을 1차 출처로 취급해야 하며, 원문 arXiv 확인 권장.

### 메커니즘 핵심 가정

그래프 구조 일관성이 의미 있으려면: (a) 의미적 유사도 기반 엣지가 실제 개념적 의존 관계를 잘 포착해야 하고, (b) 일관성 실패가 진짜 이해 부족을 반영해야 한다 — 의미적으로 유사하지만 독립된 사실들 사이의 일관성은 진정한 이해와 무관할 수 있다.

### 재현 가능성

- **코드·데이터**: 미확인.
- **문항 품질 보증**: 10,000개 문항이 어떻게 구축됐는지(전문가 작성, LLM 생성 후 검수, 기존 벤치마크 재활용 등) 원문 확인 필요. LLM 생성 문항이라면 평가 오염(evaluation contamination) 위험 존재.
- **그래프 엣지 기준**: 의미 유사도 임계값(threshold), 유사도 모델 선택이 결과에 영향. 이 설계 선택의 민감도 분석이 필요.

### 강점 / 한계

**강점**
- 독립 MCQ의 "암기 편향" 한계를 개념 관계 일관성으로 보완하는 새로운 평가 프레임.
- KBS를 통한 LLM 맹점 가시화 — 어떤 개념 영역에서 취약한지 진단 도구로 활용 가능.
- 의학·생물학·화학 다도메인 포괄 — 생의약 LLM 종합 평가에 적합.

**한계**
- 그래프 엣지 구성의 의미 유사도 기준이 자의적일 수 있고, 이 선택이 GCS에 직접 영향.
- 10,000개 문항 구축 과정·출처 불명 — 기존 벤치마크 데이터 중복 위험 또는 LLM 생성 오염 위험 미검증.
- 일관성 측정이 "이해"의 프록시로 충분한지는 철학적으로 개방된 질문 — 정답 패턴 없이도 일관성은 달성 가능.
- 코드·데이터 미공개 시 재현 및 자체 평가 어려움.

### 검증 수준

in silico. LLM 벤치마크 평가. 생명과학 실험적 검증 없음. preprint(미동료심사) · NeurIPS 2026 포스터(동료심사 통과).

### 내 연구 활용 가능성

바이오의약 LLM(GPT-4o, Claude, Gemini, domain-tuned 모델)을 연구 보조로 도입할 때 단순 정확도가 아닌 개념 일관성 기준으로 평가하는 툴킷으로 활용 가능하다. 코드 공개 시 내부 평가 데이터에 KBS를 적용해 특정 유전체·임상 개념 영역에서의 모델 취약점을 사전 파악하는 용도로 검토할 만하다.

## C5. Multi-Obj Protein Opt: 모듈식 확산 스티어링 다목적 단백질 최적화

**출처**: arXiv:2610.28943 · preprint(미동료심사) · 2026-10-20

### 외부 맥락: 다목적 단백질 최적화 방법론 지형

이 논문이 속할 것으로 추정되는 방법론 흐름에는 다음 동계 연구들이 있다.

- **MP2D (IJCAI 2026, Kong et al.)**: 조건부 이산 확산 + MCTS로 항균 펩타이드 및 단백질 바인더에서 4~5개 경쟁 목표 동시 최적화. Pareto 기반 보상으로 트리 탐색을 유도. (출처: IJCAI 2026 proceedings)
- **MoMST (ICML 2026)**: 확산 모델 내 메모리 기반 자기 대조 학습 + 테스트 타임 Pareto 정렬.
- **Feynman-Kac 스티어링 (arXiv 2511.09216)**: 재훈련 없이 사용자 정의 보상으로 확산 도중 스티어링 — "모듈식" 접근의 선행 사례.

추정: arXiv 2610.28943이 "모듈식"이라는 키워드를 제목에 포함했다면, 재훈련 없이 교환 가능한 보상/제약 모듈로 목표를 구성하는 방식일 가능성이 높다. 단, 원문 확인 전까지 이 추정을 사실로 다루지 않는다.
