# 2026-W31 방법 렌즈 분석

## 이번 주 방법론 흐름 요약

이번 주를 관통하는 공통 주제는 생물학 데이터의 도메인 특이적 복잡성에 맞춤 설계된 아키텍처들이다. CENO는 긴 DNA 서열의 다중 태스크 통합을 위해 Mamba/Attention/MoE 하이브리드와 MSA 후처리를 결합한다. Vilya-2는 비정규 화학을 가진 펩타이드 계면 모델링에서 전원자 확산 트랜스포머의 일반화 가능성을 보인다. PMRD는 멀티모달 약물 표현에서 노이즈-기전 분리를 명시적 목표로 설계했다. SCTA는 scRNA-seq 표적 발굴 파이프라인의 재현성 결핍을 에이전트 역할 전문화와 교차 실행 안정성 기준으로 풀었다. EHR FM은 자기회귀 EHR 모델에 다중 모달리티를 통합하는 설계 선택지를 처음 체계적으로 비교했다.

## 논문별 방법 분석

### 1. CENO (DOI:10.64898/2026.07.28.741284)

**무엇이 새로운가**: Mamba(선형 어텐션)·Transformer Self-Attention·MoE를 결합한 하이브리드 백본에 다중 종 다중 서열 정렬(MSA) 사후 훈련을 더해 긴 DNA 서열 이해·변이 효과 점수(VEP)·조절 서열 신규 생성 세 태스크를 단일 자기회귀 모델로 처리하는 게놈 스케일 세계 모델. 진화적 MSA 정보를 사후 훈련 지도 신호로 쓰는 방식이 기존 단일 종 DNA LM과 방법론적으로 차별화된다.

**핵심 가정**: 다중 종 진화 정렬이 비코딩 조절 서열의 기능적 제약을 충분히 포착한다는 것. 이 가정이 깨지면 생성된 조절 서열이 기능적으로 무의미할 수 있다. MoE 전문화가 실제로 태스크별로 분리된다는 암묵적 가정도 포함된다.

**재현 가능성**: 코드·모델 완전 공개(github.com/CladeTeam/CENO). HuggingFace trust_remote_code, TraitGym VEP 파이프라인, vLLM 오프라인 추론 데모 포함. 다만 초록에서 구체 벤치마크 수치가 명시되지 않아 독립 재현 전까지 성능 주장의 크기는 불명확하다. 미제공: 구체 벤치마크 수치.

**베이스라인**: 초록 기준 명시 없음. 검토필요: 비교 모델(Evo-2, Nucleotide Transformer, HyenaDNA 등)과의 직접 비교 결과는 본문 확인 필요.

**강점·한계**: 완전 공개 코드 + 세 태스크 통합 단일 모델 + MSA 기반 진화 신호 활용 // 구체 성능 수치 미명시, 독립 재현 전 주장 크기 불명확.

**내 연구 적용 메모**: TraitGym VEP 파이프라인으로 자체 변이 데이터에 바로 적용 가능하다. 조절 서열 생성 모듈은 CRISPRi 표적 설계나 합성 프로모터 최적화 프로젝트의 출발점이 될 수 있다.

### 2. Vilya-2 (arXiv:2607.25156)

**무엇이 새로운가**: AlphaFold 계열이 처리하지 못한 비정규 잔기·거대고리화·이황화 결합 스테이플을 포함하는 펩타이드 치료제와 표적 단백질 계면을 전원자(all-atom) 확산 트랜스포머로 모델링. Vilya-1의 개별 분자 구조 예측을 단백질-펩타이드 복합체 계면 수준으로 확장하고, 훈련에서 보지 못한 거대고리·미니단백질까지 일반화된다고 보고한다.

**핵심 가정**: 전원자 표현이 비정규 화학을 적절히 포착하고, 훈련 데이터의 펩타이드 화학 다양성이 테스트 시 비정규 잔기 공간을 충분히 포괄한다는 것. 일반화 주장의 범위는 독립 재현 전 불명확하다.

**재현 가능성**: Riptides 벤치마크 공개(github.com/VilyaPublic/Riptides). 미제공: 모델 추론 코드 공개 여부 미확인. Riptides로 타 그룹 독립 재현은 가능하다.

**베이스라인**: 초록 기준 — 대표적 공동-폴딩(co-folding) 모델을 크게 상회하고 결합 수용체를 템플릿으로 제공해도 동일. 구체 비교 모델명은 본문 확인 필요. 핵심 수치: 59.1% sub-2Å backbone 회복(초록 기준).

**강점·한계**: 공개 벤치마크 + 비정규 화학 일반화 주장 + 구체 정량 수치(59.1%) // 모델 추론 코드 미확인, 단백질 수용체 구조 가용성이 실용적 전제 조건, 훈련 데이터 다양성 범위 불명확.

**내 연구 적용 메모**: Riptides 벤치마크에 자체 보유 펩타이드 데이터를 추가해 독립 평가가 가능하다. 거대고리 합성 프로젝트가 있다면 계면 구조 예측 단계 검토 가치 있다.

### 3. PMRD (arXiv:2607.25322)

**무엇이 새로운가**: 화학 구조·유전자 발현·세포 형태 세 모달리티에서 메커니즘 일치 인자(mechanism-consistent factors)와 모달리티별 노이즈를 분리하는 도메인 분리 기반 프레임워크. 직접 융합이나 인스턴스 수준 대조 정렬이 scaffold-hop 화합물을 잘못 분리하는 문제를 합의 반응 도메인(consensus response domain)으로 해결한다. KDD 2026 채택.

**핵심 가정**: 다중 모달리티에 공통되는 잠재 인자가 실제 약리 기전을 선택적으로 반영한다는 것. 배치 효과가 강하면 합의 도메인이 배치를 학습할 위험이 있다.

**재현 가능성**: 미제공: 코드·데이터셋 공개 미확인. 소속 기관 미기재. 질문: 사용 데이터셋(L1000 CMAP, JUMP-CP 등) 원문 확인 필요. KDD 2026 채택으로 방법론 신뢰도는 일정 이상.

**베이스라인**: 직접 융합, 인스턴스 수준 대조 정렬 명시. 구체 수치 비교는 본문 확인 필요.

**강점·한계**: KDD 2026 채택 + 노이즈-기전 분리 명시적 설계 // 코드 미공개, 소속 기관 미기재, 구체 수치 미명시.

**내 연구 적용 메모**: 세포 표현형 데이터를 화학 구조와 통합하는 파이프라인에서 도메인 분리 아이디어를 배치 효과 처리에 응용 가능하다. 코드 공개 시 CMAP L1000 데이터로 재현 우선.

### 4. SCTA (arXiv:2607.23821)

**무엇이 새로운가**: scRNA-seq 표적 발굴 파이프라인을 cell-type triage·candidate filtering·evidence aggregation 전담 에이전트로 분해하고, 평가 기준을 단일 실행 그럴듯함에서 교차 실행 안정성(cross-run stability)으로 전환한 방법론적 시도. BioKDD 2026 채택.

**핵심 가정**: 전문 에이전트 분해가 각 결정점의 불확실성을 독립적으로 제어 가능하다는 것. 구조화된 생물학적 증거가 충분히 풍부해야 제약이 의미 있다. 깨지면 안정적으로 틀릴(consistently wrong) 위험.

**재현 가능성**: 미제공: 코드·데이터 공개 미확인. 유전성 만성 췌장염 단일 데이터셋 ablation만 제시. 워크숍 논문 수준.

**베이스라인**: 에이전트 구성 요소 ablation 비교 포함. 전통 Scanpy/Seurat 파이프라인과의 직접 비교는 초록 기준 미확인.

**강점·한계**: 재현성을 성능과 동등하게 취급하는 설계 전환 // 단일 질환 데이터셋 외 검증 없음, 도메인 이전 비용 불명확.

**내 연구 적용 메모**: 코드 공개 시 자체 scRNA-seq 데이터에서 stability 지표를 기존 파이프라인과 비교 검증하는 첫 적용이 가능하다.

### 5. EHR FM (arXiv:2607.22264)

**무엇이 새로운가**: 구조화 EHR 이벤트 코드만 다루던 자기회귀 EHR 파운데이션 모델에 ECG 파형·흉부 X선·임상 노트를 모달리티별 잠재 압축(latent compression)과 게이트 교차 어텐션(gated cross-attention)으로 시간 정렬하여 통합하는 프레임워크. (1) 잠재 압축 방법, (2) 사전 훈련 인코더 선택이라는 두 핵심 설계 선택지를 MIMIC-IV에서 체계적으로 비교한 최초 연구.

**핵심 가정**: 모달리티별 사전 훈련 인코더가 임상 EHR 도메인에서 의미 있는 표현을 추출한다는 것. 게이트 교차 어텐션이 시간 정렬을 충분히 포착한다는 것.

**재현 가능성**: 미제공: 코드 공개 미확인. MIMIC-IV는 공개 데이터셋이므로 코드 공개 시 재현 가능성 높다.

**베이스라인**: 비압축 교차 어텐션, 평균 풀링과 비교. 최적 잠재 압축이 두 기준 모두를 상회(초록 기준; 구체 AUC 수치 미명시).

**강점·한계**: ICML 2026 워크숍 채택 + MIMIC-IV 실제 임상 데이터 후향 검증 + 설계 선택지 체계적 비교 // 단일기관 후향 검증, 코드 미확인, 구체 수치 미명시.

**내 연구 적용 메모**: 멀티모달 EHR 분석 프로젝트 설계 시 게이트 교차 어텐션 + 잠재 압축 조합을 기본 아키텍처 옵션으로 참조 가능하다. 코드 공개 시 MIMIC-IV 제어 절제 실험 재현이 첫 검증 단계다.

## 방법론 관점 종합 메모

- **코드 공개 현황**: CENO(완전 공개)·Vilya-2(Riptides 벤치마크 공개)가 즉시 활용 가능한 최상위. PMRD·SCTA·EHR FM은 코드 공개 미확인.
- **검증 수준**: EHR FM만 후향(MIMIC-IV) 임상 데이터 검증, 나머지 4편은 in silico. 전향·다기관 검증은 없음.
- **공통 한계**: 구체 벤치마크 수치 미명시(CENO, EHR FM), 단일 데이터셋 ablation(SCTA), 코드 미공개(PMRD, SCTA, EHR FM) — 독립 재현 전까지 주장의 크기를 잠정적으로 유지해야 한다.
