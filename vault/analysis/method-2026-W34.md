## [C1] MCTH — Monte Carlo Tree Hallucination for Biomolecular Co-design

**원문**: arXiv:2608.17381 (preprint, 미동료심사, 2026-08-18 제출)
**저자**: Xuefeng Liu, Mingxuan Cao, Xiao Luo, Songhao Jiang, Tobin Sosnick, Jinbo Xu, Louis Maher, Rick Stevens (U. Chicago / Argonne National Laboratory)
**링크**: https://arxiv.org/abs/2608.17381
**코드**: 미공개 — 재현 검증 불가

---

### 문제의식 선행

단백질 설계 도구들은 특정 분자 쌍(단백질-단백질, 단백질-리간드 등)에 각각 최적화된 별도 모델을 필요로 한다. 통합 프레임워크 없이 쓰면 각 모달리티(modality)마다 전문 도구를 따로 세팅해야 하며, 새로운 분자 쌍이 등장할 때마다 모델을 재훈련해야 한다는 비용이 발생한다.

### 무엇이 새로운가

MCTH는 동결된(frozen) 단백질 폴딩(folding) 및 역폴딩(inverse-folding) 모델을 변경 없이 블랙박스 오라클(black-box oracle)로 쓰면서, 이들이 생성하는 hallucination 궤적 위에 MCTS(Monte Carlo Tree Search)로 추론 예산을 배분한다. 핵심 신규성은 세 가지다.

1. **추론 시간 계산(inference-time compute) 재배분**: 추가 학습 없이 기존 frozen 모델의 탐색 공간에 MCTS를 얹어 적응적 예산 할당을 수행한다. 랜덤 샘플링이나 순환(cycling) 전략보다 같은 예산 내에서 더 나은 설계를 찾는다고 보고한다(검색 결과 기반, 원문 확인 필요).
2. **바이오물리 스코어링 통합(biophysics-informed scoring)**: 순수 모델 신뢰도(confidence)가 아닌 에너지 항(energy term)을 보상 신호로 결합. 모델 아티팩트와 물리적으로 타당한 설계를 구별하려는 의도.
3. **단일 프레임워크 다중 모달리티**: 단백질-RNA, 단백질-DNA, 단백질-단백질, 단백질-리간드를 동일한 MCTS 루프 안에서 처리. 기존 방법들이 모달리티별 별도 학습을 요구했던 것과 대비된다.

검색 결과에 따르면 사용된 frozen 모델에 ProteinMPNN(역폴딩), Boltz-2(평가 오라클), AlphaFold2(이중 전문가 구성에서 추가 평가)가 포함된다. 단일 전문가(Boltz-only) 구성에서 mean ipTM(interface predicted TM-score) 0.57, 이중 전문가 구성이 11개 타깃 중 9개에서 단일 전문가를 상회한다는 수치가 언급됐다. `검토필요:` 이 수치는 웹 검색 결과 기반이며 원문 직접 확인이 필요하다.

### 방법의 핵심 가정 (메커니즘 핵심 가정)

이 방법이 성립하려면 세 가지가 참이어야 한다.

- **Frozen 모델의 hallucination 다양성이 설계 공간을 충분히 커버한다**: MCTS가 좋은 설계를 찾으려면 random rollout이 만드는 궤적들이 실제 좋은 해 근방을 통과해야 한다. 모델이 특정 분자 쌍에 과도하게 편향(biased)되어 있으면 MCTS가 도달할 수 없는 영역이 생긴다.
- **바이오물리 스코어가 설계 공간에서 단조적(monotonic)이고 매끄럽다**: 에너지 항이 노이즈가 많거나 불연속적이면 MCTS의 UCB(upper confidence bound) 선택이 오도될 수 있다.
- **Frozen 모델이 목표 분자 쌍의 서열-구조 매핑을 충분히 학습했다**: 모델이 훈련 데이터에 없는 희귀 분자 쌍(예: 특정 RNA 클래스)을 다룰 때 hallucination의 질 자체가 낮아진다.

### 재현 가능성·검증 수준

| 항목 | 상태 |
|------|------|
| 검증 수준 | in silico (preprint, 미동료심사) |
| 코드 공개 | 미공개 |
| 데이터 공개 | 미제공: 별도 언급 없음 |
| 외부 평가 | 검색에서 held-out AlphaFold3·Chai-1을 search-time oracle 외 평가 도구로 사용했다고 언급 |
| ablation | 원문 직접 접근 불가 — 미제공 |

코드가 없으므로 독자가 다른 frozen 모델 조합이나 다른 분자 쌍에서 MCTS 전략을 재현·검증하기 어렵다. 베이스라인 비교(랜덤 샘플링, 순환 전략)는 언급됐지만, 공정성 여부(동일 계산 예산 통제 여부)는 원문 확인 전까지 `검토필요:` 상태.

### 강점 / 한계

**강점**
- 기존 모델을 재훈련 없이 쓰므로 AlphaFold3, RFdiffusion 등 새로운 folding 모델이 나올 때 즉각 교체 적용 가능하다.
- 다중 분자 쌍을 하나의 파이프라인에서 처리하는 범용성은 실험실 자동화 관점에서 매력적이다.

**한계**
- In silico 검증만 존재. 설계된 서열의 실험 합성·기능 검증 결과 없음.
- 코드 미공개로 재현 불가. "통합 프레임워크"라는 주장을 독자가 직접 검증할 수단이 없다.
- MCTS의 계산 비용(탐색 트리 깊이·너비)이 논문에서 어떻게 제어됐는지 원문 접근 없이 파악 불가. `미제공:` 실용적 계산 비용 수치.
- 바이오물리 스코어 선택이 분자 쌍마다 달라질 수 있으며, 이 선택이 결과에 얼마나 민감한지 불분명하다.

### 내 연구 적용 메모

`해석:` 단백질-DNA 혹은 단백질-RNA co-design 파이프라인을 구성하는 경우, 이 프레임워크는 기존 frozen 모델(ESMFold, ProteinMPNN 등)을 재사용하면서 탐색 전략만 업그레이드하는 방식으로 흥미롭다. 그러나 코드가 없으므로 지금 당장 실험에 쓰기는 어렵다. 논문이 공개되고 코드가 릴리스되면, 특히 단백질-리간드 co-design 태스크에서 ProteinMPNN + RFdiffusion 조합에 MCTS를 얹는 방식의 재현 실험을 검토할 만하다. 우선순위: 코드 공개 후 재평가.

## [C2] Horvath 에피제네틱 클럭 — 대리 끝점으로서의 체계적 검증

**원문**: Nature Medicine, DOI:10.1038/s41591-026-04524-1 (peer-reviewed, 2026-08-21 온라인)
**저자**: Steve Horvath (교신저자) — 소속: `추정:` Altos Labs (Cambridge, UK). 원문 확인 필요.
**링크**: https://doi.org/10.1038/s41591-026-04524-1
**코드**: 미제공: 별도 언급 없음

---

### 문제의식 선행

노화 개입 임상시험(longevity clinical trial)에서 수십 년의 추적 관찰이 필요한 사망·질환 끝점 대신 DNA 메틸화(DNA methylation) 클럭을 대리 끝점(surrogate endpoint)으로 쓰려는 시도가 늘고 있다. 그런데 "클럭이 나이 및 위험과 상관된다"와 "클럭이 진정한 대리 끝점 역할을 한다"는 별개의 주장이다. 이 구분이 체계적으로 검증된 적이 없었다.

### 무엇이 새로운가

이 논문은 방법적 신규성보다 **검증 설계의 신규성**이 핵심이다. GrimAge, PhenoAge 등을 포함한 16종 메틸화 클럭을 51개 종단 연구(longitudinal study) 데이터에 적용해, 각 클럭이 대리 끝점의 통계적 기준(예: Prentice 기준, 또는 이에 준하는 기준)을 만족하는지 체계적으로 시험한다. 기존에는 클럭의 예측력을 각 연구에서 독립적으로 보고했지만, 이 규모로 51개 종단 연구를 통합해 surrogate endpoint 행동 여부를 교차 검증한 사례가 없었다.

`미제공:` 어떤 구체적 통계 기준(Prentice criterion 외 변형 기준 등)을 썼는지, 51개 연구의 총 N이 얼마인지 원문 직접 접근 없이 파악 불가.

### 방법의 핵심 가정 (메커니즘 핵심 가정)

- **메틸화 클럭이 개입(intervention)에 의해 단기적으로 변하는 값이어야 한다**: 대리 끝점은 개입 후 충분히 빠르게, 예측 가능한 방향으로 움직여야 한다. 클럭이 너무 느리게 반응하거나 개입과 독립적으로 변하면 대리 끝점 역할을 못한다.
- **51개 종단 연구의 이질성(heterogeneity)이 메타분석적으로 제어 가능하다**: 코호트마다 측정 기법, 조직 유형, 연령 분포가 다르므로, 이를 통합하는 분석 방법의 선택이 결론에 영향을 준다.
- **대리 끝점 기준이 임상시험 설계와 맞게 정의됐다**: 임상적 의미는 clinical-analyst 영역이므로, 방법 관점에서는 "어떤 통계 기준을 적용했는가"가 핵심이다.

### 재현 가능성·검증 수준

| 항목 | 상태 |
|------|------|
| 검증 수준 | 후향/전향 혼합 (51개 종단 연구, peer-reviewed) |
| 코드 공개 | 미제공 |
| 데이터 공개 | 미제공: 51개 연구의 개별 데이터 접근성 불명확 |
| 외부 검증 | 51개 연구 자체가 다기관·다코호트 검증에 해당 |

Horvath는 주요 클럭의 원저자이므로 **이해상충(conflict of interest)** 가능성이 있다. `검토필요:` 저자가 직접 개발한 클럭(GrimAge, PhenoAge)과 타 연구자 클럭 간 결과 차이를 중립적으로 해석하는지 원문에서 확인 필요.

### 강점 / 한계

**강점**
- 51개 종단 연구를 단일 분석 틀로 통합한 규모는 에피제네틱 클럭 문헌에서 전례가 없는 수준이다.
- "예측력"과 "대리 끝점 타당성"을 명확히 구분하는 문제 정의 자체가 가치 있다. 이 구분이 없으면 클럭 예측력이 곧 임상 유효성인 것처럼 오해하기 쉽다.

**한계**
- 코드·분석 스크립트 미공개. 16종 클럭에 같은 기준을 적용했는지 독자가 검증할 방법이 없다.
- 저자 이해상충 가능성. Nature Medicine 심사에서 이를 어떻게 처리했는지 공개 여부 불명확.
- `미제공:` 클럭별 결과 수치, surrogate 기준 통과/실패 여부가 몇 개 클럭에서 어떻게 나왔는지 원문 접근 없이 파악 불가.

### 내 연구 적용 메모

`해석:` 노화 바이오마커나 후성유전체 데이터를 다루는 연구에서, 이 논문은 "클럭 값이 치료 반응을 설명한다"고 주장하기 전에 surrogate endpoint 기준을 점검하는 방법론적 프레임을 제공한다. 바이오마커 검증 파이프라인 설계 시 Prentice 기준 또는 이에 준하는 기준을 명시적으로 체크하는 단계를 추가하는 계기로 삼을 수 있다. 단, 분석 코드가 없어 직접 방법 재사용은 어렵다.

## [C3] EmitGCL — 지식 인식 그래프 대조 학습으로 미래 전이 예측

**원문**: Nature Communications, DOI:10.1038/s41467-026-76277-x (peer-reviewed, 2026-08)
**원본 bioRxiv**: 2025.05.16.654579
**링크**: https://doi.org/10.1038/s41467-026-76277-x
**코드**: 미공개 — 재현 검증 불가

---

### 문제의식 선행

유방암 등에서 림프절 음성(lymph node-negative) 판정을 받은 환자가 이후 원격 전이를 보이는 occult metastasis 문제는, 기존 영상 검사와 단일 오믹스 마커로 탐지하기 어렵다. 단세포 해상도(single-cell resolution)에서 전이 전구체 세포(metastatic precursor cell)를 사전에 잡아낼 방법이 필요했다.

### 무엇이 새로운가

EmitGCL은 지식 인식 그래프 대조 학습(knowledge-aware graph contrastive learning) 프레임워크다. 핵심 설계는 두 가지다.

1. **이질성 그래프(heterogeneous graph) 표현**: 환자의 원발 종양(primary tumor)과 전이 부위(metastatic site)에서 얻은 단세포 RNA 시퀀싱(scRNA-seq) 데이터를 세포-유전자 이질성 그래프로 표현한다. 전이 관련 경로(pathway) 사전 지식을 그래프 구조에 주입해, 단순 그래프 학습으로는 잡기 어려운 생물학적 신호를 증폭한다.
2. **대조 학습(contrastive learning)으로 전이 전후 차이 포착**: 같은 종양 계통(tumor lineage)의 원발 세포와 전이 세포 쌍 사이의 미묘한 차이를 대조 목적 함수로 학습하면서 배경 노이즈를 억제한다.

출력은 세 가지다: 전이 부위의 occult 전이 세포 식별, 원발 종양의 전이 전구체 세포 식별, 미래 전이를 표지하는 바이오마커 유전자 발굴.

`검토필요:` raw 파일에서 "멀티오믹스(multi-omics)"라고 표기됐으나, 웹 검색 결과에 따르면 모델 입력이 scRNA-seq에 집중된 것으로 보인다. 제목의 "multi-omics"가 실제로 어떤 오믹스 레이어를 사용하는지 원문 확인 필요.

HSP90AA1·HSP90AB1이 유방암 미래 전이 바이오마커로 동정됐다는 점은 raw 파일에 명시됨. 웹 검색에서 이 결과가 5개 독립 코호트 (n=420)에서 검증됐다고 언급됐으나, 이 수치는 `검토필요:` 원문 직접 확인 필요.

### 방법의 핵심 가정 (메커니즘 핵심 가정)

- **원발 종양과 전이 부위의 동시 scRNA-seq 데이터가 필요하다**: 모델이 두 부위의 매칭(matched) 데이터를 입력받는 설계라면, 원발 부위만 가진 환자에서는 직접 적용이 어렵다. `질문:` 이 매칭 조건이 실제 임상 데이터에서 얼마나 충족 가능한가.
- **전이 관련 경로 사전 지식이 대상 암종에서 유효하다**: 지식 인식(knowledge-aware) 구조는 사용한 경로 데이터베이스의 품질에 의존한다. 경로 지식이 덜 알려진 희귀 암종에서 성능 저하가 예상된다.
- **6개 암종에서 학습한 표현이 새로운 암종으로 전이 가능하다**: 7개 코호트 외의 암종이나 치료 맥락에서 모델이 일반화되는지는 별도 검증이 필요하다.

### 재현 가능성·검증 수준

| 항목 | 상태 |
|------|------|
| 검증 수준 | 후향 (N=7 코호트, 6개 암종) + 시험관 내(in vitro) HSP90 억제 실험 |
| 코드 공개 | 미공개 — 재현 검증 불가 |
| 데이터 공개 | 미제공: 공개 데이터셋 여부 원문 확인 필요 |
| ablation | 원문 접근 불가 — 미제공 |

7개 코호트를 쓴 것은 단일 기관 연구 대비 강점이나, 모두 후향(retrospective) 설계다. 전향적 외부 검증 없이 prospective 임상 유용성을 주장하기는 어렵다(임상 함의는 clinical-analyst 영역).

### 강점 / 한계

**강점**
- 그래프 신경망에 경로 사전 지식을 주입하는 접근은, 단순 데이터 기반 학습보다 해석 가능성을 높인다. 바이오마커 발굴 결과(HSP90 계열)가 in vitro 검증까지 연결된 점은 in silico 수준을 넘는다.
- 6개 암종이라는 범위는 단일 암종 특화 모델보다 실용적이다.

**한계**
- 코드 미공개. "멀티오믹스"라는 주장의 구체적 오믹스 구성 불명확.
- 매칭된 원발-전이 scRNA-seq 데이터 확보가 표준 임상 워크플로에서 쉽지 않다.
- 후향 코호트 기반이므로 선택 편향(selection bias) 가능성 내재. 전이 확인된 사례가 코호트에 편향적으로 포함됐을 가능성 배제 불가.
- `미제공:` 경쟁 방법 대비 구체적 수치(sensitivity, specificity 수치 범위 등)는 원문 접근 없이 인용 불가.

### 내 연구 적용 메모

`해석:` 유전체·전사체 데이터를 다루는 바이오인포 연구에서, 이질성 그래프 + 경로 지식 주입 + 대조 학습의 조합은 세포 상태 분류 문제에 응용 가능한 설계 패턴이다. 코드가 공개되면, 다른 임상 표현형(예: 치료 반응)을 예측하는 scRNA-seq 분석에 유사 프레임워크를 적용하는 실험을 검토할 수 있다. 지금은 코드 공개 대기 상태.

## [C4] 양자 커널 SVM — 폐암 조기 발견을 위한 DNA 단편체학·메틸화 분류

**원문**: arXiv:2608.19304 (preprint, CIBB 2026 채택, 2026-08-19 제출)
**저자**: Hamed Javidi, Alex Zajichek, Hakan Doga, Laxmi Parida, Filippo Utro, Peter J. Mazzone (IBM Research; Cleveland Clinic)
**링크**: https://arxiv.org/abs/2608.19304
**코드**: 미공개 — 재현 검증 불가

---

### 기존 한계 → 이번 해결 시도

DNA 단편체학(fragmentomics)과 DNA 메틸화(methylation)를 통합한 액체생검(liquid biopsy) 분류는 고차원의 비선형 패턴 포착이 중요하다. 고전(classical) SVM 커널로는 커널 함수의 설계 공간이 제한되며, 특히 특징 수가 적을 때 표현력 한계가 있을 수 있다. 이 논문은 양자 커널(quantum kernel)을 통해 고전 커널이 표현하기 어려운 특징 공간을 탐색한다.

### 무엇이 새로운가

신규성의 핵심은 알고리즘 자체보다 **적용 방식**에 있다.

1. **특징 인코딩 전처리**: DNA 단편체학 및 메틸화 특징을 각도(angle) 및 밀집-각도(dense-angle) 특징 맵(feature map)으로 변환해 양자 힐베르트 공간(quantum Hilbert space)에 인코딩. 다양한 얽힘(entanglement) 전략을 실험.
2. **충실도 기반 양자 커널(fidelity-based quantum kernel)**: 두 데이터 포인트 사이의 상태 벡터(statevector) 내적을 커널 값으로 사용. 정확한 상태 벡터 시뮬레이션(exact statevector simulation)으로 계산.
3. **분류기 통합**: 사전 계산 양자 커널(precomputed-kernel SVM) 및 커널-PCA 로지스틱 회귀(kernel-PCA logistic regression)에 통합.

웹 검색 결과에 따르면, DNA 단편체학 20개 특징 실험에서 양자 커널이 AUC ~81-82%, 고전 SVM 베이스라인이 ~78-79%로 보고됐다. `검토필요:` 이 수치는 웹 검색 기반이며 원문 직접 확인 필요. `미제공:` 메틸화 데이터셋에서의 양자 vs 고전 비교 수치.

### 방법의 핵심 가정 (메커니즘 핵심 가정)

- **현재 양자 커널 = 시뮬레이션**: 논문이 정확한 상태 벡터 시뮬레이션을 사용했다는 점은, 실제 양자 하드웨어가 아닌 고전 컴퓨터 위의 양자 회로 에뮬레이션임을 의미한다. `외부 맥락:` 현재 NISQ(Noisy Intermediate-Scale Quantum) 시대의 실제 양자 기기는 노이즈로 인해 시뮬레이션 성능을 재현하기 어렵다. 이 논문의 결과가 실제 양자 하드웨어에서 동일하게 나온다는 주장은 별도 검증 필요.
- **20개 특징의 저차원 설정**: 양자 커널의 이론적 이점은 특징 수가 늘어날 때 지수적으로 표현력이 증가한다는 가정에 기반한다. 20개 특징이라는 매우 좁은 설정에서 고전 대비 우위가 일반적으로 성립하는지 의문이다.
- **소규모 데이터셋 전제**: 액체생검 데이터는 일반적으로 샘플 수가 제한적이다. `추정:` 이 조건이 결과를 유리하게 작용했을 가능성이 있다. 데이터가 커지면 고전 ML 방법이 더 경쟁력 있을 수 있다.

### 재현 가능성·검증 수준

| 항목 | 상태 |
|------|------|
| 검증 수준 | in silico — 시뮬레이션 기반 (CIBB 2026 채택, 미동료심사 수준) |
| 코드 공개 | 미공개 |
| 데이터 공개 | 미제공: Cleveland Clinic 임상 데이터 — 공개 어려울 것으로 추정 |
| 외부 검증 | 없음 |
| 실제 양자 하드웨어 실험 | 없음 |

### 강점 / 한계

**강점**
- DNA 단편체학 + 메틸화를 양자 커널로 연결하는 시도 자체는 탐색적 방법론으로서의 가치가 있다.
- IBM Research + Cleveland Clinic 협업이라는 기관 자원은 향후 실제 하드웨어 실험으로 이어질 가능성을 열어둔다.

**한계**
- 실제 양자 하드웨어 실험 없음. 현재 결과는 고전 컴퓨터의 양자 회로 에뮬레이션이다.
- AUC 차이(~3pp)가 통계적으로 유의미한지, 샘플 수 기반 신뢰구간이 얼마인지 원문 접근 없이 알 수 없다.
- 특징 수 20개는 실제 액체생검 파이프라인의 고차원 데이터와 거리가 있다.
- `해석:` 현 시점에서 이 방법이 고전 ML 대비 임상적으로 의미 있는 우위를 보인다고 보기 어렵다. 탐색적 방법론 논문으로 읽어야 한다.

### 내 연구 적용 메모

`해석:` 바이오인포 연구에서 양자 커널을 단편체학 분석에 직접 도입하기는 아직 시기상조다. 소규모 특징 공간에서 탐색적 벤치마크로 참조하는 수준. 실제 양자 하드웨어가 NISQ 한계를 넘어설 때 재평가가 필요하다. 당장의 실용 가치: 낮음.

## [C5] EpiBench — LLM의 에피토프(epitope) 추론 능력 체계적 평가

**원문**: arXiv:2608.06022 (preprint, 미동료심사)
**저자**: Zirui Wang et al. (상세 소속 원문 확인 필요)
**링크**: https://arxiv.org/abs/2608.06022
**코드**: 미제공: 언급 없음

---

### 문제의식 선행

항체 약물 개발(antibody drug discovery)에서 LLM을 활용하려는 시도가 늘고 있지만, LLM이 에피토프(epitope, 항원 결합 부위) 추론을 실제로 할 수 있는지 체계적으로 평가한 벤치마크가 없었다. 기존 에피토프 예측 평가는 구조 모델 중심이었고, 서열 기반·자동 채점 가능한 LLM 전용 벤치마크가 부재했다.

### 무엇이 새로운가

EpiBench는 세 가지 측면에서 기존 에피토프 평가와 차별화된다.

1. **폐쇄형·서열 기반(closed-book, sequence-based)**: 구조 정보 없이 서열만으로 에피토프를 추론하도록 설계. LLM이 실제 생물학적 맥락 추론 능력을 갖는지 테스트한다.
2. **자동 채점 가능(automatically scorable)**: 인간 평가자 없이 정량 평가 가능하도록 설계. 1,609개 샘플의 데이터 구성: 구조적 항체-항원 접촉(structural antibody-antigen contact), 기능적 B세포 분석(functional B-cell assay), 딥 돌연변이 스캐닝(deep mutational scanning, DMS) escape 측정 데이터 기반. 바로 가기 평가 아티팩트(shortcut-based evaluation artifact)를 줄이기 위한 통제 샘플링(controlled sampling)을 사용했다.
3. **5가지 과제의 계층적 구성**: 표적 영역 발견(targetable region discovery), 항체 조건부 에피토프 동정(antibody-conditioned epitope identification), 에피토프 빈닝(epitope binning), 기능적 에피토프 평가(functional epitope assessment), 항체 탈출 평가(antibody escape assessment). 단일 능력이 아닌 에피토프 추론의 여러 층위를 분리 진단한다.

### 방법의 핵심 가정 (메커니즘 핵심 가정)

- **서열만으로 에피토프 추론이 가능해야 한다는 가정**: 현실에서 에피토프는 구조적 맥락에 크게 의존한다. 서열 기반 폐쇄형 설계는 LLM 평가에 적합하지만, "서열만으로 풀 수 있는 문제"와 "구조가 필요한 문제"를 구분하지 않으면 LLM의 실제 유용성을 과소 또는 과대평가할 수 있다.
- **DMS 데이터가 실제 임상 에피토프와 상관성이 높다**: DMS escape 측정은 실험실 조건의 선택압 데이터다. 실제 임상 escape 변이와 어느 정도 일치하는지는 별도 검토가 필요하다.
- **9개 LLM 샘플이 현재 LLM 능력을 대표한다**: 범용 LLM 9개의 평가 결과가 항체 특화 모델(예: AntiBERTy, AbLang 등)을 배제하고 있다면, 벤치마크의 결론이 "범용 LLM의 한계"에 국한될 수 있다. `질문:` 항체·단백질 특화 언어 모델을 포함한 평가가 있는지 원문 확인 필요.

### 재현 가능성·검증 수준

| 항목 | 상태 |
|------|------|
| 검증 수준 | in silico (벤치마크 평가, preprint, 미동료심사) |
| 코드 공개 | 미제공 |
| 데이터 공개 | 미제공: 1,609 샘플 데이터셋 공개 여부 원문 확인 필요 |
| 베이스라인 | 과제별 task-specific baseline 사용 (웹 검색 결과 기반) |

벤치마크 논문으로서 데이터셋과 평가 코드의 공개 여부가 재사용 가능성을 결정한다. 미공개 시 독자가 새로운 모델을 동일 조건에서 평가할 수 없어 비교 가능성이 사라진다.

### 강점 / 한계

**강점**
- 에피토프 추론을 위한 최초의 체계적 LLM 벤치마크라는 위치 선점. 항체 약물 개발에서 LLM 활용 논의를 위한 기준선을 제공한다.
- 5가지 과제를 계층적으로 설계해 LLM의 어느 능력이 부족한지 분리 진단 가능하다는 점이 단순 정확도 비교보다 유익하다.
- DMS 데이터를 포함함으로써 항체 escape 평가라는 임상 관련 과제를 포함했다.

**한계**
- 코드·데이터 미공개 시 벤치마크의 재사용 가치가 급감한다.
- 범용 LLM만 평가했다면, 항체·단백질 특화 모델과의 비교가 없어 "LLM 전반의 한계"를 주장하기 어렵다.
- 서열 기반 설계의 한계: 구조 정보 없이 에피토프를 맞추기 어려운 과제를 LLM에게 요구하고 실패를 확인하는 것이, 실제로 LLM을 유용하게 쓰는 방식과 얼마나 관련 있는지 의문이다.
- 1,609 샘플은 특히 DMS 과제에서 과제별로 나눠지면 소규모가 될 수 있다. `미제공:` 과제별 샘플 수 분포.

### 내 연구 적용 메모

`해석:` 항체 발굴 파이프라인에서 LLM을 에피토프 추론 도구로 쓰려는 계획이 있다면, EpiBench를 자체 평가 기준선으로 활용하는 것이 유용하다. 다만 데이터셋과 코드가 공개돼야 실제로 쓸 수 있다. 현재는 "LLM이 에피토프 추론에서 아직 부족하다"는 진단을 제공하는 논문으로 읽되, 향후 특화 파인튜닝(fine-tuning) 또는 검색 증강(retrieval-augmented) 방식의 개선 기준선으로 참조할 수 있다.

## 방법 관점 주간 총평

이번 주 5편에서 공통으로 눈에 띄는 패턴은 두 가지다.

**첫째, 코드·데이터 미공개가 전건이다.** C1~C5 모두 코드를 공개하지 않았다. 방법론 논문에서 재현 가능성이 이렇게 일관되게 닫혀 있으면, 각 논문의 주장을 독자가 독립적으로 검증하기 어렵다. 이 주에 방법을 바로 내 연구에 적용하려는 시도는 코드 공개 전까지 보류하는 것이 합리적이다.

**둘째, 검증 깊이 차이가 크다.** C2(Horvath clock)는 51개 종단 연구 기반으로 가장 탄탄한 데이터 토대를 갖고 있으나, 분석 코드가 없다. C3(EmitGCL)는 7개 코호트 + in vitro 검증까지 있어 방법론적 검증 수준이 이번 주 논문 중 가장 높다. C1·C4·C5는 in silico 단계에 머물며 외부 검증 없다.

방법 렌즈에서 이번 주 가장 주목할 설계 아이디어는 C3의 지식 인식 이질성 그래프 대조 학습(knowledge-aware heterogeneous graph contrastive learning)과 C1의 inference-time compute 재배분 전략(MCTS over frozen oracle)이다. 두 아이디어 모두 코드 공개 후 재평가를 권장한다.
